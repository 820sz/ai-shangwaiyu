# 软件特色

> 一句话定位：**不是「背单词软件」或「刷题工具」的又一个变体，而是一套围绕「输入—输出—反馈—再输入」闭环的 AI 原生语言学习系统。**
> 本文写的是软件本身的**技术架构与定位**（它和市面同类产品的结构差异），不涉及营销话术。

## 1. 闭环架构：四个板块共用同一份学习数据

大多数语言 App 是「单点工具」：背单词的只管词表、刷题的只管题目、阅读的只管文章，彼此数据不通。
本软件把学习拆成一条完整链路，并让**同一份数据在四个板块之间真实流转**：

```
输入（材料中心 / 找材料 / 书架 / 材料库 / 阅读器 / 识图 / 生词本）
   ↕  同一份材料、同一份词汇、同一份进度、同一份能力数据
输出（四阶：写词 → 写句 → 写段 → 写篇；题库 / 练习中心）
   ↕
反馈（AI 批改 / rubric 评分 / 错误档案 / 复盘）
   ↕
助理（学习画像 / 任务 / 水平测试 / 每周复盘）
   ↕
我的（统计 / 周报 / 学习偏好 / 数据备份）
```

具体体现：

- **同一篇材料**：在输入里找到、阅读、翻译、收词；在输出里可以直接「从读过的材料出题」；在助理/我的里体现为阅读量、难度、进度数据。
- **同一份词汇**：阅读器划词/识图识别的生词进入生词本 → 输出「写词」练它 → 批改后的错误进入错误档案 → 助理复盘时按弱项安排下一次任务。
- **同一套能力模型**：难度档、词汇量区间、CEFR、阅读速度、输出得分都写进学习者模型，被四个板块共同读取，而不是每个页面各算一套。

## 2. 多维度材料体系：真实抓取，不是预制内容库

- **四个维度的找材料入口**：按需求（目标/难度/形式）、按题材、按形式、按场景；每个入口再分子分类，可多选。
- **真实来源**：公开源（Project Gutenberg 公版书、RSS 外刊、arXiv 论文、Wikipedia）+ DeepSeek 官方搜索/网页抓取；每条结果都有真实 URL，不编造材料。
- **本地难度分析**：抓到正文后在本地算词数/词频覆盖率/CEFR/预估时长/新词密度（不上传正文给服务器），难度是算出来的，不是标签猜的。
- **结果可留存、可管理**：发现结果按频道存快照；可保存到「我的」、可继续找更多、可编辑/隐藏/删除；材料库按浏览记录/外部导入/已隐藏三区分组管理。
- **内容质量闸门**：抓到的书店/课程介绍页、导航页、非英文页面、考试报名公告页会被过滤，避免把"宣传信息"当成阅读材料。

## 3. 高度个性化与可自定义：一套模型，全局生效

- **学习者模型**：难度档（i+1 / i+10 / i+100 / 不限）、学习目标（四级/六级/考研/雅思/兴趣）、兴趣主题、屏蔽词、当前水平、阅读速度、输出表现——一处设置，全局的推荐/排序/出题/难度标签都跟随。
- **可按需定制的阅读体验**：阅读器三种纸张（纸白/米黄/墨夜）、5 档字号、3 档行距、模型与思考档位；书架两种形态（封面网格 / 3D 书脊）；材料可自定义中文标题与分组。
- **有边界的个性化**：AI 只在需要的地方介入（见下），数据与规则本地优先，不把学习完全交给模型随机发挥。

## 4. AI 驱动，但用在"该用的地方"

- **找材料**：AI 生成检索计划、从真实搜索结果里筛选、必要时基于搜索到的信息生成"AI 改写学习版"（明确标注非原文，作为找不到原文时的保底）。
- **阅读**：翻译（按段/全文）、查词、追问、长难句讲解。
- **输出**：按目标出题（真题抓取/材料出题/内置题库）、按 rubric 批改（内容/组织/语言/词汇/句式分维度打分并给建议）、错误归因。
- **助理**：把行为数据组织成"今天先做什么、为什么、做得怎么样"的可执行建议，而不是空泛鼓励。
- **本地确定性规则兜底**：难度分析、词频、质量闸门、间隔复习调度、来源/校对标注都是本地可解释规则——AI 负责"生成与判断"，规则负责"可核验与兜底"。

## 5. 可解释、可管理、不黑箱

- 每条材料/每道题都能看到：来源、难度、覆盖率、权威度、校对状态；
- AI 推荐能点开「为什么推这些」，AI 改写的材料明确标注「AI 改写学习版（非原文）」；
- 材料、词汇、题库、隐藏项都可以手动编辑/删除；
- 本地数据库保存学习进度，退出重进不丢；题组可保存草稿、随时继续。

## 6. 技术架构（给关心实现的人）

| 层 | 选型/做法 |
|---|---|
| 客户端 | Flutter（Android 单端），自绘组件体系（果冻/纸面两套皮肤共用设计令牌），无 WebView 拼页面 |
| 本地数据 | SQLite（材料/正文分块/阅读进度/译文/题组/作答/错误档案）+ Hive（偏好/快照/缓存）；**账号体系：无**，数据只在设备本地 |
| 抓取 | 自写抓取与解析管道：公开源适配 + 官方搜索/抓取 API + og:image 封面 + 正文质量闸门；不是"AI 凭空编材料" |
| 难度分析 | 词频表 + 已知词覆盖率 + CEFR 分档 + 新词密度，全部本地计算 |
| AI | DeepSeek（对话/搜索/抓取）+ 可选豆包；每个功能可配置模型与思考档位；API Key 由用户自己配置 |
| 学习算法 | 间隔复习（FSRS 风格调度）、错误归因聚合、周报统计 |
| 隐私 | 不做账号、不上传学习数据；只在调用 AI 功能时发送必要文本；材料正文默认只存本地 |

## 7. 和「背单词软件 / 刷题 App」的结构差异

| 维度 | 常见单点工具 | 本软件 |
|---|---|---|
| 学习闭环 | 只有记忆或只有刷题一环 | 输入→输出→反馈→再输入四板块闭环，数据互通 |
| 材料 | 预制词库/题库 | 真实抓取的材料 + 本地难度分析 + 可留存管理 |
| 个性化 | 通用计划/固定词表 | 学习者模型驱动推荐、出题、难度、任务 |
| AI 角色 | 噱头功能或全文生成 | 用在检索/翻译/出题/批改/复盘，且规则兜底、来源可查 |
| 可解释 | 结果黑箱 | 来源/难度/覆盖率/校对/推荐理由可见 |
| 数据 | 账号云端 | 本地优先、无账号、离线可读已存材料 |

## 8. 当前阶段明确的边界

- 本软件是**个人非商业项目**（作者自用 + 朋友使用），不承诺商业化运营的服务水平；
- 听力/口语评测当前阶段不做（用户明确）；
- 材料检索依赖网络与所配置的 AI Key，离线只能读已保存内容；
- AI 生成内容（翻译/批改/改写版）可能有误，仅作学习参考。
