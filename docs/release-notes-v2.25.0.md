# ReadFlow / AI上外语 v2.25.0 更新说明

> 本版是 **v5 输入板块** 的整体交付:材料中心重构、书架双形态、材料库管理、输入内页全量果冻化。
> 仅提供 arm64 安装包;覆盖安装即可,数据(材料/生词/进度)保留。

## 一、材料中心重做(v5 架构)

- **首页只留大功能分区**:今日精读 / 按需求找材料 / 按题材 / 按形式 / 按场景 / 我的材料库。
  旧版把"我的需求、更多找法、书架、今日推荐"全塞在首页的问题一并拆掉。
- **今日精读**:保留大卡 UI(封面 + 标签 + 英文标题 + 中文标题 + 已知% / 时长 / 词数 /
  摘要句数 / 口音 + 难度建议 + 开始阅读 / 换一篇 / 原文链接);
  新增**标题行左右小箭头**(1/N 进度)切换候选;**长按卡片**弹出预览:
  完整标题、标题翻译、来源、**为什么推这篇**(只用真实依据,不编理由)。
- **按需求 = 全局推送机制**:难度档 + 学习目标 + 形式统一进 `MaterialNeed`,
  今日精读候选、各维度列表、材料库推荐走同一套排序。
- **四个维度统一二级页**:按需求(可改难度/形式,保存后全 App 生效)、按题材、按形式、按场景;
  支持子分类多选;**按形式严格按材料类型过滤**;题材/场景先用词表扩展初筛,
  列表底部新增「**AI 补长尾**」按钮,按当前方向用 AI 再找一批。

## 二、书架双形态

- **详细书架(默认)**:2 列封面网格(宽屏自动 4 列),标题 / 已读进度 / 已读完角标;
  点书打开、长按原弹层(打开/看封面/标记读完/移出)。
- **3D 立体轮播书架**:一排书脊立在书架上、竖排书侧标题可读;中间选中那本被"抽出来"
  倾斜展示封面;左右滑 / 点书脊切换,点封面打开。按参考图重做,不再是"一次一本大卡"。
- 页头右侧圆键切换两种形态,选择记住(默认详细书架)。

## 三、材料库管理

- 三个 tab:**浏览记录 / 外部导入 / 已隐藏**,每个 tab 带数量。
- 浏览记录按**来源**分组(如 NPR News、Project Gutenberg),外部导入按**分组名**分组
  (教材/职场英语…,未分组排最后),分组可折叠。
- **长按进入多选**:批量隐藏 / 批量删除。
- 删除区分两种:**隐藏**(可恢复、不进推荐)与**彻底删除**(正文+进度+译文一起删)。
- 已隐藏 tab 可恢复或彻底删除。

## 四、输入内页果冻化(视觉统一)

- 识图全文翻译:结果卡改白卡 + 段落胶囊 + 「✦ AI 讲解」胶囊。
- 查词详情弹层、保存分类弹层、导入通道选择器、阅读设置弹层、目录弹层全部统一果冻语言
  (白卡 + 淡底图标块 + pill 选项 + 大标题)。
- 阅读器顶部材料元信息改成 5 个小胶囊(词数/时长/CEFR/已知覆盖率/难度建议)。
- 词条详情页:分区 accent 竖条、信息行果冻化、掌握度按钮圆角白卡 + 选中色、例句卡淡底。
- 复习队列卡:白卡阴影 + accent 进度条 + 新词胶囊。
- 全文翻译/查词/导入/分类等弹层统一 30 圆角、单一拖拽条。

## 五、修复

- **阅读器翻译进度显示 bug**:之前会把整个 `ReaderUnit` 列表 dump 到界面
  ("已翻 x/x 段"后面跟一大串对象),已改为正常显示几段/共几段。
- 分类选择弹层双拖拽条、奇数分类被拉通栏的问题。
- 材料中心外链打不开时的提示守护(context 跨 async)。

## 六、已知限制(如实说明)

- 题材/场景检索 = **本机材料词表初筛 + AI 补长尾兜底**,不是全量公开源精准搜索;
  界面已如实标注。
- 3D 书架的书脊是按书名/进度生成的布面书脊;真实书封只显示在"抽出来的封面"上,
  且需要联网抓取(抓不到时回退程序化封面)。
- 按你的要求,**听力部分不做**。
- 阅读器翻译范围/左右切换文章等 P5 打磨项仍待做。
