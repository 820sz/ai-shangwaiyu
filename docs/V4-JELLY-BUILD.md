## 二·补 · 材料封面重做(v4.2,2026-11-03 用户点名"封面问题一直没解决好")

- **问题**:旧封面是"深色渐变块 + 白色单字标",在果冻浅色界面里像一块块黑砖头;
  单字(麻/T/E)区分度低,用户读起来依旧"意义不明"。
- **做法**(`lib/widgets/material_cover.dart`):
  1. 底:按标题 hash 稳定取色的**糖果纸面**(同一篇永远同色),不再是深色渐变;
  2. 身份:左侧**域色书脊** + 按 kind 的极淡几何纹理(书脊/点阵/报头/声波/经纬球);
  3. 字:浅底深墨 —— 宽卡(≥168 宽且高)才放标题片段;72~168 的中卡放"能认出来的
     词/2~4 个字"(英文超过 10 字母退回单字母,避免「Photosyn」半截字);
     42×54 缩略才用单字标;
  4. 徽标:白玻璃种类胶囊 + 难度胶囊(深色主题自动换深色玻璃,深浅都不隐身);
  5. 有真图时仍优先用图 + 暗色 scrim(徽标可读),加载中/失败露出程序化封面,永不白块。
- **样张**:`docs/ui-preview/jelly/covers.png`(明/暗 × 列表/书架/横卡/今日精读/横卡内);

## 二·补2 · 材料自动配图(v4.3,2026-11-03)

用户补充:"材料那些封面尽量能让 AI 抓取并配上材料自身的插图或者封面,不然整个
软件太素了",并明确"书封网上本来就有"。

**实测网络(用户本机/国内网络)**:豆瓣读书接口 + 豆瓣图床 **可达**;360 图片
搜索接口 **可达**(thumb CDN 可下);Open Library / Google Books / Wikimedia /
Gutenberg 封面 / Unsplash **不可达**(超时或 403)。所以策略是"国内可达源抓取优先,
AI 生图兜底":

| 层级 | 来源 | 成本 | 说明 |
|---|---|---|---|
| 1 | 材料源自带图(feed media:image / og:image / cover_url) | 0 | 已有链路,直接展示 |
| 2 | 豆瓣书封(`subject_suggest` → 图床 /l/) | 0 | 书/书名型材料;实测真实封面可下 |
| 3 | 360 图片搜索(thumb CDN) | 0 | 文章/论文/其他;240px 缩略,适合列表 |
| 4 | 火山方舟 Seedream 生图 | 约几毛/张 | 默认关;方舟端点才可用;生成后永久缓存 |
| 5 | 程序化"印刷封面" | 0 | 全部失败时的兜底 |

落地:`lib/services/material_art.dart`(抓取/缓存/去重/限并发/生图)+
`lib/widgets/art_cover.dart`(先程序化封面 → 后台取图 → 原地换上;失败静默)。
缓存落在应用支持目录 `material_art/matart_<hash>.jpg`,同标题同类型永久复用;
源头图加载失败(403/被墙)会触发重抓。设置页「材料自动配图」可选:
抓取(默认)/ 抓取+AI 兜底 / 关闭。

## 二·补3 · AI 原生件(v4.4,2026-11-03)

用户确认:"思考过程、流式输出、AI 头像 logo、追问抽屉"这套设计全部保留并升级。
**做法:只换皮肤,不动流式/停止/超时/记忆逻辑。**

- **思考过程**(`ThinkingBlock`,follow_up_bubble.dart):💭 emoji → **鲸鱼尾**
  (`WhaleThinking`,用户指定形象)+ 果冻淡染卡 + "思考中 · Ns" 计时 + 展开区底部
  渐隐(长内容不被硬切);折叠、180px 限高、流式实时追加全部保留。
- **流式输出**:正文下方新增**呼吸光标 + "生成中…"**(`_StreamingCaret`),
  让"还在写/写到哪"可感知;停止按钮仍只在输入栏(不在气泡里闪烁)。
- **AI 身份**(model_avatars.dart):品牌 logo 一个不改,外面加**白底托 + 极淡描边**
  圆环,浅色糖果底/深色卡片上都能认出;错误红底、未知模型哈希色首字母兜底不变。
- **追问抽屉**(follow_up_drawer.dart):身份行(追问标题 w900 + 模型槽位胶囊 +
  新建 + 历史)、用户气泡改渐变果冻 + 右下小圆角、AI 气泡白卡 + 柔影、
  快捷提问改淡主色胶囊、发送键改主色圆形箭头(停止仍是红色圆键);
  DraggableScrollableSheet 0.3↔0.85、滚动记忆、历史面板、编辑重发等行为不变。

## 三、验收口径(v4)
1. 第一眼:冷白底 + 糖果色块 + 大圆角 + 柔影,不是"白底大黑字 + 蓝按钮";
2. 深色模式同样成立(黑底 + 低饱和果冻 + 玻璃底栏);
3. 主行动唯一且明显;材料中心在输入首屏永远可见(头图胶囊 + 动作砖 + 列表);
4. 内页与主屏同一套卡片/标签/按钮(共享组件已换,内页逐屏去手写样式);
5. 全部颜色/圆角/阴影只从 `V4Skin` 或 `colorScheme` 取(`theme_test` 有硬编码闸门);
6. 不新增功能、不动数据层(dbVersion 22)、听力不做。

## 四、下一批:内页逐屏迁移(按四组,每屏出图确认)
