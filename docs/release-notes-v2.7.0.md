## 1. 「输入」页 UI 尺寸不统一 —— 已统一

**改前**:这一页的滚动视图没有页面左右边距,所以「上传分析材料(原拍照识文)」和
「材料中心」两张卡是**通栏**的;而下面的「AI 生词定制文章」和「我的学习材料」各自
硬写了 16 的左右外边距 + 12 的圆角。同一页出现两套卡片几何,左边就差 16px。

**现在**:四张卡走同一套几何(左右边距、圆角 16、内边距、卡片颜色全一致),
左边一条竖线对齐。

## 2. 材料中心

### 2(1) 链接 + 软件内呈现,两条路都给

**改前**:公开源的结果只能"软件内打开",AI 点名的作品**只有外链**。

**现在**:每一处都是两个按钮 ——
- 「软件内阅读」:抓正文入库,在里面翻译 / 点词 / 收藏 / 追问;
- 「原文链接」:直接用系统浏览器打开(反爬、要登录的页面就走这条)。

今日推荐、材料库、检索结果、AI 点名作品**四处都齐了**。AI 点名的作品在软件内抓不到时,
会直接弹一个「用浏览器打开」的按钮,不让你卡在死路上。

### 2(2) 中文标题 + 翻译 + 点词两个动作 —— 三个阅读器都有

- **标题一律「中文(英文)」**:检索结果、AI 点名的作品、以及**新入库的材料**
  (抓完正文先中文化再入库,所以书架 / 阅读器 / 「我的学习材料」显示的是同一个标题)。
- **逐段英中对照翻译**:材料阅读器底部新增「翻译」按钮,点一下每段英文下面出中文。
- **点词 / 长按选中,底部两个选项**:「询问 AI」(就地流式讲解,不跳页)与
  「收藏进单词本」。
- 这三件事**特色功能生词成文**和 **AI 改写材料**里也都有了 ——
  以前那两处是纯文本,点不了、也没有翻译。三个阅读器现在共用同一套阅读正文。

### 2(3) 搜索框里那口"死数据" —— 找到根因了

那个「小说故事」**不是搜索历史**,是学习画像里的兴趣词被当成默认关键词填进输入框。
现在:搜索框只回填"你上次在这个分类里真搜过的词",没有记录就**留空**
(靠提示语告诉你可以用中文说需求);进页面自动搜的那一次用内部默认词,**不会写进输入框**。

### 2(4) 外部资源导入 —— 文件 / 图片 / 链接三条通道

**改前**:只有一个"标题 + 正文"的粘贴框。

**现在**(按你选的方案:纯文本类 + 图片 + 链接):
- **文件**:点右上角「+」→ 从文件导入。支持 `.txt / .md / .srt / .vtt / .csv / .json / .log / .html` 等纯文本类,
  HTML 会自动抽正文;走**系统文件选择器,不需要任何存储权限**。
  中文乱码(GBK 编码)会明确提示,不会把乱码当材料收进去;超过 8MB 会提示切成几份。
  PDF / EPUB / DOCX 目前**不解析**:会告诉你"先转成 txt 或复制文本粘贴",不假装支持。
- **图片**:拍照或选图(可多选)→ AI 提取图上**全部正文**(不是只提取划线词)→
  可以**就地改错字**再入库。
- **链接**:贴公开网页链接 → 抓正文入库;Gutenberg / arXiv 的链接会自动认出来走专用抓取
  (公版书拿全文、论文拿摘要)。需要登录 / 付费 / JS 渲染的页面抓不到时会说清原因。

## 3. 「拍照识文」升级为「上传分析材料」

- 首页那张卡现在是两个平级入口:**「拍照识别」**(= 原来的功能区,一点没变)
  和 **「外部链接导入」**(论文、期刊、新闻、博客都行)。
- 链接导入后直接进**材料阅读器**:软件内呈现正文 + 底部多功能栏
  (`模型 / 翻译 / 收词 / 追问 / 更多`),追问 AI、收藏、退出自动存进度、
  **选择保存位置**都在。

## 4. 难度自选 i+1 / i+10 / i+100

材料中心顶部就能切:

| 档位 | 含义(按未知词率) |
|---|---|
| **i+1** | 覆盖率 ≥98%,几乎全认识,轻松泛读 |
| **i+10** | 覆盖率 90%~98%,舒适精读,正好够一够 |
| **i+100** | 覆盖率 <90%,硬啃区,建议先预热生词 |
| 不限 | 不做难度约束 |

切换后:材料库按这一档**重新排序并标注**「符合 / 偏易 / 偏难」,还能一键「只看符合」;
同时这一档会作为**硬要求**交给 AI 去找材料。

> 如果你对 i+1 / i+10 / i+100 的区间定义有别的理解,告诉我数字,改一处就全生效。

## 5. 个性化找资源

材料中心顶部新增面板:**难度 + 内容类型(公版书/论文/外刊/播客/百科)+ 题材倾向 +
补充/调整需求**(比如"不要学术腔,每篇 10 分钟以内")。设好之后:
- 找材料时这些会进 AI 的提示词(它按你的偏好找);
- 内容类型还会**收窄检索范围**(选了"论文"就只查 arXiv,不浪费时间去连不上的源);
- 首页「按你的水平找材料」页也会显示当前生效的偏好。

## 6. 「我的学习材料」

### 6(1) 能直接删分组了

**改前**:打开子分类(比如「书籍」)只有重命名/改页码,**没有删除** ——
删词只能进生词本一个一个删。

**现在**:一级分组和二级(页码/章节)都能直接操作:
- **删除整组(N 个生词)**:二次确认,显示条数;
- **解散分组**:词保留,只是不再挂在任何材料下(回到「未归类」)。
- 顺带修了一个小毛病:一级分组右上角的铅笔把**展开箭头**顶掉了,你看不出这行能展开;
  现在箭头回来了,四个操作收进展开区一行,带文字标签。

### 6(2) "改了出处还在未归类" —— 这是真 bug,已修

**根因**:「未归类」里的词 `material_path` 是空的,而那个铅笔**只能改页码** ——
没有任何入口能把"材料名"写进去,所以改完还在未归类。

**现在**:未归类的分组和二级都有「**归入材料…**」,填材料名 + 页码 →
这些词立刻移到「分类 / 材料名」下面。材料名留空时会当场提示
(而不是"保存成功但什么都没变")。
