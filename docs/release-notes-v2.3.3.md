### 🐞 一、同一个词会被收进生词本两次

`insertVocabularies` 是**裸插入**,没有任何查重。于是:

- 听写页「把没听出的词收进生词本」→ 按钮在保存成功后**没有禁用**,用户点第二次就把同一批词插了第二遍;
- 一次听写里两句漏了同一个词、AI 识图返回的词表里有重复词 → 同一批里也会重复;
- 结果:生词本里一个词两行,复习队列里同一张卡出现两次(还互相争配额)。

修法放在**数据库层**一次修好(而不是在四个收词入口各写一遍查重):插入前把"库里已有的词 + 本批已处理的词"过一遍,词面按 `trim().toLowerCase()` 比较,重复跳过,并返回**真正插入的条数**。这和备份恢复"按词面去重、已存在跳过"的既有约定一致。

界面同步改:听写页保存成功后按钮变为「已收进生词本」并禁用,提示如实拆分:新增几个、本来就有几个、挂上复习状态几个。

### 🧪 二、新增两条整链路测试(`test/review_flow_test.dart`,6 例)

**复习链路**(复刻 `review_screen._rate`):

- 评「不认识」→ 到期时间必须**往后走**(否则队列永远清不完)、`lapses` 累加、掌握度回退、错误档案留痕;重新打开复习页时它**不该立刻又出现**;
- 新词评「认识」→ 不再是新词(否则"新词额度"永远用不完)、稳定度真的写进去了;
- 小结页的「7 天负荷」与刚写进去的到期时间**对得上**(第 4 天有 1 张,前 3 天为 0)。

**听写链路**:

- 抽句 → 打字(故意漏词)→ 判分指出漏词 → 一键收词 → **真的出现在今日复习队列**;
- 重复收同一批 → 只插一次;同一批里重复的词 → 只插一条。
