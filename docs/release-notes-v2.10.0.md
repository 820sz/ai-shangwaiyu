# AI上外语 v2.10.0

## 先说认账的三件

### 1. 翻译:进度条是死的、取消不掉、几乎没法用、范围乱 —— 是**五个** bug,不是一个

- **取消不掉**:我以前只置了一个标志位,**当前那一批请求还在跑** → 界面继续显示"正在翻译"。现在用 `CancelToken` **真的中断网络请求**,点取消立刻停;关掉翻译也一样。
- **几乎没法用**:旧实现每批 3 段、**串行**请求 —— 67 段要 23 次往返。现在按**字符预算**切批(1600 字符 / 每批最多 4 段)+ **2 路并发**。
- **进度条是死的**:`已完成` 只有整批回来才 +1,第一批卡住就永远 0%。现在每完成一批就推进。
- **公版书必报错**:`maxTokens` 写死 4096,长段翻译被截断 → 段数对不上 → **整批丢弃**。现在按输入长度自适应(1200~8192),并且段数对不上时**抢救前 k 段**,不再整批扔掉。
- **范围乱**:进度分母被我压成 `min(段数,60)`,同一屏出现「第 1/67 段」和「已完成 0/66 段」两套数字。现在分母就是**本次真实段数**。

### 2. 标题中文:"我都说了几次了,一次都没实现过" —— 你说得对

我以前只把译名放在**那一次列表的内存**里,翻完就丢:材料库、书架、阅读器标题全没中文。现在**译名落库**(`materials.title_cn`),材料库/书架/阅读器读同一份,打开材料中心还会**后台补齐**缺失的译名 —— 只翻一次,永久有效。

### 3. 材料导入串了材料中心的文章

我用了"拉全库"的接口、入库时也没记来源。现在**只认用户手动导入的**(origin=import),材料中心的公版书/论文/外刊一律不进这里。

## 逐条交付

**① 「上传分析材料」合并** —— 原来"拍照识别"和"从相册选择"是两个并排按钮,你得先判断"我这算哪种"。现在一个「**上传图片**」按钮 → 弹层里选「拍一张 / 从相册选(可多选)」。

**②(1) 翻译** —— 见上面五条。另外:译文改成英中对照块,单段失败可就地重翻;**范围选择**四档(当前段 / 前后各 3 段 / 当前章前 20 段 / 整篇),每档实时算"共 N 段 · 约 X 分钟",整篇超过 40 段会提醒可以随时取消。

**②(2) 标题中文** —— 见上面。推荐列表、材料库、书架、阅读器**全部**带中文。

**②(3) 打开材料的思考过程改成真流式** —— 不再是"转圈 + 一句固定文案",而是**逐条推真实步骤**:
`正在抓取正文… → 抓到正文:12 段 · 约 8400 字 → 正在把标题翻成中文… → 正在分析难度并入库… → 分析完成:C1 · 3200 词 · 约 12 分钟`,末尾带"已用 N 秒"。

**②(4) 内容类型补上内容层面** —— 原来只有**来源**维度(公版书/论文/外刊…),现在加了**内容**维度 10 类:**新闻报道 / 评论社论 / 科普 / 文学小说 / 学术论文 / 商业财经 / 演讲致辞 / 访谈对话 / 教程指南 / 历史人文**,可多选。每一类带**英文检索词**并**真的拼进检索** —— 中文标签对公开源没用,检索词才决定"找到什么"。

**②(5) 今日推荐点了没反应** —— 我把点击写成了"设为今日精读"(只换上面那张大卡,没有跳转)。现在**点卡片直接打开这篇文章**,「设为今日精读」降级成小按钮。

**②(6) 封面重做** —— 不再是"色块 + 标题前两个字":
- 小尺寸取**第一个有意义的词**(英文取首个实词并首字母大写,中文取前 3 字且不切断词、跳过"第/章"这类结构字);
- 大尺寸显示标题前 14~18 字,按类型画**低对比几何纹理**(书=书脊竖带、论文=点阵、外刊=斜切色带、播客=同心弧、百科=经纬球、文章=排版行线);
- 左上**种类徽标** + 左下**难度胶囊**(按档位配色);有真图优先、加载失败自动降级;深色模式专门校过对比度(全部高于 WCAG AA)。

**③ 材料导入** —— 见上面,只收你自己导入的东西;分类可用自己的名字(如「新视野教材」),可重命名/解散分组,导入后直接进阅读器。

**④⑤ 书架(全新)** ——
- **阅读器里** AppBar 就有「加入书架」☆;**退出这篇材料时**弹你指定的三选一:「**放进书架 / 放进收藏夹 / 不了,就看看**」(已经在架上、或刚点开就退,不会烦你);
- **材料中心**新增「书架」区块(就在"个性化找资源"下方),带一排横书脊预览,点进独立书架页;
- 书架页:搁板和书脊**全部自绘** —— 深胡桃木/浅橡木搁板(上表面受光、前沿压暗、下沿投影)、书脊斜向渐变 + 中缝高光 + 书头书尾堵头布、**竖排书名**、底部一条**进度书签带**(在读琥珀/读完绿);一层按屏宽放 3~7 本;顶部四格统计(藏书/读完/在读/累计时长);长按可看封面/移出书架,右上角可按最近阅读、加入时间、阅读进度**重排并落库**;
- **空书架也是书架**:一样画出带搁板的架子 + 6 个虚位(第一个带加号)+ 一句人话引导,等你放满。

**⑥ 名片能改大小和形状了** —— 你第二次说"无法编辑",我上次只做了"换头像/换背景图",**确实没有大小和形状**。现在:
- 头像:**大小 3 档**(小/中/大)、**形状 3 种**(圆形/圆角方形/方形)、**边框**(无/细/粗);
- 背景图:**缩放**、**位置**(上/中/下)、**暗度**、**模糊**四个滑条 —— 保证放上照片也能看清白字;
- 全部在编辑面板里**实时预览**,改什么立刻看到;整卡可点 + 卡上「编辑名片」按钮(入口又强化了一次)。

**⑦ 收藏夹阅读界面** —— 你说得对,又简陋又有一堆 AI 符号。现在:来源徽标 + 标题 + 字数信息卡 + **正常渲染的 Markdown**(`##` 真的成标题、`**` 真的成粗体、`- ` 真的成列表),并且**先清洗再渲染**:去掉 AI 开场/结尾客套("好的,以下是…"、"希望对你有所帮助")、统一全角符号、补结构空行;还能复制全文、删除这条收藏。

**⑧ 移动材料** —— 改成**从已有分类里选**:列出当前分类下已有的材料,点一下就移动,不用手打;「新建一个材料…(手动输入)"降级成底部兜底。
