## v2.3.0 — 材料中心修好了、入口合并了、桌面有小组件了

这一版主要来自你的真机实测反馈:**材料中心没法用**、**材料中心该和「其他输入材料」合并**、**导师要改名并挪位置**、**AI 学习建议删掉**;顺带把 2.2 收尾的**桌面小组件**做完。

---

### 🔧 一、材料中心为什么"没法用"——根因是默认值选错

不是你的网络坏,也不是功能没做,是**默认选中了连不上的源**:

- 旧实现默认选列表第一个源 = **BBC Learning English**;
- 我在本机(中国大陆)实测了全部 7 个源:

| 源 | 结果 |
|---|---|
| NPR News | ✅ 200 · 2.7 秒 |
| arXiv 论文 | ✅ 200 · 0.9 秒 |
| Project Gutenberg | ✅ 200 · 26 秒(614KB,首包慢) |
| BBC Learning English / VOA / TED / Wikipedia | ❌ 9 秒无响应(超时) |

于是你打开材料中心看到的**第一屏必然是失败**。修法(不是加个"重试"就完事):

1. **默认源改成 NPR**(实测可用);
2. **记住每个源的可用性**:成功/失败都记在本机(含原因与时间),**下次直接落在你上次成功过的源上**;
3. **源标签上直接标状态**:✔ 最近可用 / ⚠ 上次失败;选中哪个源,下面一行就说明"它是什么 + 在你这儿行不行";
4. 新增「**检测可用源**」(右上角):一次把 7 个源挨个探一遍,直接告诉你**哪些能用** —— 手工试错一个源要等 9~20 秒,试一圈一两分钟还未必记得住;
5. **失败卡片重写**:说清"哪个源、为什么、下一步点哪",并给「换到 XXX」按钮(旧版只有「重试」,试完还是同一个连不上的源);
6. **公版书全文超时放宽到 90 秒**:实测《Pride and Prejudice》全文首包就要 26 秒,原来的 20 秒必然失败 —— 这不是源挂了,是整本书本来就大(新闻类仍保持 20 秒,不让你卡在坏源上等一分钟)。

### 🔀 二、材料中心与「其他输入材料」合并

你说得对,两者是同一个定位。现在**材料中心是唯一的"找材料"入口**,一页里四段:

1. **今日推荐**(公开源:外刊/原版书/播客/百科/论文)
2. **按你的水平找材料**(原「其他输入材料」的分类入口:教材/书籍/外刊/碎片文章/其他 → AI 按你的词汇量推荐,并避开你屏蔽的题材)
3. **粘贴自备材料**(右上角按钮)
4. **材料库**(已入库材料,按"今天最适合读"排序)

输入页那张「其他输入材料」卡片已删除。

### 🧭 三、底栏:导师 → 学习助理,挪到「我的」右边

新顺序:**输入 / 输出 / 我的 / 学习助理**。页面内所有"导师"字样(问导师、导师还缺这些信息、导师选材…)一并改名。打开 App 仍默认落在学习助理页,先看到"今天学什么"。

### 🗑️ 四、删掉「AI 学习建议」

你说它完全没用,我同意:它的输入只有**生词收藏数 + 连续天数 + 按书分布**,算不出任何真东西 —— 所以只能说"先定个小目标、每天 10 分钟"这种谁都能说的话,而且每次还要花一次**付费 API 调用**。入口、状态、provider 与 API 方法已全部删除。这个位置现在由学习助理承担:本地诊断(11 类规则,**每条结论都带数字依据**)、可点开、可打勾、会随数据变化。

### 📱 五、桌面小组件(v2.2 收尾)

「我的 → 桌面小组件」:

- **一键添加到桌面**(启动器不支持时,页面里给长按桌面的图文步骤);
- **同步并预览**:点一下立刻按当前数据推送,并把"桌面上会显示什么"原样贴出来 —— 不用切回桌面就能核对;
- 小组件显示:**今天第一件该做的事 + 待复习数 + 今天新词额度 + 连续学习天数**,点整块打开 App。

两条刻意的设计:

1. **过期数据不冒充今天**:桌面挂件读不到 App 的数据库,数据是"打开 App 时推送"的。所以隔了一天后,小组件会自己改说「打开 App 刷新今日任务」+「上次同步 N 天前」,而不是拿三天前的"待复习 3 个"骗你(系统每 30 分钟会让它重绘一次,这个判断在原生侧独立做);
2. **没数据就说没数据**:全新安装显示"打开 App 生成今天的计划",不显示 0/0/0。

另外,小组件里的数字与 App 内**同口径**:新词额度用复习页同一个函数算,连续天数复用学习助理的同一份实现(桌面和 App 显示两个不同数字,比不显示更糟)。

### ⚠️ 已知限制

1. **小组件的外观只能在你的桌面上验证** —— App 内的"预览"只还原文字与配色(桌面圆角、壁纸下的观感、不同启动器的间距差异我这边看不到);
2. 材料源可达性结论来自**我这边**的网络实测(2026-09-24)。你的网络(移动数据/WiFi)可能不同,点「检测可用源」就能得到**你那边**的结论;
3. 小组件数据在**打开 App 时**推送,系统不保证后台定时更新(Android 对后台任务有限制,我没做后台服务 —— 那会吃电、也不可靠);
4. 「跟读」按你的意思**不再排期**(没有语音识别就没有可信的发音评分);
5. 「每日提醒」仍需通知包 + Android 13 权限引导(你之前未选),继续放在待办里。
