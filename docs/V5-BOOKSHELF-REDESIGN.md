## 一、现状

- `lib/widgets/bookshelf_view.dart`：平面木架（自绘搁板/书脊/书脊文字/进度书签），
  v2.13 曾尝试 3D 透视，但因**没有做裁剪**导致书脊文字溢出到统计条，被迫回退；
- `lib/screens/input/bookshelf_screen.dart`：排序（最近/进度/书名）、筛选（全部/在读/已读完/已搁置）、
  长按操作（移出书架/看封面）、空态；数据来自 `BookshelfBook`（materials + progress）；
- 视觉：v2.24.1 已把木色板换成**果冻淡紫书架 + 白搁板 + 主色光晕**（保留平面结构）。

结论：**数据与操作可完全复用，只重做"画法"与"形态切换"**。

## 二、两种形态定义

### 形态 A · 详细书架（封面优先）

```
┌ 书架 ─────────────────────── [切换:详细|3D] ┐
│ 统计条: 12 本 · 在读 3 · 已读完 6 · 累计 …   │
│ [全部][在读][已读完][已搁置]   排序:最近 ▾     │
│ ┌──────┐ ┌──────┐ ┌──────┐                 │
│ │ 封面  │ │ 封面  │ │ 封面  │  (2~3 列网格)    │
│ │ 标题  │ │ 标题  │ │ 标题  │                 │
│ │进度38%│ │进度12%│ │ 已读完 │                 │
│ └──────┘ └──────┘ └──────┘                 │
└───────────────────────────────────────────┘
```

- 用现有 `ArtCover`（真实书封 + 程序化兜底）做 3:4 封面卡；
- 信息：中文标题（英文小字）、进度、难度等级、最近阅读；
- 空书架：插画 + "去材料中心加一本"；
- 复用现有排序/筛选/长按操作。

### 形态 B · 3D 轮播书架（书脊优先）

```
┌ 书架 ─────────────────────── [切换:详细|3D] ┐
│                                             │
│        ╱▔▔▔╲   ╱▔▔▔╲   ╱▔▔▔╲              │
│       ╱ 书脊 ╲ ╱ 书脊 ╲ ╱ 书脊 ╲   ← 3D 透视 │
│      │标题竖排││标题竖排││标题竖排│          │
│      │进度书签││进度书签││进度书签│          │
│       ╲____╱   ╲____╱   ╲____╱              │
│  ‹ 左右滑动切换 · 中间一本最大/最正 ›          │
│      ● ○ ○ ○   分页/当前位置                  │
└───────────────────────────────────────────┘
```

- 单排水平轮播：中间书放大、两侧按距离做透视倾斜（`Matrix4` + 自绘阴影）；
- 书脊显示：竖排中文标题（或英文缩写）、书脊色（按书籍 id 稳定生成）、进度条/书签带、等级字母；
- 手势：左右滑动吸附（每本一档），点击中间/任意一本打开阅读器；
- 性能：只构建可视 ±4 本；用 `ClipRect` 严格裁剪（v2.13 的坑）；关闭动画尊重系统"减少动态"；
- 可选（Q8）：自动缓慢轮播 / 无限循环 / 点击翻面看封面。

## 三、切换与状态

- 书架页头右侧增加**形态切换按钮**（`详细` / `3D` 双图标，或 SegmentedButton）；
- 选择存 Hive（`keyShelfViewMode`，值 `detail` / `carousel`），下次进入沿用；
- 默认形态：**待你拍板**（建议默认详细书架，3D 作为"看封面/把玩"模式；见主文档 Q7）；
- 两种形态共用：数据、排序、筛选、点击打开、长按操作、空态；
- 统计条在两种形态都保留（3D 模式下可压缩成一行小字）。

## 四、技术方案

| 项 | 方案 |
|---|---|
| 3D 实现 | 自绘 + `Transform`（`Matrix4.identity()..setEntry(3,2,0.001)..rotateY(angle)`），每本按距中心距离计算 `angle/scale/z`；阴影用 `CustomPainter` 画椭圆/滤色，不用 elevation |
| 裁剪 | 外层 `ClipRect` + 每本书 `ClipRect`（解决 v2.13 文字溢出） |
| 数据 | 复用 `BookshelfBook`（materialId/title/percent/cefr/coverUrl…），不新增表 |
| 书脊配色 | 纯函数 `shelfSpinePalette(seed)`（沿用现有 `_ShelfPalette` 扩展，可单测） |
| 手势 | `PageView`（`viewportFraction<1` + 自定义 `Transform` 子项）或自写 `GestureDetector` + `AnimationController` 吸附；优先 PageView，稳定省事 |
| 性能 | 只渲染可视区 ±4；`AnimatedBuilder` 只重建变换层；图片用现有 ArtCover 的缓存 |
| 无障碍 | 揭示语义标签"第 N 本《标题》，进度 X%"；减少动态模式下禁用透视动画 |
| 测试 | 纯函数（书脊配色/位置/尺寸）单测 + 真实屏幕渲染（3D/详细各一屏） |
