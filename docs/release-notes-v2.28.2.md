# ReadFlow v2.28.2 · 搜索修复（AI 检索词 + AI 改写兜底 + 少误杀）

> 针对 2026-11-08 真机反馈：按需搜/自由搜搜不到、AI 该更聪明、名片背景糊、AI 改写材料要标注。

## 1. 搜索 AI 更聪明（用户要求：搜中文名要想到原版名）

- **新增检索词规划**（`lib/services/search_query_planner.dart`）：中文书名/译名/主题先由 AI 判断原版英文名或最合适检索词，再检索；
  - 例：搜《原子习惯》→ 按 **Atomic Habits** 检索（不再拿中文名硬搜出一堆 RSS 新闻）；
  - 规划失败/没配 Key 自动退回原关键词，不阻塞搜索；
  - 搜索过程里会显示「已按「Atomic Habits」检索（…）」。
- **相关性过滤**：与关键词（含原版检索词）毫无交集的结果直接丢弃（例如 RSS 最新新闻），并在结果说明里写明「已丢弃 N 条无关结果」；丢掉后如果没结果，下方就是 AI 改写兜底。

## 2. 按需搜/自由搜「搜不到」修复

- **候选级公告过滤放宽**：旧实现只要标题/摘要里出现「官网/公告/培训/招生」任一弱词就整条拒（真机上出现 8 条全被当公告过滤）；
  现在改成「强信号单个即拒（报名入口/准考证/成绩查询/考试大纲…）+ 弱信号累计 3 个才拒 + URL 路径强信号」，正常文章不再被误杀。
- **按需搜新增「AI 改写保底」**：这次搜到的真实线索（标题/摘要/来源）会作为依据，一键生成「AI 改写学习版（非原文）」，
  标注依据数量/真实字数/难度/来源，可「开始读」「保存到我的」；另加「去自由搜」入口。没有真实线索时按钮禁用并明说（不凭空编）。
- **没有原文、只有 AI 改写的材料会有小标记**：结果卡上新增 `AI 改写` 小胶囊（标题本身也带「AI 改写学习版（非原文）」）。

## 3. 名片背景不再糊

- 卡片渲染时不再额外加模糊、用户设置里的背景模糊在名片上封顶 2px（照片保持可辨认）；文字可读性由「上淡下重」的纸色渐变 scrim 保证。
- 三栏数据「约 4250 词 · B2」不再被截断（等比缩放）。
