# ReadFlow v2.12.0 更新说明 · 前端全面升级

> 这批的依据是你 10/23 给的原则:
> 「**精简和高级、实用是第一位**,在此基础上,去增加软件前端的**丰富性和趣味性**,
> 让使用体验过程不单独枯燥!」以及「整个软件的前端都需要升级,不只是 ui,
> 各方面的交互、分类逻辑等等都要」。
> 参考了你给的 5 张样图(扇贝阅读 / 训记 / 轻小说文库),学的是**做法与原理**,不是照抄。

## 一、整套视觉换了(不是只改某一屏)

- **背景**:冷灰白 → **暖白**。阅读类 App 的底要温润,长时间看不累;
- **主色**:近黑 → **蓝**。旧主色做按钮时像"次要/禁用",现在主行动是明确的蓝色
  (选的是偏深的蓝,对白底 5.4:1,过无障碍对比度标准);
- **字阶**:之前字号是手写的(11/11.5/12/12.5/14.5…),现在统一成 **7 档**
  (28/22/18/16/14.5/12/11):大标题够大、元信息够小,一屏有了节奏;
- **圆角与阴影**:卡片 16 → **20**(大卡 24);阴影从"几乎没有"变成**两层柔和投影**
  (深色模式仍然不用阴影,靠亮度差 —— 这是原来的约定);
- **主按钮**:统一 **48 高 + 14 圆角**,该大的地方就大;
- **标签**:统一**胶囊形**;加了一套难度徽标(Lv 横排/竖排两种)。

## 二、每个功能有了自己的"样子"(这是"不枯燥"的关键)

以前整个 App 只有一种形态:圆角卡 + 文字列表 —— 所以结构再改也还是"清一色"。
这批建了一套**形态库**,不同内容用不同形态:

| 内容 | 形态 |
|---|---|
| 今日精读 / 推荐文章 | **大图卡**:通栏图 + 标签行(领域 + Lv)+ 标题 + 中文副标题 + 元信息(句数/时长/口音)+ **整宽主按钮** |
| 材料列表 / 检索结果 | **横卡**:左文右图 + 竖排 Lv + 标签,扫读效率最高 |
| 书架 | **3D 透视书架**:书脊有纵深、搁板有方向,不再是平面贴图 |
| 统计 | **大数字面板**:数字 26 号加粗,一眼看懂 |
| 空态 | **自绘轻插图**(圆点 + 主色圆),不再是灰图标 + 一行字 |

## 三、四屏重做

**材料页(原"输入")**
- 去掉顶部工具条,改成**大标题 + 日期/引导**;
- 「上传分析材料」成为**唯一主行动**:整宽蓝按钮「拍照 / 从相册上传」+ 次按钮「导入外部链接」;
- 材料中心入口降为第二层级的入口条(带图标块)。

**材料中心**(你骂得最多的那屏)
- **删掉了上一版我自己编的「找材料 / 在读 / 我的东西」三组分段** —— 你说得对,
  那三个名字看不出意义;
- 顶部改成**内容领域页签**:科学与技术 / 商业与政治 / 健康与生活 / 文化与艺术 /
  旅行与体验 / 语言与学习…(点一下直接按题材找材料);
- 所有区块**纵向杂志式排列**,靠形态差异产生节奏(大图卡 → 横滑卡流 → 题材结果 →
  网格 → 真书架 → 横卡列表);
- 材料库改成**横卡**(左文右图 + 竖排 Lv),去掉卡上占位的一排按钮。

**练习页(原"输出")**:大标题 + 编号区块(01 练 / 02 写)。

**我的**:三个数字合并成**一张数据面板**(数字放大);三个分组标题带编号(01/02/03)。

**学习助理**:加载改成骨架屏(原先是转圈);区块标题带编号。

## 四、底栏与分类逻辑

- 底栏文案改成**用户语言**:材料 / 练习 / 我的 / 助理
  (原来叫"输入 / 输出"—— 那是工程词,用户得猜);
- 学习助理的加载转圈、以及其他 20 多处转圈全部清掉,统一改成骨架屏/时间线
  (这是你早就定过的规矩:"界面里不许出现转圈")。
