## v2.5.0 — 排 bug + 前端大升级(材料中心找得到原文 / 开屏与退出动画 / 全 App 排版重做)

这一版按你 2026-09-24 提的第二批五件事做:**①排 bug、打磨每个功能 ②前端大升级(参考「训记」学本质)③材料中心 AI 找不出原版材料 ④AI 改写看不到出处/来源/思考 ⑤开屏动画 + 退出动画**。没有加任何你没要求的功能;听力/音频、跟读、每日提醒**按你说的都没做**。

### 📚 3. 材料中心:AI 找不出任何原版材料(你说"完全没有用武之地")

**根因**:上一版挑的检索站 `gutendex.com` 在大陆网络**实测 12.5 秒超时**;而且旧实现只报一句"没有结果",你看不出是"这个源不通"还是"真的没这本书"。

**这版**:
- 公版书改用 **Gutenberg 站内检索页**(实测 3.1 秒 / 10 条);arXiv 改 https(6.7 秒 / 10 条);**不给关键词也总有结果**(默认给"最受欢迎书单");
- 各源**并行**检索 + 12 秒总预算(外刊从 62 秒降到 12 秒),已经知道连不上的源直接跳过;
- **每个源单独如实报**:通了几条 / 为什么空 / 上次没连上已跳过 —— 页面上一条信息条列清楚,不再让你猜;
- 中文关键词会明确提示"这些源都是英文库,请用英文关键词";
- 进页面**自动搜一次**,打开就有东西看。

### 🔍 4. AI 改写内容:出处 / 来源 / 思考过程

- AI 推荐的详情页新增**溯源卡**:用的是哪个模型、什么时候生成、依据的画像快照、关键词,以及**可展开的思考过程**(以前用完就丢,现在落库,dbVersion 13);
- 页面顶部写明"**这是 AI 编写、不是出版原文**",条目带「AI 编写」角标;要可考证的原文就切到「资料原文」那一栏。

### 🎬 5. 开屏动画 + 退出动画

- **开屏**:logo 淡入 + 轻放大(700ms),文案延迟出现并上移淡入,整段约 1.45 秒,**点一下可以跳过**;
- 文案**可以自己改**:「我的 → 外观 → 开屏文案」(默认就是「让语言,回归本质」,留空恢复默认);
- **退出**:在首页按返回弹出**字幕式提示**(「辛苦啦,再学一会儿?」/「累了~休息啦」),元素错峰淡入;**一天只问一次**,其余时候直接退。

### 🎨 2. 前端大升级(学「训记」的本质,不照搬外表)

学的是它的四条本质:**打开即行动 / 预判下一步并预填 / 数据就在手边 / 状态可恢复**;明确**没学**它那套需要讲解的隐藏手势(我们的操作必须看得见),也没学它的高信息密度与深色默认(阅读场景要留白)。

- **新地基**:设计令牌(间距 / 圆角 / 时长 / 边距的唯一事实源)+ 一套通用组件(卡片 / 区块标题 / 入口行 / 空态 / 加载 / 失败 / 列表错峰入场),页面切换改为淡入上移;
- **学习助理首页**:一屏一个**主行动**(今天先做这件),其余任务与诊断折叠;
- **输入页**:主行动(拍照)优先,入口按场景排;
- **材料中心 / 方向页**:统一排版,源状态用**色点 + 一句话**一眼看清,失败卡可**一键换源**;
- **阅读器**(新功能):阅读设置里可调**字号 5 档 / 行距 3 档**,带实时预览,**材料阅读器和文章阅读器共用同一份偏好**;查词面板重做层级(词 + 音标 + 朗读 → 词性/释义 → 例句卡 → 整行「收进生词本」);
- **复习页**:进度一眼可读(大字号序号 + 粗进度条 + 「还剩约 N 分钟」);卡片放大、内容居中;评分按钮变**大按钮**;标记按钮加高;
- **「我的」**:13 个平铺入口收成三组 —— **学习**(生词本 / 复习模式 / 收藏夹)、**数据与回顾**(统计 / 本周报告 / 错误档案 / 备份导出 + 学习曲线)、**设置与数据管理**(API / 学习偏好 / 外观 / 桌面小组件 / 诊断 / 检查更新);
- **设置类页面**(API / 外观 / 学习偏好 / 备份)表单、卡片、区块标题、按钮高度统一;
- **顺带修掉界面里漏出来的字面 `**星号**`**(材料中心与方向页的说明文字)。

### 🐞 1. 排 bug

- **修掉「备份恢复丢复习次数」**:从备份恢复后,`reps` / `lapses`(复习过几次、忘过几次)以前会被重置成 1 / 0;现在按备份里的真实值还原,并补了测试(含"正常复习仍是累加"的回归);
- **浅色下看不清的根**:把散落在 20 多个文件里的写死颜色(~90 处 `Colors.orange/green/red/blue/amber`)收敛成**随明暗切换的语义色** —— 这些写死色在白底上只有 **2.2~2.8:1**(WCAG 要求 4.5:1),就是"看不清"的来源。新增两个**全 App 唯一**的取色入口:掌握度色(新词 / 学习中 / 已掌握)与词条类型色(单词 / 短语 / 句子),并加了对比度闸门测试;
- 复习页在 **2× 系统字号**下的溢出防护(进度行可省略、评分按钮自适应缩放);
- 材料中心 / 阅读器 / 复习页的**失败态都可原地重试**(不再只有一行文字)。
