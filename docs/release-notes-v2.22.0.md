# ReadFlow v2.22.0 · 补漏（二）：写句三题型 + 题库 + 目标排序 + 助理诊断/复盘深化 + 模型能力

> 批 8（2026-11-02）：按自查清单继续补齐，这一版集中在"练习方式自选"、"材料按目标排"、"助理专业度"。

## 更新内容

1. 写句阶新增三种题型，自己选：句式改写（AI 出题+评分；没配 AI 时自动切离线对照，不评假分）、错句纠错（句子被故意改坏几处，改回正确句并逐点对照）、连词成句（词块点选拼句）。
2. 新增「题库」：做过的题组都留在这里，点开可原样重练，不再"做完就走"；入口在输出页四阶下方。
3. 练习中心改成两个入口：四阶练习（推荐）与旧版练习计划；旧链路保留历史数据但不再是唯一选择。
4. 四阶练习形态区分：写句/写段/写篇的作答区高度、提示语、写篇的评分维度预览各不相同，不再是一个模子。
5. 材料库支持「按目标优先」排序：选过四六级/考研/雅思/托福后，相关材料（真题/考试类/标题命中）排在前面，可一键关闭；同时修掉重复条目。
6. 助理升级：新增 4 条诊断（任务停滞 / 计划过载 / 假完成 / 能力停滞），复盘增加按时率、按类型产出、连续跳过提醒——每条结论都带真实数字。
7. 阅读器默认字号下调一档（长文连读更稳，可在阅读设置里调回）。
8. AI 能力接线：出题/评分/检索计划启用 JSON Output（不兼容自动降级重试）；找材料候选不足时自动"换关键词再找一轮"（tool-calls 两段式补救），花费仍可见。

## 技术细节

- 写句三题型：`sentence_practice.dart`（句子来源/改写生成/纠错注入/连词成句/统一回流）+ `sentence_practice_screen.dart`（三模式一屏）；新增 11 条纯函数测试（注入错误、多解判定、标点分块、可复现打散、回流禁用路径）。
- 题库：`practice_history_screen.dart` 从 `exercise_sets/items` 还原题组重练。
- 材料排序：`MaterialLibrary.rankForGoals` + `dedupeShelf`（纯函数），材料中心加「按目标优先」开关。
- 助理：`LearnerSnapshot` 新增任务/能力信号（loader 独立降级），`tutor_engine` 4 条新规则，`tutor_insights` 复盘指标扩展（按时率 ≤ 目标×1.2 口径；类型产出按 goalTag 聚合；连续跳过由任务表新→旧数）。
- 能力层：`base_api` 支持 `response_format` + 不支持端点进程内缓存降级；`material_discovery` 增加 refine 阶段（真实候选 → 换 query → 最多一轮）。
- 验证：`flutter analyze` 0 error / 0 warning（8 条存量 info）；全量测试 **1525 passed + 1 skip + 1 已知假失败**（`profile_card_test` Hive 假时钟问题，与 App 无关）。
