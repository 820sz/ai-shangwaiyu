# ReadFlow v2.11.0 更新说明

> 本次的 4 条全部来自你 10/5 的真机反馈(含截图 2 张)。

## 1. 修好了"部分文章打不开"

你截图里那句 `打不开这条原文:【Project Gutenberg(公版书)】书籍 id 不合法:0` —— 根因找到了:

材料中心的"今日推荐 / 今日精读"是从订阅源读来的,而订阅里给的是一条**完整网址**
(如 `https://www.gutenberg.org/ebooks/79727`),但打开时程序把它当成"书号"去解析,
解析不出来就变成了 0 → 报"书籍 id 不合法:0"。

现在打开前会先把这一条**规范化**(纯书号 / 书目页链接 / 全文链接 / 带版本号的论文编号
都能认出来),并且顺手修掉了同一个毛病的另一处(按水平找材料那条链路)。
同一本书从"发现更多"和从"今日推荐"打开,也不会在材料库变成两条了。

## 2. 封面改用**原材料自己带的图**(按你说的,不做 AI 生图)

- **新闻/外刊**:订阅里其实自带文章头图,以前没被认出来(它的写法跟旧解析器预期不一致,
  而且图片地址直连会被 CDN 拒绝 —— 现在会先"拆包"拿到真正的原图地址);
- **公版书**:按书号直接取官方封面(实测 12 个书号全部可用);
- **打开过的材料**:封面会**存进本地库**,重启后材料库/书架里依然是真图,不再退回色块;
- 拿不到图时,仍旧回落到原来那种程序化封面 —— 永远不会出现空白块。

⚠️ 一句实话:公版书用的是 PG **官方生成**的封面(排印文字版式),**不是原书插图**。
真·原版画插图藏在"带插图的 HTML 版"里(实测那一页 650KB、偶发断流、最长要等 60 秒),
放进正常打开流程会毁掉手感,所以这条我**没有**做 —— 如果你想要,我可以单独做一个
"长按封面 → 抓真插图"的按需入口(会有明显等待,但只在你主动点的时候)。

## 3. 个性名片精简

- **签名与名字的颜色分开了**:以前两个都是白色、只差透明度,在花哨背景图上糊成一片;
  现在签名走冷青灰,和纯白名字一眼能分开;
- **删掉了你圈起来的那句描述和那个宽按钮**,入口改成**右上角一个小铅笔**(点得到,
  有触觉反馈,不再是"看着像按钮但点不动"的装饰);
- **编辑界面压到约一屏**:去掉"3/12"字数计数器、去掉两句解释文案、文字头像预设并进
  "从相册选"那一行、大小/形状/边框三组合并到一行标题下 ——
  **三个自定义维度一个都没少**。

## 4. 全局 UI 升级(按你选的方案)

**材料中心**(你说"最没欲望的一屏"):
- 「今日精读」提到最上面当**主角大卡**(整页唯一一张大图卡,给眼睛一个落点);
- 「今日推荐」从 6 张竖列卡改成**横向滑动的封面卡**(一张一张往右翻,高度省了三分之二);
- 「书架」区块换成**真的书架**(有厚度的搁板、立着的书脊、空位的虚线框 ——
  和独立书架页同一套画法,以前只在书架页用);
- 「按你的水平找材料」改成**真正的两列网格**;
- 其余区块收进顶部**三组分段切换**:找材料 / 在读 / 我的东西 —— 首屏不再是一长串一样的横条,
  每块的可用空间也变大了。**每个区块自己的折叠/隐藏机制原样保留**,功能一个没藏。

**整体**:补了统一的字号阶梯(以前字号是手写散落的,同一层级的文字在不同页面不一样大),
卡片有了"型号"(普通 / 主角 / 紧凑 / 强调),网格方块全 App 共用一份实现。

**底部导航**:选中项上方多了一条指示条、图标轻微抬起、换栏时一次轻触觉 ——
只加这三样,没有弹跳和彩虹色(按你"高级但不要眼花缭乱"的要求)。
