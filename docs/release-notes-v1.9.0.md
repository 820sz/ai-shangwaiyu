## v1.9.0 — 全面代码审查修复版

本版基于一次完整代码审查（`docs/CODE-REVIEW-2026-09-19.md`，45 个文件逐行过 + 5 维度审计 + 主审复核），把审查发现的 P0/P1 阻断项与绝大多数 P2 问题一次性修掉：**P0 3/3、P1 9/9、P2 34/34 全部落地**（个别项为部分实现，见文末"未做"）。

### 数据安全（最要紧的一批）
- **修好"升级后生词本打不开"的隐患**：数据库迁移原来是"失败也吞掉"的写法，一旦某步失败，`user_version` 照样推进，失败的迁移永不重跑 → 生词本每次读写都抛 `no such column`。现在迁移改为**幂等 + 单事务 + 真实错误上抛**，并在每次启动做一次自检补列/补表。
- **全新安装缺列修复**：新建库漏了 `phonetic` 列，全新安装的用户一进生词本就报错。已补。
- 数据库补 **9 个索引**、打开 **外键约束**、清理历史遗留的孤儿练习记录（这些曾让"已完成练习"数量虚高）。
- 批量删除/批量移动生词、书籍重命名、页码改动全部改为**单事务**，失败有提示，不再出现"界面删了、库里还在"。
- 一行坏数据不再毁掉整页：文章/练习解析改为容错解析，页面加载失败会复位并给出重试。

### AI 功能可用性
- **修好 DeepSeek「极致/高」档位下功能失灵**：文章生成、回译练习、学习建议的第二个 API 服务此前会带上 DeepSeek 不接受的参数，正文被思考过程吃光 → 现在统一按厂商规则构请求，正文为空时自动从思考通道取结果。
- **修好材料推荐/精读在思考档位下"AI 未返回内容"**（与追问同源的兜底缺失）。
- **流式解析修复**：中文被网络分包切开时不再丢字（原来会解出乱码字符，甚至整帧静默丢失 → 表现为"AI 没识别到标记的词"）。
- **不再永久转圈**：流式生成期间加了 60 秒空闲看门狗（网关断流/半开连接会明确报错）；材料推荐增加总超时与「取消生成」按钮。
- 参数降级重试收敛为最多一次，且只在错误类型明确时才降级 —— 避免同一张图片被重复上传、重复计费。
- 「方舟端点 + deepseek 模型名」这类混搭配置现在能正确判定参数族；方舟不认的「极致」档自动归一到最高合法档，不会再被打回"不思考"。

### 复习与词汇
- 复习进度现在**连"已标记"一起保存**：退出再续看，卡片标记不再消失，统计数也不会因为重复点击而超过卡片总数。
- 续看定位改为按断点词 ID 定位（原来删词后会跳到"最后一张"）。
- 「不认识/模糊/认识」与生词本的「新词/学习中/已掌握」标签语义对齐，标完能对上号。

### 更新与隐私
- **下载的 APK 会校验 sha256 与字节数**（取自 GitHub Release asset 的 `digest`/`size`），校验不通过拒绝安装；直连失败自动走镜像并提示。
- 关闭系统云备份（API Key 存在本地明文配置里，不再随备份上云）；移除全局明文流量开关；诊断页的 Key 只显示厂商与长度。
- 崩溃日志脱敏 + 256KB 轮转；FileProvider 的共享范围收窄到"缓存/updates"这一层。

### 体验与性能
- 写译页按返回键不再直接丢草稿：弹「保存为写译记录 / 直接离开 / 取消」，结果页有常驻的「保存记录」。
- 四处"永久删除"（收藏、追问清空、推荐删除、重新推荐）统一确认弹窗 + 删除后「撤销」。
- 统计页/收藏夹/文章列表补三态（加载中 / 空 / 失败可重试），不再永久转圈或静默消失。
- 词条列表改为惰性构建、缩略图按显示尺寸解码（12MP 照片不再整张进内存），灰色正文色对比度提到 WCAG AA。
- 动效：选中卡片有极轻的缩放回应、复习卡片切换有方向语感、系统开启"移除动画"时全部瞬时完成、回顶/回底时长统一。
