# ReadFlow v2.28.3 · 搜索根因修复 + AI 改写选项/覆盖优先

> 对应 2026-11-08 反馈：自由搜残留旧新闻、按需搜永远 0 条、AI 改写内容差/字数少、字幕被挡。

## 1. 按需搜「永远搜不到」根因修复

- 根因：`FindNeedContext.queries()` 取的是中文目标/兴趣（兴趣只保留拉丁字母 → 中文兴趣被丢掉），公开源只认英文、官方搜索拿到中文就返回考试报名页/中文文章，抓正文又被判"不是英文正文" → 恒 0 条。
- 修复：按需搜先把「需求+兴趣+目标+难度」交给 AI 规划成 **1~3 条英文检索词**（考试目标只用于难度，不当检索词），再走同一条真实检索流水线；搜索过程会显示「已规划英文检索词…」。规划失败自动退回原流程，不阻塞。

## 2. 自由搜不再残留旧结果

- 根因：进页会自动恢复「该关键词上次的频道快照」，看起来像本次搜到了 NPR 新闻。
- 修复：自由搜**只展示本次搜索的结果**（历史仍可在入口页看）；同时保留 v2.28.2 的检索词规划 + 相关性过滤（与关键词无关的 RSS 最新内容会被丢弃并注明）。

## 3. AI 改写：先问字数/难度 + 覆盖优先

- 点「生成 AI 改写学习版」后先弹选项：
  - **字数**：不限（推荐，优先覆盖内容）/ 约 400 / 约 700 / 约 1000；
  - **难度**：贴近原材料难度（默认）/ 更简单（高频词/短句）/ 更难（丰富词汇/复杂句）。
- prompt 重写：**优先保证内容覆盖** —— 模型先提炼 3~6 个关键点（outline），正文必须逐点覆盖；线索不足时不编造；不设固定字数上限时按内容需要写（一般 500~900 词）；生成后不足字数会**自动重试一次**；结果卡显示「覆盖 N 个内容要点」。
- 不再把不相关的 NPR 线索喂给模型：只用与本次关键词相关的线索；一条都没有时按"围绕主题写、不冒充来源"生成（仍标注 AI 改写）。
- AI 改写卡片底部说明改成两行短句 + 底部留白，避免文字被裁。

## 4. 其他
