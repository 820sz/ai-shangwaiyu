## v2.0.0 预览版 · 第 2 期：导师 tab（AI 主导的每日入口）

> ⚠️ 仍是 **预览版**（prerelease）。材料中心 UI 与复习内核还没接上，本版交付的是 **2.0 的心脏：导师**。

### 这一版能做什么

装完后 App 打开就是「**导师**」页（底栏四栏：导师 / 输入 / 输出 / 我的）。

**1. 今天做什么（任务卡，落了库）**
- 由诊断自动生成 3-4 条，每条写明**多少分钟**和**为什么给你派这个**
- 点「开始」直接跳到对应功能（词汇量测试 / 复习 / 材料中心 / 写作）
- 做完打勾会写进数据库（当日任务一份，不重复生成）

**2. 诊断（每条都带依据）**
这一版最核心的变化：诊断是**在手机本地用规则算出来的**，不是让 AI 自由发挥。每条结论都带"依据"一行，例如：
- 「复习堆积：X 个词已经过期 —— 到期共 Y 个，其中 X 个超过计划时间」（过期 >200 时升级为红色"先清账"）
- 「生词本在变成收藏夹 —— 已收录 50+ 词，但一条复习记录都没有」
- 「近 30 天只有输入，没有输出 —— 读了 X 词 / Y 分钟，但没有任何输出练习记录」
- 「《材料名》对你偏难 —— 覆盖率只有 86%，每 100 词有 14 个生词」
- 「重复出错：时态 —— 错误档案里 时态(7 次)、冠词(4 次) 反复出现」
- 一切正常时给的是"把覆盖率目标从 98% 调到 95-96%"这种**可执行**建议，而不是"保持节奏"

**3. 问导师（会话带证据包）**
- 导师的 system prompt 里塞的是**结构化数据快照 + 本地已得出的结论**，并硬性要求：先结论后依据、给可执行的下一步、数据不够就直说缺什么、不要说空话
- 会话落库（重启后还在）；会话历史 + 画像 + 数据快照一起给模型

**4. 缺什么问什么（画像即问即存）**
- 导师页顶部直接列出"还缺哪些信息"，用可点选的 chip 收集：学习目的 / 每天可投入时间 / 偏好题材
- 选完立刻写入学习者模型，并**重新跑一遍诊断**（任务卡跟着变）

### 想请你重点看
1. 「导师」页第一眼的**诊断结论是否让你信服**（每条都有依据，有没有"说了等于没说"的）；
2. 任务卡的**时长与措辞**是否合理（3-4 条、贴着你的每日时间）；
3. 顶部画像追问会不会太啰嗦（现在缺什么就显示什么）；
4. 问导师几句，看它会不会**胡编数据**（如果编了，把原话发我 —— 那是 prompt 或证据包要修）。
