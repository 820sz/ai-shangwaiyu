# 下一版候选清单（v2.27.0 之后 · 需用户拍板或调研）

> v2.27.0 已交付并等真机验收。本文把「本轮记录为二期/等批准」的项整理成可决策清单，
> 用户验收时可以顺手拍板，避免下一轮又停在等待上。**本文不涉及任何生产代码改动。**

## A. 必须先由用户拍板的两项（之前明确"等批准"）

### A1. 单题 `source_url` 入库（需要一次数据库迁移 22 → 23）
- 现状：题组级已存 `license_note`（含全部来源 URL），单题只存在内存、重练后丢失；`exercise_items` 表没有 `source_url` 列。
- 方案：dbVersion 22→23，`_ensureColumn(db, 'exercise_items', 'source_url', 'TEXT')`（纯加列、老数据为空、可回滚=删列/忽略）。
- 收益：每道题可独立标「来源 URL + 校对」，避免重练后来源丢。
- 风险：迁移一旦写错不可自愈（有单测闸门）；需要用户确认后再做。
- 预估：0.3 人日。

### A2. 六级专属 rubric（需改 rubric seed 初始化）
- 现状：拆了「四级/六级」目标 + 词池按等级切，但六级作文/翻译仍复用四级 rubric 维度。
- 方案：`rubrics` seed 增加 `cet6_writing`/`cet6_translation`（DB 初始化 INSERT OR IGNORE，不改表结构）；出题器按 exam_type 选 rubric。
- 风险：seed 变更只对"新装/未 seed 过"的库生效，老库需一次性补 seed（幂等 INSERT OR IGNORE 可覆盖）。
- 预估：0.5 人日。

## B. 需要先做技术调研再拍板

### B1. 找材料 PDF 正文提取（需要加第三方 PDF 解析依赖）
- 现状：PDF 只保证「能打开 PDF（外部浏览器）」；正文抓不到就标 unavailable。
- 要做的：先验证 Android arm64 下可用的纯 Dart/Kotlin PDF 文本提取方案（包体、构建、可维护性），再决定是否引入依赖；用户规则是"不擅自加依赖"，所以**先出调研结论**。
- 预估：调研 0.5 天 + 实现 1~2 天（取决于方案）。

## C. 本轮明确记为二期（不需要决策，排期即可）

### C1. 深色模式 + 360dp 窄屏适配与渲染验收
- 现状：阅读器墨夜纸已覆盖"深色阅读"，但其它页面系统深色主题、360dp 窄屏未逐屏出图；QA 已声明二期。
- 方案：按主题补深色令牌（V4Skin 已有 jellyDark）+ 360dp 关键屏渲染 + 修溢出；预计 1.5 人日。

### C2. 长书阅读进度校准
- 现状：percent 用 `offset/maxScrollExtent` 线性近似，懒加载长书会轻微跳动（设计 §7.3 已知）。
- 方案：改为 `(已读块 + 块内比例) / 总块数` 二次校准；预计 0.5 人日。

### C3. 阅读器查词弹层 C 化（共享件布局）
- 现状：`word_action_sheet.dart` 是拍照页/其它阅读器共用，本轮只跟随纸色（布局未 C 化，已获批准例外）。
- 方案：抽一份 Reader 专用查词卡（保留共享件不动），阅读器内使用；预计 0.5 人日。

### C4. 「我的 → 频道材料」300 条上限
- 现状：`MaterialLibrary.shelf(limit:300)`，超 300 条明示但不全量；DB 无分页接口。
- 方案：给 materials 查询加分页参数（limit/offset），频道「我的」按需加载；0 迁移；预计 0.5 人日。

### C5. 死代码下线（旧找材料页家族）
- 现状（已核实）：`material_discover_screen.dart`（旧 AI 找材料，已无活入口）、`category_material_screen.dart`（唯一实例化点是零引用旧页）、`legacy_material_center_screen.dart`（类名仍是 `MaterialCenterScreen`，零实例化，仅被 export 复用 BandAdviceBanner/warmUpWordFrequency）、`material_browse_screen.dart` 的补长尾卡（settingsOnly 下不渲染）、`ai_material_search.dart`（旧 AI 编写页）。
- 方案：先确认无引用 → 迁移 export 复用项 → 删文件（-3~4k 行），避免以后误用；预计 0.5 人日。

### C6. 找材料质量继续调（按真机结果）
- 系列多册聚合（新概念/剑桥雅思/CET 真题按系列聚合）；
- 候选层 URL 域名预过滤（书店/电商域名不发 Fetch，省钱）；
- 渠道与提示词按真实结果调；预计 1~2 人日（持续）。
