# ReadFlow v2.29.2 · AI 改写改为「作者口吻重写原作」+ 搜索二次不再空转

## 1. AI 改写（理解修正）

上一版把"改写"做成了"书评/概述"（第三人称、核心内容一笔带过）——这是错的。

现在 prompt 明确要求：
- **以原作者的叙述口吻**重写（原作第一人称就用第一人称；论述/教学口吻沿用）；
- 正文里**不许出现**"这本书讲了…/作者认为…/本文介绍…/这是围绕《X》的改写…"这类第三人称元叙述；
- **按原作结构完整展开**核心内容（章节/观点/方法/例子/结论），核心内容不许一笔带过；
- **篇幅由原材料内容量决定**（一般 1000~2500 词，内容多就长），用户仍可在生成前选字数/难度；
- 非原文标注只在标题/文末（App 统一加），正文保持作者口吻；禁止编造引文/页码/数据/链接。

## 2. 自由搜二次检索不再空转

- 上一版原版没找到时"补搜"仍复用书籍源（Project Gutenberg），所以三次都在同一个源里空转。
- 现在：书/作品类原版 0 条时，直接改用**官方搜索**找内容参考（summary/key ideas/book notes 类网页）；
  其他类型才用 AI 规划词补搜公开源。官方搜索也拿不到时，就走 AI 改写（作者口吻、按知识体系覆盖）。
