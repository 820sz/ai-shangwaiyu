## 二、根因（写给自己）

1. **把"组件新"当"页面新"**：用 `V4DetailHeader` 换了头就报"完成"，body 没动；
2. **用示意图当验收**：手搭页面 ≠ 生产屏幕，布局/间距/顺序都可能不同；
3. **没有全局组件思维**：`AppSectionHeader` / AppBarTheme / `VocabCard` / `BookshelfPalette`
   这类"一处改、全 App 生效"的地方没先做，导致逐页改又慢又漏。

- `theme.dart`：`appBarTheme` → 果冻底 + 26 圆角 + 深墨标题 + 图标深墨（存量 AppBar 页全部受益）
- `design_kit.dart`：`AppSectionHeader` → 编号主色胶囊 + 一行 18px w900 标题 + 右侧淡底胶囊动作
- `bookshelf_view.dart`：书架配色 → 果冻淡紫 + 白搁板 + 主色光晕/虚线

## 四、验收规则（从此执行）

1. 页面级一律**真实屏幕渲染**截图验收，示意图只允许做"组件级提案"且必须标注"示意图"；
2. 每屏改完先跑真实渲染自检，再提交；
3. 用户真机截图是最终裁判，发现不符按截图逐项对照修。
