# ReadFlow / AI上外语 v2.25.1 修复说明

> 针对 v2.25.0 真机验收反馈的 5 个问题的修复版。覆盖安装,数据保留。

## 1. 书架找不到 → 入口回归

v5 重构材料中心首页时,旧首页里的"书架"入口被一起拆掉了,但书架页本身没有坏。
现在材料中心首页底部新增并排两个入口:

- **我的书架 · N 本** → 直接进书架(详细封面网格 / 3D 立体轮播可切换)
- **我的材料库 · N 篇** → 管理页

## 2. 阅读器"毫无变化" → 正文前大标题卡

- 标题、来源类型、词数/时长/CEFR/已知覆盖率/难度建议,**全部移进正文滚动内容**;
  下滑时随正文一起滚走,不再"永远悬在顶部";
- 大标题 26px 加粗、来源胶囊、阅读进度百分比;
- 阅读区的纸面、翻译便签、底栏沿用,但上方信息结构换了。

## 3. AI 推荐不成系统、没爬原文 → 改走真实爬取

- "按需求补长尾 / AI 找材料"入口统一改走 v3 的真实发现流程:
  **AI 出检索计划 → DeepSeek 官方搜索接口 + 公开源(Project Gutenberg / NPR /
  ScienceDaily / NASA / TED / BBC/VOA)→ 抓回正文入库**,每条结果都有真实 URL,
  可点"打开原文"核对,难度用本地词频算;
- 不再是"模型凭空写一份材料"(旧 `ai_material_search` 的 AI 编写列表);
- 旧推荐列表卡也修了版式:标题独占整行,标签(来源/难度)放第二行,
  不再出现 "Atomi / c / Habit / s" 这种逐字换行。

## 4. 排版过挤 / 空间不合理 → 卡片重排

- **按题材 / 按形式** 两张卡改成纵向布局:图标+箭头一行、标题整行、说明两行,
  不再把"按题材"折成"按题/材";
- 卡片间距、内边距统一;说明文字限制最大行数,不再挤成三行;
- 书架/材料库入口改成并排小卡,数量一眼可见。

## 5. 顶部大 UI 下滑不缩小 → 折叠头部

- 材料中心的果冻大头部移进滚动内容:**下滑时跟着内容滚走**(不再固定悬浮),
  滚走后顶部出现紧凑条(返回 + 材料中心 + 编辑需求 + 导入);
- 阅读器同上:难度/词数信息条移进正文,滚动即隐藏。

## 已知限制

- DeepSeek 官方搜索需要你在设置里配了官方 Key 才会启用;没配时只用公开源
  (Gutenberg/RSS),仍是真实原文,只是覆盖面小一些。
- 书架 3D 书脊是生成式书脊,真实书封只出现在"抽出来的封面"上,需要联网抓。
