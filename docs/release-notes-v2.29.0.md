# ReadFlow v2.29.0 · 搜材料「准确性优先」+ AI 改写按作品知识体系重写

> 用户 2026-11-08 核心反馈：
> 1) 搜书不能拿沾边关键词凑数（搜《原子习惯》出 arXiv「atomic clusters」物理论文）；
> 2) 原版没有时，应找**这本书的二手解析/书评/读后感**（真实文章），而不是拼凑；
> 3) AI 改写的正确逻辑：**先理解这本书讲什么（用模型知识，不限语言），梳理成体系再改写**，
>    而不是用边角料线索拼出没有完整度的四不像。

## 1. 自由搜：类型路由 + 严格相关性

- **按 AI 判断的类型收窄来源**：书 → 只搜书籍源（Gutenberg），不会再跑去 arXiv 搜"atomic"；
  论文 → arXiv；外刊/新闻 → RSS；播客 → 播客源；用户手动选类型时以手动为准。
- **严格相关性**：先看完整短语是否出现；否则要求**大多数实词**都命中（≤2 个词时必须全中），
  不再"标题里有一个通用词就算相关"。无关结果会被丢弃并注明数量。
- **原版没找到 → 补搜二手材料**：AI 规划 2 条「book review / summary analysis / 读后感」类检索词
  （规划失败用模板兜底），第二轮结果同样过严格相关性；找到时说明"原版没找到，已补搜相关解读 N 条"。

## 2. AI 改写：按"作品知识体系"重写（核心逻辑修正）

- 不再要求"只能取材于搜索线索"（那会拼成四不像）；现在的流程是：
  1) 先确定用户要找的是**哪本书/哪篇文章/哪个主题**（中文名 + 原版名一起给模型）；
  2) 用模型自己的知识（不限语言）梳理该作品的 **4~8 个核心要点**（主旨、关键观点/方法、章节结构、结论/应用）；
  3) 按这些要点**逐点覆盖**改写成英文学习材料，明确标注「AI 改写学习版（非原文）」；
  4) 搜索线索只用于补充/确认书名作者主题；禁止编造具体引文、页码、统计数据、链接。
- 结果卡显示「覆盖 N 个内容要点」；字数/难度选项沿用（默认不限字数、贴近原材料难度）。
- 仍然先弹选项弹层（可滚动、按钮可点）；生成按钮不再固定高度，文字不被裁。
