# PLAN-2.0 — AI 上外语 2.0 产品与设计文档

> 状态：**已确认，v2.0 开工**（2026-09-22）
> 依据：用户《谈谈语言学习的本质》 + 2026-09-22 两轮讨论决策
> 决策记录：新增独立「导师」tab（AI 主导）；水平评估 = 自适应词汇量测试 + 全量行为数据持续修正；材料由**软件提供渠道**（不是让用户上传）；2.0 做「听」不做「说」；分三阶段 v2.0/v2.1/v2.2；接受内置词频表（2-6MB assets）；导师页内主动 + 可选每日提醒（默认关，首次进导师页问一次）。
> 补充决策（用户 2026-09-22 确认）：① 不引入需注册的外部 API key，外刊走**无需 key 的公开源**；② 词汇量测试**两种模式都要**（5 分钟速测 / 10 分钟完整版含语法+阅读小题）；③ 音标与音频**英式美式都给**（可切换）；④ 题材**支持用户自选黑名单**。

## 1. 定位与原则

### 1.1 与《谈谈语言学习的本质》的对齐

用户文档给出四层结构，本设计把它直接做成产品骨架：

| 层次 | 用户文档的表述 | 产品对应物 |
|---|---|---|
| L1 闭环 | 输入 → 输出 → 反馈 → 再输入 | 材料中心 → 阅读/听 → 说写练习 → 批改与错误档案 → 复习调度 → 下一批材料 |
| L2 四能力 | 听、说、读、写 | 读（材料中心+阅读器）、写（写译批改）、听（v2.2）、说（**2.0 明确不做**） |
| L3 三要素 | 语音、词汇、语法 | 词汇：SRS + 词汇量估计；语法：错误标签画像；语音：音标 + TTS（v2.2 加跟读） |
| L4 个性化 | 按目的差异化手段 | 学习者模型的目标维度 → 导师生成计划与材料配比；**考试向只做词表对标，不做"刷题当起点"** |

**两条不可违背的产品纪律**（源自用户文档的"笨而有效的体力活优先"）：
1. **真实语料优先**：绝不把"AI 仿写材料"冒充学习材料（v1.9 的"精读内容"就是这个错误）。
2. **不制造虚假成就感**：统计只呈现真实数据（识别的词数、读懂的比例、记忆留存），不做积分化的空中楼阁。

### 1.2 2.0 的一句话定义

> 从"工具集 + 一次性 AI 文本"升级为 **"带学习者模型的 AI 导师 + 由软件供给的真实材料渠道 + 可追踪的记忆与反馈闭环"**。

## 2. 现状盘点：两个功能为什么"形同虚设"

### 2.1 「AI 学习建议」

**输入侧（真正的病根）**

| 现状 | 问题 |
|---|---|
| `LearnerProfileStore.suggestFromVocab`：`vocab.length < 50 → 入门(A1-A2)` … `> 800 → 高级(C1-C2)` | 用"生词本收录数"当水平标尺，与真实水平近乎无关，甚至反相关（初学者见词就收；高手只收低频词）。它是"我收藏了多少"，不是"我会多少" |
| `getPersonalizedAdvice(totalVocab, masteredVocab, streakDays, vocabByBook, memory)` | 模型只拿到 5 个聚合数字 → 只能输出"保持节奏、多读多听"这类废话。**不是模型蠢，是证据为零** |
| `masteryLevel` 只有 0/1/2 三档 | 没有时间戳、没有复习历史 → 无法回答"会不会忘""什么时候该复习" |
| 无材料维度 | 不知道用户最近读什么、难度多少、读懂比例、哪些词反复查 |
| 无输出维度 | 写译批改分数、错误类型、回译正确率都不进画像 |
| 无"提问"能力 | 画像靠一次性表单，之后永不更新；AI 不会主动问 |

**形态侧**：一次性 200 字文本，无法追问、无法执行、无法复盘。导师的核心是 **对话 + 观察 + 布置任务 + 检查**。

### 2.2 「其他输入材料」

| 现状 | 问题 |
|---|---|
| 本质 = "AI 推荐 4-6 个书名 + 生成一篇精读内容" | 书名是真的，但内容是 AI **改写**的（prompt 原文写着"若非真实出版物原文，请写'根据该材料风格改写的精读选段'"）→ 用户学的是仿写文本，**输入环节失真** |
| 没有内容源 | 不是"渠道"，而是"让 AI 空想推荐"；App 自身不供给任何真实材料 |
| 无难度量化 | 只有 AI 嘴上说的"B1/四级"，没有覆盖率/生词密度这类可验证指标 |
| 体验薄弱 | 无阅读进度、无点词查词、无生词分布预览、无读前/读后动作设计 |
| 与闭环脱节 | 生成内容进阅读器后与生词本/复习/统计无回流 |

## 3. 学习者模型（Learner Model）：一切个性化的地基

**存储**：单行 JSON（`learner_model`）+ 明细表（词级、材料级、会话级）。**每个字段都带 `value / source(自报·测试·推断) / confidence / updatedAt`**；未测量维度在 UI 上显示"待测"，并给出"如何测"的入口 —— 这是"专业评估"与"瞎猜"的分界。

### 3.1 词汇维度

| 指标 | 怎么得到 | 说明 |
|---|---|---|
| 词汇量估计 V̂（±CI） | **自适应 Yes/No 测试**：按词频分层（1k/2k/3k/5k/10k/20k…）每层抽 20 词，用户勾选"认识"；穿插 **伪词**（如 `floter`）估计虚报率 → V̂ = Σ(命中率 − 虚报率) × 层容量 | Meara & Buxton 的经典方法；5-8 分钟，误差约 ±10% |
| 词汇掌握状态（词级） | **FSRS** 参数：stability / difficulty / last_review / due_at / reps / lapses | 取代三档 `masteryLevel`；旧数据按旧档位给初值迁移 |
| 自报补充 | 用户可随时修正（"我觉得自己比这个高/低"） | 与测试值并存，显示两个数 |
| 行为持续修正 | 阅读覆盖率实际表现、复习正确率、写译用词水平 | 贝叶斯式微调 V̂ 与置信度 |

### 3.2 材料难度维度（**全部本地计算，零 API 成本**）

| 指标 | 公式/口径 |
|---|---|
| 词数 / 独特词数 | token 化后统计（含词组边界处理） |
| **已知词覆盖率** | `|types ∩ 用户已知词表| / |types|`（已知词表 = 已掌握词 + 低词频段推定认识词） |
| **生词密度** | 生词数 / 100 词 |
| CEFR 估计 | 词频分布 + 平均句长 + 从句密度 → 映射 A1…C2 |
| 可读性 | Flesch Reading Ease / Flesch-Kincaid Grade |
| 预计阅读时长 | `词数 / 用户实测阅读速度(wpm)`，wpm 从 `reading_sessions` 估计 |

**i+1 匹配规则**（材料推荐与难度提示的统一依据）：

| 用途 | 覆盖率区间 | 说明 |
|---|---|---|
| 泛读 / 消遣 | ≥ 98% | 几乎无阻力 |
| 舒适精读（默认推荐） | 95–98% | 每 100 词 2-5 个生词 |
| 挑战精读 | 90–95% | 需要预习词 |
| 过载（不推荐，给提示） | < 90% | 明确告知"这份材料对当前水平偏难" |

### 3.3 语法与错误维度

- **错误标签体系**（固定枚举，便于统计）：时态 / 语态 / 冠词 / 介词 / 单复数 / 主谓一致 / 搭配 / 语序 / 中式英语 / 拼写 / 标点 / 从句结构。
- 来源：写译批改、回译练习、读后测验（v2.1 起）。
- 记录：次数、最近发生时间、**状态（已改正 / 仍复发）** → 形成"薄弱点雷达"。

### 3.4 行为与习惯维度

学习天数 / 连续天数 / 每日输入词数 / 阅读分钟与速度 / 复习完成率与准时率 / 材料完成率 / 活跃时段 / 拾词率（每 1000 词收多少生词）。

### 3.5 目标与约束维度

目的（应试 / 工作 / 原版书 / 口语 / 兴趣）、目标水平与期限、每日可投入时长（分钟）、偏好题材、排斥的形式（例如"不想做选择题"）。

## 4. 导师（Tutor）：软件内置 agent

### 4.1 定位

可读全库数据、可写少量结构化字段、可发起追问、可生成任务与复盘、可自由对话的**单一导师实体**（不是散落在各页的 AI 按钮）。它必须"知道自己在说什么"——每条结论都要落到数据上。

### 4.2 能力清单（工具接口）

| 类别 | 接口 | 用途 |
|---|---|---|
| 读 | `get_profile()` | 画像全字段 + 来源 + 置信度 |
| 读 | `get_vocab_stats()` | 词量、掌握分布、到期数、新词、短语占比、最近收录 |
| 读 | `get_materials(recent/finished/by_level)` | 在读/读完的材料 + 难度 + 覆盖率 + 完成度 |
| 读 | `get_reading_sessions()` | 时长、速度、查词次数、拾词数 |
| 读 | `get_writing_feedback()` | 批改分数、错误标签、改前改后 |
| 读 | `get_exercise_results()` | 回译/测验正确率与错因 |
| 读 | `get_review_stats()` | 复习完成率、准时率、留存曲线 |
| 读 | `get_activity()` | 频率、时段、连续天数、输入量趋势 |
| 读 | `get_tutor_memory()` | 长期记忆（用户自述、承诺、失败尝试） |
| 写 | `update_profile(fields)` | 追问得到的答案落库（水平/目标/时间/偏好） |
| 写 | `create_tasks(items)` | 生成今日/本周任务卡 |
| 写 | `set_daily_quota(new_words, review_cap)` | 调整复习配额（防止堆积） |
| 写 | `add_error_tag(tag, evidence)` | 归档错误类型 |
| 写 | `add_memory(note)` | 写入长期记忆 |
| 行动 | `open(material/review/writing/placement)` | 卡片可直点直达 |

### 4.3 四种交互范式

1. **诊断（进入导师页 / 每周）**：输出 3-5 条结构化结论 —— 每条 = 发现 + 证据（引用具体数据）+ 建议动作 + 一键跳转。禁止无证据断言、禁止鸡汤。
2. **结构化追问（缺数据时）**：一次问 3-5 个（选项 + 自由填），回答直接入库；例如"你每天的可用时间？""目标是读原版书还是应试？""最近这份材料读起来什么感觉（太易/合适/太吃力）？"
3. **任务卡（今日/本周）**：3-4 项，形如"精读《X》第 3 节（约 900 词，覆盖率 96%）18 分钟"、"复习 24 个到期词"、"用今天拾的 5 个词写 3 句"。完成后回填，未完成会进复盘。
4. **复盘（周报）**：本周输入量/输出量/复习完成率/错误复发情况 + 下周调整（含配额调整与材料更换建议）。

### 4.4 硬约束（写进 system prompt 与代码校验）

- 无证据不下结论；结论必须能指到 `get_*` 的具体字段。
- 不确定就**先问**，不要猜用户的水平/目的。
- 不编造材料、不编造用户数据；材料只能来自材料库（有 `material_id`）。
- 输出结构固定（JSON schema），失败可重试，解析失败不污染 UI。
- 隐私：AI 只拿**结构化摘要**；原文片段默认不外发（可在设置里开启"允许发送片段"）。

### 4.5 主动性

- **页内主动**：进入导师页、材料读完、批改完成、复习堆积（到期 > 阈值）、连续中断 ≥ 3 天时给出提示卡。
- **每日提醒（可选，默认关）**：本地通知（`flutter_local_notifications`，无需服务端），时间可设；内容是"今日任务卡"摘要，不打扰、不诱导。

## 5. 材料渠道（材料中心）：由软件供给真实材料

> 关键修正（用户 2026-09-22）：**这一块是"软件提供学习材料的渠道"，不是"让用户上传材料"**。用户导入只是补充入口。

### 5.1 内容源（2.0 全类别接入）

| 类别 | 具体源 | 获取方式 | 附加物 |
|---|---|---|---|
| 外刊 / 新闻 | BBC Learning English、VOA Learning English、NPR、公开新闻页面的 RSS（**全部无需 API key**） | RSS / 公开页面 + 正文提取 | 难度预分析、可选音频 |
| 外刊（可选后补） | The Guardian Open Platform（需免费 key，用户暂不引入） | 预留适配位，key 由用户后填 | 同上级 |
| 原版书 / 公版 | Project Gutenberg、Standard Ebooks（数万册公版） | 直接下载 TXT/EPUB | 分章、词频分级、覆盖率筛选、章节进度 |
| 播客 / 听力 | BBC 6 Minute English、VOA、TED Talks Daily、NPR 播客 | RSS 音频 + 公开转写稿（无稿则转写） | 音频播放、逐句稿、听写/跟读（v2.2） |
| 科普 / 学术 | Wikipedia（CC BY-SA，API）、arXiv（摘要/预印本）、NASA 等 | API | 摘要级材料、术语表 |
| 考试向 | **内置考纲词表**（四六级 / 雅思 / 托福 / 考研），真题由用户自备 | 打包进 assets | 目标词单、水平对标、"距目标还差多少词" |

### 5.2 版权与合规边界（硬规则）

1. 只抓取**公开可获取**内容；付费墙、需登录、`robots.txt` 禁止的一律不抓。
2. 保留出处、作者、链接、许可信息，UI 显著展示"来源"。
3. 仅个人学习使用，**不做二次分发**、不提供批量导出原文。
4. 本地缓存带有效期（新闻类 7 天，公版书长期），提供"清除缓存"。
5. 音频只做流式播放 + 临时缓存，不转存到公共位置。

### 5.3 材料元数据与预分析（入库时本地计算）

`kind / source / source_id / title / author / url / license / word_count / unique_words / cefr / flesch / coverage(按当前用户) / new_word_density / est_minutes / chapters / audio_url / transcript_ref / cached_at`

### 5.4 用户侧的三条入口

1. **今日推荐**：按 i+1 + 目标 + 偏好 + 近期主题去重，给 3 份候选（各带覆盖率与预计时长）。
2. **材料库**：分类/难度/主题/时长筛选 + 搜索；"按我的水平可读"过滤器（覆盖率 ≥ 95%）。
3. **我的导入（次要）**：粘贴文本 / 剪贴板识别 / URL / PDF·EPUB / 音频 / 拍照（现有识图走同一分析管线）。

## 6. 学习闭环与数据回流

```
材料中心（真实材料 + 预分析）
   ↓ 选材（覆盖率 95-98%）
读前：预热 5-10 个关键生词（点击即查/朗读）
   ↓
阅读器：点词即查（词典+AI释义+音标+TTS）/ 已掌握词不打扰 / 进度记忆 / 逐句跟读
   ↓ 拾词（带上下文入库，自动进 SRS）
读后：自动出题（生词填空 / 句子回译 / 听写）→ 正确率 + 错误标签
   ↓
复习调度（FSRS 到期队列）→ 复习结果回填记忆稳固度
   ↓
导师：诊断 → 调整任务与配额 → 换材料/换难度 → 回到"材料中心"
```

**每一步都产出可回流的数据**（这是 1.x 缺失的一环）。同样闭环也适用于"拍照识图"这条既有链路：识别 → 拾词 → 复习 → 在材料里再次遇到 → 标记"已巩固"。

## 7. 数据结构（dbVersion 11 起）

| 表 | 关键字段 | 说明 |
|---|---|---|
| `learner_model` | json, updated_at | 画像全字段 + source/confidence |
| `placement_tests` | taken_at, estimate, ci, detail_json | 词汇量测试历史 |
| `word_review` | vocab_id, stability, difficulty, due_at, last_review_at, reps, lapses, last_rating | FSRS 状态（vocabulary 表加列或独立表） |
| `materials` | kind, source, source_id, title, author, url, license, word_count, cefr, coverage, difficulty_json, cached_at | 材料元数据 |
| `material_content` | material_id, chunk_index, text | 正文分块（便于按章加载与缓存） |
| `material_progress` | material_id, position, minutes, lookups, picked_words, finished_at | 阅读进度 |
| `reading_sessions` | material_id/article_id, started_at, ended_at, words, lookups, wpm | 行为数据 |
| `quiz_results` | kind, ref_id, total, correct, detail_json, created_at | 读后测验/回译 |
| `error_tags` | source, tag, count, first_at, last_at, status | 错误档案（v2.1） |
| `tutor_tasks` | plan_date, kind, payload_json, done_at, result_json | 任务卡 |
| `tutor_messages` | role, content, tool_calls, created_at | 导师会话 |
| `tutor_memory` | kind, text, created_at | 长期记忆 |

迁移策略：全部为**新建表**（幂等 + 事务 + 启动自检，沿用 v1.9.0 的迁移骨架）；`vocabulary.mastery_level` 保持读兼容，同时初始化 `word_review` 初值（新词=未学，学习中=初学，已掌握=已巩固但到期时间按旧数据保守估计）。

## 9. 分阶段范围与验收

## 11. 风险与对策

| 风险 | 对策 |
|---|---|
| 外部内容源不稳定/改版 | 多源并存 + 本地缓存 + 明确的失败提示与手动导入兜底 |
| 版权/ToS | 只用公开源；保留出处；个人使用；不二次分发；提供"删除该来源"开关 |
| App 体积膨胀（词频表+缓存） | 词频表按需分包（首启动只装高频段）；缓存上限与 LRU 清理 |
| AI 成本 | 难度/覆盖率/时长全部本地算；AI 只做"判断与表达"；导师会话按需触发 |
| 模型输出不可控 | 固定 JSON schema + 校验 + 失败重试 + 兜底文案；禁止无证据断言 |
| 数据迁移风险 | 新建表 + 幂等迁移 + 启动自检 + 上线前跑"旧库→新库"回归测试 |
| 过度提醒打扰 | 每日提醒默认关；主动提示有频率上限（每天 ≤ 2 条） |

## 12. 已确认决策（2026-09-22）

| # | 事项 | 决策 |
|---|---|---|
| 1 | 每日提醒 | 页内主动 + **可选每日提醒，默认关**；首次进入导师页时询问一次（时间可设） |
| 2 | 外部 API key | **不引入需注册的 key**：外刊/新闻只用无需 key 的公开源（RSS/公开页面）；Guardian 适配位预留 |
| 3 | 词汇量测试长度 | **两种模式都做**：速测（约 5 分钟，只测词汇量）/ 完整版（约 10 分钟，含语法与阅读小题，用于更准的水平定位） |
| 4 | 音标与音频 | **英式 + 美式都给**：词条同时显示两套音标，TTS 音色可切换（默认跟系统） |
| 5 | 题材偏好 | **支持自选黑名单**（题材/关键词），材料推荐与导师选材一律遵守 |

### 附属设计（由上述决策推出）
- **提醒实现**：本地通知（`flutter_local_notifications`），无需服务端；每天最多 1 条任务摘要 + 每周 1 条周报；可在设置里彻底关闭。
- **双模式测试**：速测 = 词频分层 Yes/No（3 层 × 20 词 + 6 伪词）；完整版 = 分词频 6 层 × 20 词 + 8 伪词 + 5 道语法小题 + 1 段短阅读 3 题（语法/阅读只用于定位档位与错误标签，不计入词汇量估计）。
- **音标存储**：`vocabulary` 增加 `phonetic_uk` / `phonetic_us`；AI 补全与词典回填都写两套；无美式时回退英式并标注。
- **黑名单**：`learner_model.preferences.blocked_topics`（题材枚举）+ `blocked_keywords`（自由词），材料入库与推荐时过滤，命中时提示"已按你的偏好屏蔽 N 条"。
