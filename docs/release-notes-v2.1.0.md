## v2.1.0 — 复习真正开始"按记忆排",反馈变成可追踪的资产

这一版是 2.0 的第二阶段（**记忆与反馈**）。一句话概括：**复习不再靠你自己安排，错误不再靠你自己回想**。

### 🧠 一、复习页接入 FSRS（间隔重复内核）

打开「复习」默认进入 **今日复习**：

- **队列是算出来的**：从每个词的记忆状态（稳定度/难度/上次复习）出发 —— 到期的词按「**过期最久 → 记忆最脆弱**」排前，再用**复习优先**的配额补新词（复习吃满今天的预算就不加新词）
- **四档评分**替代原来的三档标记：**不认识 / 模糊 / 认识 / 太简单**；每次评分都会更新该词的稳定度、难度与下次到期时间（FSRS-4.5 算法）
- 先「先自己回忆」再看答案，避免"看一眼就当会了"
- 完成页给本轮小结（认识 X · 太简单 Y · 模糊 Z · 不认识 W）+ **未来 7 天负荷**（如 `12 / 8 / 15 / 3 / 0 / 0 / 0`）与建议（峰值 >60 会直接说"这两天别再堆新词，先还账"）
- 答「不认识」的词**自动进错误档案**、并立刻回到队列更早出现
- 原来的「自由复习」（按掌握度/日期筛选整库浏览）保留为第二个模式

**三种问法**（同一队列切换，检验"认得"→"能产出"）：

| 题型 | 怎么问 |
|---|---|
| 认词 | 看词想释义 |
| **拼写** | 给中文释义，拼出英文（判分忽略大小写/空白/连字符） |
| **听写** | 放发音，写出单词（可重听） |

### 📋 二、错误档案（把"我英语不好"变成"我时态错了 7 次"）

「我的 → 错误档案」：按考点聚合，显示**次数 / 首次与最近时间 / 来源**（写译批改、回译练习、读后测验、复习）/ 样例词；可「标记已改正」与「恢复为待处理」；标过已改正又犯的会显示**红色"复发"角标**；顶部一行汇总最该处理的是什么。

### 📈 三、每周报告

「我的 → 本周报告」：**本地生成**（不调 AI）的滚动 7 天复盘 —— 概览（学习天数/词数/分钟/新收词/复习词数/读完材料/正确率）、**亮点**、**下周建议**、**未来 7 天负荷条形图**；可一键复制为文本。亮点与建议**每条都带数字**（例："先清 60 个过期词，再加新词（每天 20 分钟大约能复习 150 个）"），不写"加油/继续保持"。

### ⚙️ 四、配额管理

「我的 → 学习偏好」新增**每日学习配额**：每天可投入时间（15/30/45/60/90 分钟）+ 每天最多加几个新词（含"**只复习不加新词**"）。这两个数字同时驱动复习队列与导师的今日任务卡。

### 🎧 五、听力播放（提前交付）

播客/TED 材料打开后顶部出现播放条：播放/暂停、**±15 秒**、**倍速 0.75/1/1.25/1.5**，**边听边看稿**；音频源连不上/下架会分别给出可读原因 + 重试。全 App 共用一个播放器（不会与单词发音打架），来电时正确让路。

### 📦 六、导出与备份（提前交付）

「我的 → 备份与导出」：**完整备份 JSON**（生词 + 复习进度 + 画像 + 偏好，**唯一可回导**）、**生词本 CSV**（Excel 可开）、**Anki 导入包 TSV**；支持**合并导入**（按词去重）与**覆盖导入**（先清空，需二次确认）。文件写到 `Android/data/<包名>/files/exports/`（免存储权限、文件管理器可见），也可一键复制/分享。**备份不含 API Key**。

### 🐞 本轮修掉的真 bug

1. **学习偏好页的黑名单从没存过**：此前点「保存」只写了朗读音色，题材/关键词黑名单根本没进模型（你自己选的"不想看的题材"其实一直没生效）；
2. **导出复习状态差一天**：用 24 小时窗口截断导致"距到期 4 天 23 小时"显示成 4 天，现统一按**自然日**（与复习页分桶同口径）；
3. **新建库缺双音标列**：全新安装靠启动自检补列，现已写进建表语句。

### ⚠️ 已知限制（诚实说明）

1. 「每日提醒」通知未做（需引入通知包 + Android 13 权限引导，你本轮未选）—— 当前用导师页的任务卡与断层提醒代替；
2. 逐句听写/跟读未做：RSS 音频一般没有时间轴，做不成自动切句；计划做"手动选段循环"的诚实版本，**不做假的发音评分**；
3. 桌面小组件与深色模式仍在排期（深色模式要替换全库硬编码灰阶，单独一版做干净）；
4. 旧词条的单音标不会自动拆成英/美两套（需重新触发 AI 补全）；
5. bbc_le / voa_le / ted / wikipedia 四个源在中国大陆网络下可能连不上（NPR / Gutenberg / arXiv 实测直连正常）。

### 想请你验证

1. 复习页：四档评分手感、到期队列顺序是否符合直觉、完成页负荷预测是否有用；三种题型（认出/拼写/听写）都试一遍；
2. 「学习偏好」里把新词上限调成"只复习不加新词"，看复习队列是否真的不再放新词；加几个屏蔽题材后确认 AI 推荐里那些条目**真的消失**；
3. 错误档案：故意拼错/答错几次，看是否聚合、能否标记已改正；
4. **换机演练**：导出完整备份 → 存到微信/备忘录 → 清 App 数据 → 粘贴恢复，确认词与复习进度都回来了。
