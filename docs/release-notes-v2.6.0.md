### 🔎 6(1) 识图"开盲盒" —— 先给你看提示词,再说问题

**原来的日常识别提示词(逐字,节选关键纪律)**:

```
2. 只输出有明确标记痕迹的内容;正文中未作任何标记的文字一律不要输出。
4. 如果不能确定某个内容是否被标记,宁可漏掉,也不要输出。     ← 这两条是元凶
```
校准重识别那档还写着「输出前自检…无法确认的删掉——**宁可少,不可错**」。

**我查到的机器侧问题(比提示词更致命)**:

| 问题 | 实测/文档依据 |
|---|---|
| 日常识别给豆包发的是 `detail: low` | 官方文档:`low` 会把图**压到 512×512** —— 书页小字和淡色划线直接没了 |
| 给 DeepSeek 根本不发 `detail` | 而 [9-10 上线的 V4.1-Flash](https://api-docs.deepseek.com/zh-cn/guides/vision) 明确支持 `low/high/original/auto` |
| 图片只压到 2000px / JPEG q88 | 两家服务端还会再压到 ~1300×1300 等效像素;有损压缩最伤"淡色细线" |
| 我的校验层会**静默丢条目** | 规则"被更长条目包含 → 丢弃":`credit` 遇上 `credit for humanity's successes`,`credit` 就消失了 |

**这版怎么改**:

1. **删掉"宁可漏掉"**,改成**"标记优先、宁可多收"**:拿不准的照样收进来,标成「待确认」(列表上有黄色小标),不要的你自己取消;
2. **默认档加"逐行清点"作业流程**:转正 → 逐行扫 → **输出前对账**(扫了几行 / 找到几处标记),这两个数直接显示在结果头部 —— 它有没有认真看,一眼就知道;
3. **图片清晰度**:2600px / q92 / **一律 `detail=high`**;
4. **加第二遍"只找漏"复查**:把整页切成 2×2 高清小块重看一遍(第一遍的整页会被服务端压糊),把已找到的词交给它"别重复",**只找漏的,结果追加**;
5. **校验层改"只补不删"**:包含关系不再丢;截断没得替换也不丢;例句缺失用证据行兜底并记账;结果头部可以点开看**每一类都动了什么**;
6. **例句不再丢**:`original_sentence` 改成必填,缺了补、补不上在头部报"缺例句 N 条";
7. **中文批注结构化**(你第 6(3) 条):中文批注现在是「**中文 → 对应英文 → 英文原句**」,不再是"中文——中文";
8. 顺带修:多图识别时**证据行 `line` 字段被丢掉**(导致"出现 ×2"与核对失效)。

> 诚实说明:准确率最终还得你拿真实书页回测。我这边能保证的是:提示词不再教模型偷懒、图片不再被压糊、复查遍会补漏、校验层不再偷偷丢东西。

### 📚 8(1)(2)(3) 材料中心

- **中文说需求就行**:不再弹"请用英文关键词"。你说中文 → AI 把它翻成公开源认的英文检索词 + **直接点名它确实知道的作品**(中英标题 / 作者 / 一句"为什么适合你"),再拿这些词去 Gutenberg / arXiv / 外媒真实检索;
- **原文链接🔗**:AI 点名的作品给**书目/摘要页链接**,点了用系统浏览器打开(新增 `app/open_url` 原生通道,零新依赖);链接纪律写进提示词——**不确定就留空,绝不编造 id**;
- **标题统一「中文(英文)」**:命中的英文标题会批量交给 AI 翻成中文译名,翻不出来就回落纯英文(整屏英文的问题解决)。

### 📖 8(4) 阅读器:翻译 + 点词两个动作

- 阅读器右上新增「**翻译**」:按段翻译,正文变**英文段落 + 中文对照**;段落数对不上就整批丢弃并说明(绝不把译文错位到别的段),失败可原地重试;
- 点词面板现在是**两个动作**:【**询问 AI**】【**收藏进单词本**】。「询问 AI」就地流式讲解(这一处的词性含义 + 搭配 + 同类例句,150 字内),不用跳页面。
