## 1. 「我的」名片

你列的三条都是真问题:

- **没法自定义名字** —— 上一版**压根没有"昵称"这个字段**,名片上根本没有名字。现在有,而且是卡上最大的字;
- **没法改背景图/头像** —— 上一版的编辑入口只是卡片右上角**一个灰色小铅笔**(你大概率没找到),而且背景只有 6 套写死的渐变、不能放图。现在**整张卡都能点**,右下角有醒目的「编辑名片」按钮;背景**既可选渐变也可以从相册选图**(选了图会自动压暗一层,保证白字看得清);
- **不够精美** —— 重排层级:头像(双环描边)→ 昵称(大字)→ 签名 → 三格数据行(带细分隔线,生词数/水平/每天时间)。编辑面板**带实时预览**:改名字、签名、头像、背景立刻看到效果,不用"保存了才知道长什么样"。

## 2. 输出练习(这条重做了)

你说的"完全只能说看上去有用",我按三件事补:

**① 目标需求(可多选)+ 水平现状**
目标给了一整套分类(四六级 / 考研 / 雅思托福 / 出国生活 / 学术工作 / 职场商务 / 兴趣阅读 / 看剧听口…),
**每个都写清"练什么"**(备考类偏长词与长难句,生活类偏高频道地短语),可多选;
水平除了软件内数据(词汇量基线、CEFR),**你还可以自己补充**(一句话写清你的情况)。

**② 三种模式都做,你自己选**(你的原话:"都需要,给用户提供选择")
- **跟计划走**:按目标生成 **4 周计划**(每周主题 + 每日题量),每天一个练习包;
- **今日练习包**:轻量,不建计划,想练多少练多少;
- **自适应**:按正确率动态调题量与难度(≥90% 加量加难、<60% 减量降难)。

**③ 进度追踪,看出完整方向**
练习中心显示:计划进度条(第几天/共几天)、**连续打卡天数**、累计题数、正确率、
**最近 7 次的正确率趋势**、今天是否达标。练习入口本身就带摘要
(如"计划第 3/28 天 · 今天已练 10 题 · 正确率 82%")—— 不用点进去就知道自己在什么位置。
每道题都给**判分依据**(拼写"完全正确"、翻译"词重合 6/9"),结束后给小结卡,
**错题自动放回今天的复习队列**,还能「只练错题」。

口语交流按你说的"先挂那",标了「开发中」并写清原因(要接实时语音与发音评分)。

## 3. 材料中心

**(1) "太满、要翻半天"** —— 每个功能区标题行**整行可点收起/展开**,收起时**不构建内容**
(长列表是真省掉,不是假装折起来);菜单里还能**隐藏**整个区块,右上角新增「区块管理」
用开关恢复 —— 隐藏不等于删掉找不回来。你调过的布局会记住,下次进来还是你排的样子。

**(2) 翻译进度 + 自选范围** —— 点「翻译」先让你选**范围**:当前段 / 前后各 3 段 /
当前章前 20 段 / 整篇;每一档实时算「共 N 段 · 约 X 分钟」,整篇超过 40 段会提醒可以随时取消。
开翻后底部出现**真实进度条**:「正在翻译第 3/40 段」+ 百分比 + 约剩几分钟 + 已用时间 + **取消**
(取消后已翻好的都保留)。已翻好的不重翻,失败的那一段可以单独重试。

**(3) 发现更多的分区** —— 现在**可以多选**(选了几种就一起搜,结果按链接自动去重合并),
也可以**自己加分区**(填中文名 + 英文检索词就行,长按自定义分区可删)。

**(4) 卡片 UI(你截图骂的那处)** —— 找到原因了:我把「软件内阅读」做成默认尺寸的大按钮塞进一行,
两个按钮加起来**超过卡片宽度**,右边那个被裁成「原」字,标题和元信息也被挤到截断。
现在:元信息独立一行、两个动作改**紧凑小按钮 + 自动换行**(窄屏换行,**永远不会再溢出**)、
封面缩小、整张卡可点进阅读器。

**(5) 阅读形式更丰富 —— 让 AI 按内容选形式** —— 阅读器底部新增「丰富形式」:
**表格 / 思维导图 / 时间线 / 要点卡 / 自测卡**五种。点「让 AI 推荐」它会**先说你为什么该选它**
(比如"这篇有 7 处数字/年份,适合做成表格对照"),再生成。
生成的内容**插在对应段落下面**(标注「AI 整理 · 基于第 N 段」),可删除、可重新生成。
思维导图是用自绘的连线画的,没引第三方库;表格窄屏可横向滚动,不会挤爆。

## 4. 阅读进度自动留存 + 同步到统计

阅读器里**翻段立刻存**,没翻页时**每 3 秒存一次**,退出再存一次;读完标记完成时间。
下次打开这份材料会问你一句:**「上次读到 38%(第 12 段),继续?」**(读完则问"再看一遍吗"),
给「继续 / 从头开始」两个按钮 —— **不会静默跳走**。

「学习统计」页新增**最近在读**卡(进度条 + 还剩几分钟 + 已收词数);"读满 5 分钟记一次阅读会话"
也修了一个坑:如果拿"每 3 秒落盘"的计时器去判 5 分钟,它永远归零、永远记不上 ——
现在用独立累计秒数,退出时补零头。本周报告读的是同一份数据。

## 5. 「我的学习材料」拆成两块

你说得对,它本质就是个词汇本。现在:

- **材料导入**(新):外部导入的材料本体。导入时(或导入后)给它一个**你自己的分类名**
  (比如「新视野教材」),以后就按分类找;分类可以重命名、可以解散(解散只解组,**材料都留着**);
  点一下直接进阅读器。支持 TXT/MD 文件、粘贴文本、图片识别、网页链接。
- **我的词汇本**:原有的教材/书籍/外刊/碎片文章/其他分类、按页码分组、整组删除/归入材料…
  **逻辑一个没动**,只是名字改对了。

## 6. 等待界面(你选的三套都用上了)

- **A 流式过程时间线** —— 有明确步骤的任务:检索(「Gutenberg 找到 10 篇 1/3」)、抓取、
  识图、批改、AI 整理内容。每一条都是**真实发生**的事;
- **B 骨架屏** —— 生成长文本的任务:先铺出"结果将要占据的形状",内容一到原地替换;
- **C 进度条 + 阶段 + 已用时** —— 能估算进度的:逐段翻译、批量分析,带取消。

三条硬规则:**只显示真实步骤**、**不造假进度**、**每步至少显示 600ms**;等待超过 8 秒会升级信息
(而不是让你干看着)。全 App 的 `AppLoading` 与处理中遮罩都换成上面三种 ——
**现在整个 App 只剩 1 个转圈**(音频缓冲)。
