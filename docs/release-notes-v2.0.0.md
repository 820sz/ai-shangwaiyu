## v2.0.0 — 从"工具集"变成"会指导你的学习系统"

这一版是 2.0 的第一阶段：**地基 + AI 导师 + 材料中心**。三句话概括变化：

1. 打开 App 先看到的不是"上传图片"，而是老师告诉你**今天该做什么**；
2. 学习材料**由软件提供**（外刊/RSS、公版书全文、播客、百科、论文），并且打开就算出**对你有多难**；
3. 你的水平不再是"收藏了多少词"猜出来的，而是**测出来 + 一路用行为数据修正**。

---

### 🎓 一、AI 导师（新的首页 tab）

底栏从三栏变四栏：**导师 / 输入 / 输出 / 我的**。

**诊断（每条都能指到数字）** —— 诊断是**在手机本地用规则算出来的**，不是让 AI 自由发挥：

- 「复习堆积：60 个词已经过期 —— 到期共 80 个，其中 60 个超过计划时间」（过期 >200 升级为红色"先清账"）
- 「生词本在变成收藏夹 —— 已收录 50+ 词，但一条复习记录都没有」
- 「近 30 天只有输入，没有输出 —— 读了 5000 词 / 120 分钟，但没有任何输出练习记录」
- 「《XXX》对你偏难 —— 覆盖率只有 86%，每 100 词有 14 个生词」
- 「重复出错：时态 —— 错误档案里 时态(7 次)、冠词(4 次)反复出现」
- 状态良好时给的是「把覆盖率目标从 98% 调到 95-96%」这种可执行建议，不是"保持节奏"

**今日任务卡**：自动生成 3-4 条，每条写明**时长**和**为什么派给你**；点「开始」直达对应功能；做完打勾会写进数据库（当天只生成一份）。

**问导师**：会话里带的是**结构化数据快照 + 本地已得的结论**，并硬性要求"先结论后依据、给可执行的下一步、数据不够就直说缺什么、禁止空话"；对话落库，重启还在。

**缺什么问什么**：顶部列出"还缺哪些信息"，用 chip 点选（学习目的 / 每天可投入时间 / 偏好题材），选完**立刻写入模型并重跑诊断**。

### 📚 二、材料中心（「输入」页顶部）

**7 个公开内容源，全部无需 API Key**：BBC Learning English / VOA Learning English、NPR、TED Talks、**Project Gutenberg（6 万册公版书全文，按章切块）**、Wikipedia、arXiv。

**打开即分析（本地算，不花 API 钱）** → 给你一张**读前卡**：
篇幅（词数 + 预计分钟）、难度（CEFR）、**已知词覆盖率**、**生词密度（每 100 词几个）**、**先认这几个词**；覆盖率 < 90% 会明确警告"这份对你偏难"。

**阅读器**：按块懒加载（整本书也不卡）；**点任何词** → AI 释义 + 音标 + 例句 + 语法点 + 朗读；**一键收进生词本**（收藏即进复习队列）；进度/用时/查词数/收词数全部落库。

**读后测验**：读完自动出 5 题 —— 完形填空（挖的就是材料原句，干扰项来自同一份材料的生词）+ 中译英回想（针对你拾取的词）。**全部本地生成、可复现**；错词回到复习队列并进错误档案。

**粘贴自备材料**：论文段落、字幕稿、教材内容直接粘进来，走同一条分析管线。

**版权边界**：只抓公开可获取内容、保留出处/作者/许可、仅个人学习使用、不提供二次分发、付费墙不碰。

### 🎯 三、水平不再是猜的

- **词汇量测试**：速测（76 题，约 5 分钟）/ 完整版（128 题词汇 + 5 道语法 + 1 段阅读，约 10 分钟）
- **伪词校准**：里面混了编造出来的词，全点"认识"会被识别出来，估计值反而更低；作答不可信时**不写入模型**（宁可没有基线，也不要一条错的基线）
- **结果给区间**而不是单一数字，并告诉你"**你在哪一档开始掉**"
- **学习者模型**：每个字段都带**来源（自报/测量/推断）+ 置信度** —— 自评不再和测量混为一谈

### 🔧 四、其他改进

- **英式 + 美式双音标**同时显示（只有一边时按老样式显示单音标）
- **朗读音色可切换**：跟随系统 / 英式 / 美式（「我的 → 学习偏好」）
- **题材与关键词黑名单**：不想看的题材、不感兴趣的关键词，推荐与导师选材一律遵守（新加屏蔽词后，旧缓存里被屏蔽的条目会立刻消失）
- **数据库 v11**：新增 10 张明细表（复习状态、材料、正文分块、阅读进度、阅读会话、测验结果、错误标签、导师任务/会话/记忆）+ 双音标列；旧生词的掌握度会转成复习状态（**保守到期，绝不设成"永不到期"**）
- **提前落地的复习内核**：FSRS-4.5 调度（稳定度/难度/可提取性/间隔）+ 今日复习队列（到期排序 + 复习优先的新词配额）；复习页 UI 在 v2.1 接上

### ⚠️ 已知限制（诚实说明）

1. **网络可达性**：中国大陆网络下 BBC / VOA / TED / Wikipedia 可能连不上（实测 **NPR / Gutenberg / arXiv 直连正常**）；连不上时给明确错误 + 重试，不会假装成功。
2. 「英式口音是否真的变声」取决于设备 TTS 引擎是否装了 en-GB 语音；切了没变化不会报错（会退回默认音色）。
3. 老词条已有的单音标不会自动拆成英/美两套 —— 需要重新触发 AI 补全或重新识别。
4. 阅读器的整句朗读暂未跟随音色设置（单词朗读已跟随）。
5. 复习页目前仍是原有的三档标记；FSRS 四档评分与到期队列 UI 在 v2.1 上线。

### 想请你验证

1. 导师页的诊断结论**是否让你信服**（有没有"说了等于没说"的）、任务卡时长是否合理；
2. 问导师几句，看它**会不会胡编数据**（编了就把原话发我）；
3. 材料中心打开一份材料的**读前卡覆盖率**与你的实感是否一致；
4. 阅读器点词查词的手感；收词后去复习页看**有没有真的进队列**；
5. 走一遍词汇量测试，看结果是否符合自我感觉（这是难度推荐准确度的起点）。
