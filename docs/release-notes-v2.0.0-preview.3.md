## v2.0.0 预览版 · 第 3 期：材料中心（软件给你找真实材料）

> ⚠️ 预览版（prerelease）。这一版补上 2.0 的另一半：**输入从哪来**。
> 导师告诉你"今天读什么材料",材料中心负责**真的把材料拿来**。

### 这一版能做什么

**「输入」页 → 材料中心**（顶部第二张卡）

1. **今日推荐**:7 个公开内容源,全部**无需 API Key**
   - BBC Learning English / VOA Learning English（带音频的英语学习栏目）
   - NPR（新闻）
   - TED Talks（音频演讲）
   - Project Gutenberg（6 万册**公版书全文**,按章节切块）
   - Wikipedia（百科条目）
   - arXiv（论文摘要）
2. **打开即分析**:点「分析并读」→ 抓正文 → **本地**算难度 → 给你一张"读前卡":
   - 篇幅(词数 + 预计分钟)、难度估计(CEFR)、**已知词覆盖率**、**生词密度**、**先认这几个词**
   - 覆盖率低于 90% 会明确警告"这份对你偏难,建议只精读前几段"
3. **阅读器**
   - 按块懒加载(整本书也不会卡);点**任何词** → 底部弹层:AI 释义 + 音标 + 例句 + 语法点
   - 弹层里可**朗读**、可**一键收进生词本** —— 收藏即建立复习状态,直接进复习队列
   - 进度、用时、查词数、收词数全部落库(导师诊断读这份数据)
   - 顶部常驻难度条(覆盖率/生词密度),底部「读完了」一键标记
4. **粘贴自备材料**:论文段落、字幕稿、教材内容直接粘进来,走同一条分析管线
5. **材料库**:已入库材料按"**今天最适合读**"排序 —— 在读的、覆盖率 95-98% 的排前面,过载的排最后

### 为什么这么做(设计取舍)

- **材料是软件给的,不是让你上传**:所以主入口是"从公开源拉真实材料",粘贴只是补充;
- **难度必须可验证**:不用 AI 嘴上说"B1",而是本地算"你已经认识这份材料 96.2% 的词"(依据词频表);
- **不碰版权红线**:只抓公开可获取内容,保留出处/作者/许可,仅个人学习使用,不提供二次分发;
- **点词即入库**:查词 → 收藏 → 复习队列是一条链,不是三个割裂的动作。

### 想请你重点验证
1. 打开一份材料后,那张"读前卡"的**覆盖率是否和你的实感一致**(这是本地难度引擎的第一次真机校准);
2. 阅读器里**点词查词**的手感与释义质量;
3. 收进生词本后,去复习页看它**有没有真的进队列**;
4. 材料库的排序是否符合"今天想读哪个"的直觉。
