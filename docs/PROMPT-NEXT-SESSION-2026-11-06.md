## §B 用户目标需求（更完整的原话与背景，供方案设计时对照）

- 前端审美：**高级、精美、不喧宾夺主、有逼格**；不要只做"大界面门面"，
  点进每个功能都要同水准；排版不能挤、文字不能难看、空间分布要合理；
- 交互：顶部大 UI 要随下滚收起/滚走，不要一直悬着；
- 材料中心：只有大分类入口，点进去再分子分类；分类可多选后推精准材料；
  "按需求"要影响**全局材料推送**，不只是某个页面；
- 找材料：要系统、完整、匹配用户填写需求；能找到教材（如新概念系列）、
  真题（如四六级系列）、书、论文、资料；**不要怕版权（个人学习用）**；
  找到的链接要能跳转/阅读，PDF 不能点不动；结果要能留到对应分类，不要每次重搜；
- 书架：参考"轻小说文库 3D 书架"（一排书脊 + 抽出一本看封面），
  同时保留详细书架（封面网格）；两形态可切换；
- 阅读器：用户已选**方案 A（沉浸纸面）**，不要再画饼，按 A 落并给真机效果；
- 材料库：浏览记录/外部导入分开；能编辑中文名、删除、隐藏、批量管理；
- 其他：听力不做；自用+朋友用、非商用；不要"测试全绿"当成果；不要每屏都发盲盒包。
