# ReadFlow v2.28.4 · 搜索准确性 + AI 改写体验修复

## 1. 原版搜不到 → 补搜「二手解析/书评/读后感」（核心）

用户原话：搜一本书/期刊，如果搜不到原版，应该搜**网上对这本书的二手解析、评价、读后感**，而不是沾边关键词的内容。

- 自由搜改为**两段式检索**：
  1) 第一段：按原版名/书名检索（AI 先把中文名翻成原版名）；
  2) 若结果 < 2 篇：AI 规划 2 条「书评/解析/读后感/作者观点解读」类英文检索词，**补搜第二轮**；AI 规划失败也会用模板兜底（`"Atomic Habits" book review` / `"Atomic Habits" summary analysis`）。
- 相关性更严：能确定原版书名时，**结果标题里必须出现书名/主题词**才算相关（不再因为摘要里有一个通用词就收），并在说明里写明"已丢弃 N 条与书名无关的结果"。
- 补搜到真实二手文章时，结果说明会写"原版没找到，已补搜「书评/解析/读后感」类相关文章 N 条"；两轮都没有才进入 AI 改写兜底。

## 2. 「生成 AI 改写」按钮文字不再被裁

- 按钮去掉固定高度，改为最小高度 + 内边距，系统大字号时文字完整显示（之前 42px 固定高度会把字裁掉一半）。

## 3. AI 改写选项弹层可滚动、按钮点得到

- 选项弹层改为 `isScrollControlled` + 最大高度 86% + 内部可滚动：大字号/小屏时也能滚到底部点「开始生成」。

## 4. 沿用 v2.28.3

- 字数/难度选项（默认不限字数、贴近原材料难度、覆盖优先）、覆盖要点显示、生成后字数不足自动重试一次；
- 按需搜接入 AI 英文检索词。
