# ReadFlow / AI上外语 v2.25.2 修复说明

> 真机反馈第三轮修复:书架 3D 布局 bug、追问抽屉双横杠、找材料质量提升。
> 阅读器改版先给 3 个设计预览(见 README 附图/仓库 docs),选定后再落实现。

## 1. 书架 bug(真机截图反馈)

- **3D 书架顶部大块空白**:高度公式把"书脊高度 + 封面高度"相加,实际是重叠的,
  已改为按最高书脊 + 底部搁板 + 封面露头计算,书一排贴近搁板。
- **筛选后只剩一本/其余书脊消失**:筛选/排序变化后选中索引仍指向旧列表,
  越界后布局塌掉;现在列表变化会自动回到中间那本并重新居中。
- **底部两条操作提示重复**:3D 视图自带提示,外层又加了一行,已去掉重复。
- 书脊宽度 24~34px、高度 150~200px,封面 168 高,3 本书也不会再出现
  "一大块空+一本大封面"的失衡。

## 2. 追问抽屉出现两条"横杠"

全局主题给底部弹层开了系统拖拽条,追问抽屉自己在内容里又画了一条,
真机上就是两条。已对追问抽屉关闭系统拖拽条,只保留内容里的那条。

## 3. 找材料效果提升(本版第一步)

真机上"按我的需求找材料"只找到 1 篇,且多是公版书里的泛内容。本版改动:

- **检索计划改为具体到系列/书名/考试名**,最多 6 条中英文混合 query:
  - 教材 → "新概念英语 第三册 课文"、"New Concept English 3"、"人教版必修一";
  - 真题 → "CET-4 历年真题 pdf"、"四级真题 2024 阅读";
  - 书 → 书名 + 作者;论文 → 主题 + survey;外刊 → 媒体 + 题材;
  - 明确允许中文 query(官方搜索能搜中文网页),公开源只用英文 query;
- **官方搜索从"只搜前 2 条"提升为最多 4 条 × 每条约 8 条结果**;
- **抓正文目标从 5 篇提升到 8 篇**,补救轮同样放宽到 4 条新 query;
- 结果偏少时明确提示"换一批再找",并给按钮;
- 输入框示例改为"新概念英语第三册 / 四六级真题 / 剑桥雅思"。

### 后续(研究结论)

- 版权限制:用户明确个人学习使用,所以检索层不再自我阉割;
- 渠道优先级:DeepSeek 官方搜索+fetch(服务端抓取,不受本机网络限制)> Project
  Gutenberg(可直连)> RSS 公开源;Internet Archive/OpenLibrary 本机不可达,
  只能走官方 fetch;
- 下一步:给"教材/真题"增加**结果分组**(教材/真题/书籍/论文/文章)与
  封面/册数识别;抓 PDF 正文时优先 DS fetch,失败再回退。
