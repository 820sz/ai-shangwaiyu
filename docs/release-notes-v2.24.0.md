# ReadFlow v2.24.0 · 明亮果冻（全 App 视觉重做）

> 用户 11/03 的要求：「前端必须高级、精美、不喧宾夺主、有逼格；不要只在大界面表面做，
> 点进每一个功能又是一坨屎」。这一版把**四个主屏 + 整个输入链路**全部按「明亮果冻」
> 重做，并保留/升级 AI 原生设计；功能与数据层不变（dbVersion 22 未动）。

## 更新内容

1. **四个主屏统一视觉**：输入 / 输出 / 我的 / 助理 全部换成主屏级果冻头图
   （渐变 + 糖果色块 + 大圆角 + 柔影），底部导航换成悬浮玻璃胶囊。
2. **输入链路全部内页重做**：材料中心、题材分类、书架、收藏、阅读器、拍照/相册导入、
   链接导入、识图结果、材料分组、生词本、词条详情、复习（FSRS）——不再有"白底 AppBar +
   大黑字"的旧皮；内页统一 `V4Skin` 的颜色/圆角/阴影，深色模式同样成立。
3. **阅读器 = 纸面批注**：正文区是 24 圆角白纸；段落译文从"左侧竖线灰字"改为
   **译文便签**（淡主色卡 + 「译」徽标），翻译中的段落用便签骨架而不是转圈。
4. **识图结果 = 扫描工作台**：顶部识别状态卡（连接中/逐行识别显示鲸鱼尾；完成显示绿勾 +
   识别词数 + 已选数 + 照片存档提示）；结果前加「校对清单」分组头。
5. **AI 原生件升级**（全部保留、只换皮肤）：
   - 思考过程：💭 → **鲸鱼尾**（你指定的思考形象）+ 果冻淡染卡 + 「思考中 · Ns」计时 +
     底部渐隐；
   - 流式输出：正文下加呼吸光标 + 「生成中…」；
   - AI 身份：品牌 Logo 白底托 + 淡描边（深色/糖果背景都能认出），错误/未知模型兜底不变；
   - 追问抽屉：身份行（标题 + 模型槽位胶囊 + 新建 + 历史）、渐变用户气泡、白卡 AI 气泡、
     胶囊快捷提问、圆形发送键。
6. **材料封面自动配图**：书用豆瓣书封、其他用 360 插图（实测可达），抓到即本地缓存、
   同标题永久复用；抓不到用程序化「印刷封面」兜底；AI 生图（方舟 Seedream，按张计费）
   是**可选兜底，默认关闭**，设置页「材料自动配图」三档可切换。
7. **输出练习可拍照提交**（第一步）：答题页（四阶练习器）不再只能打字 ——
   可以「拍照 / 相册」附答案图片，提交时先自动转写成文字再按同一套 rubric 批改；
   其余练习页（写句/词库/翻译/题库）随后扩展到同一能力。

## 安装

- 只发 arm64（`app-release.apk`，约 26.4MB）。
- 手机允许「安装未知来源应用」后直接安装；App 内「检查更新」也会提示这一版。

## 验证

- `flutter analyze`：0 error / 0 warning（8 条存量 info）。
- 全量测试：1594 passed + 1 skip + 1 已知假失败（`profile_card_test`，Hive 假时钟问题，
  与本次改动无关，交接文档已标注）。

## 已知取舍

- 360 插图缩略图约 240px：列表够用，大图位偏糊；后续可"大图优先原图 + AI 生图"。
- AI 生图需要你在设置里填入方舟 Key 才会启用；默认关闭，不会产生费用。
