## 更新内容

1. **材料中心入口，任何状态都能一眼看到**：输入页标题右侧新增实心「材料中心」按钮；标题下方新增「按题材找材料」横滑区（科学与技术/商业/健康/文化/旅行/语言），点一个题材直接进对应分类页。
2. **输入首页重做**：标题区改成「日期眉标 + 大标题 + 一句话引导」；继续读卡从「小图 + 两行字」升级成阅读海报（大封面带投影、真实进度条、已读/覆盖率/时长胶囊、接着读 + 材料中心两个按钮）；拍照/链接导入从两个整宽大按钮改成两张等宽动作砖（主行动实心、次行动描边），整屏不再是"白底 + 大蓝块"。
3. **封面重做**：小封面（书架/列表/继续读）不再塞「随着疫」这种截断短语，改成单字标（字母书脊感）；大封面保留标题、排版更稳。标题交给卡外文字后，列表干净很多。
4. **写题页（写篇/写段/写句/写词设置页）**：顶部改成带阶位图形的引导卡，说清"这一阶练什么"；材料出题卡减小封面、标题两行截断、元信息压成一行，不再堆三行小字。
5. 材料中心本身没删——只是上一版入口藏得太深（继续读卡里一个"换一份"文字键），这是这次被骂"找不到"的直接原因。
