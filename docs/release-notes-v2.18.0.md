# ReadFlow v2.18.0 · 助理重做：五维现状 + 可编辑任务 + 复盘；输出数据回流闭环

> 批 3 收尾 + 批 4（2026-11-01）：把输出的数据接回错误档案/助理/周报，
> 并把助理从"行为债提醒"改成"五维现状 + 可编辑任务 + 有数字的复盘"。

## 更新内容

1. 助理首页改成五维现状：词汇 / 语法 / 阅读 / 输出 / 习惯，每个维度先给能核对的数字或状态，再给依据和下一步动作。
2. 还没测过的维度显示「待测 + 怎么测」，绝不编数字；点一下就能去测。
3. 学习任务可编辑、可自定义：能改标题与时长，能开始 / 完成 / 跳过 / 撤销，每次操作都留记录。
4. 新增「近 7 天复盘」：计划几条、完成几条、完成率、时长偏差，每条结论都带数字；连续两周对比看得出进步。
5. 需求询问支持多选目标（如「四六级 + 兴趣阅读」），自由补充的内容不再被丢弃；改完后材料推荐、题目难度、助理建议都跟着变。
6. 输出数据回流：写译批改与练习的错误会写进错误档案，助理不再说「近 30 天只有输入没有输出」。
7. 周报新增「本周输出」：输出练习次数、rubric 均分与较上周变化、维度均分、错误热点 top3；没数据时明确写「本周没有输出练习」。
8. 错误热点按既有标签体系归并（时态/冠词/介词/主谓一致/虚拟语气/词汇），不再让几十种近义写法把统计撕碎。

## 技术细节

- dbVersion 21 → 22：新增 `ability_snapshots`（五维能力时间序列，同维度同日 upsert）与 `task_events`（任务审计，只追加）；`tutor_tasks` 扩 7 列（origin/status/started_at/actual_minutes/note/parent_id/goal_tag），老数据按 `done_at` 幂等回填为 done，三通道建表自愈。
- 输出回流：`output_feedback.dart`（模型自由文本 → 既有 error_tags 归一，归一不上丢弃；`outputSnapshot` 聚合次数/均分/题型/维度均分/错误热点）+ 快照新增输出字段（output_attempts/drill_logs/writing_logs 三张以前完全没进快照的表）+ 周报输出块 + 写译批改 `recordErrorTags` 接线。
- 助理：`tutor_insights.dart`（五维现状/任务建议/复盘，纯逻辑 42 条测试）+ `tutor_snapshot.dart`（一次组装、每块降级、能力快照落库）+ `tutor_home` 五维卡片与任务状态机 UI。
- 完成任务率口径：`done / (done + skipped + expired)`（跳过与过期算未完成，pending 不进分母）；无已结算任务时不显示 0%，显示「先完成 1 条」。
- 验证：`flutter analyze` 0 error / 0 warning（9 条存量 info）；全量测试 **1442 passed + 1 skip + 1 已知假失败**（`profile_card_test` 的 Hive 假时钟问题，与 App 无关）。
