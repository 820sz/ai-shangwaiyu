## v2.0.0 预览版 · 第 1 期：地基 + 词汇量测试

> ⚠️ 这是 **预览版**（prerelease），不是 2.0 正式版。2.0 的主体（AI 导师 tab、材料中心、复习内核）还没做，本版只交付**地基**和其中你能立刻上手用的一块：**词汇量测试**。
> 装它 = 提前帮我验证地基（尤其是"离线难度计算"和"数据库迁移"这两件在真机上才见真章的事）。

### 这一版能做什么

**「我的」页 → 词汇量基线卡片**
- **速测（约 5 分钟）**：76 道"认识 / 不认识"；里面混了少量**编造出来的词**，用来校准自评虚报
- **完整版（约 10 分钟）**：128 道词汇 + 5 道语法小题（答完立刻给解析）+ 1 段短文 3 题
- **结果页**：认识约 X 词（**区间**而不是单一数字）→ 对应档位（A1–C2）→ **"你在哪一档开始掉"**（各档命中率条）→ 自评偏差提示
- 结果自动写入**学习者模型**，之后导师与材料推荐都以它为基线
- **保护机制**：如果伪词误报过半（乱点/看错题）或没测出有效基线，结果**不会**写入模型 —— 宁可没有基线，也不要一条错的基线

### 地基（本版真正的重头戏）

| 能力 | 说明 |
|---|---|
| **离线难度计算** | App 内嵌 5 万词频表 + 干净 1 万词抽样池（约 700KB），**完全本地算**：已知词覆盖率、生词密度、CEFR 估计、Flesch 可读性、预计阅读时长。不联网、不花 API 钱、结果可复现 |
| **词汇量测量** | Yes/No 词汇测试 + 伪词校准（Meara & Buxton 方法）+ 二项近似置信区间 + 低档全错时自动跳过更高档 |
| **学习者模型** | 每个字段都带**来源（自报 / 测量 / 推断）+ 置信度 + 更新时间**：自评不再和测量混为一谈；v1.8 的老画像自动迁移并标注为"自报" |
| **数据库 v11** | 新增 10 张明细表（复习状态 / 材料 / 阅读进度 / 阅读会话 / 测验结果 / 错误标签 / 导师任务 / 会话 / 记忆…）+ 英式美式双音标列；迁移幂等、带启动自检；旧生词按掌握度初始化复习状态（**保守到期，不设"永不到期"**） |

### 验证
- `flutter test`：**297 例全绿 + 1 skip**（v1.9.1 为 195 例）
- `flutter analyze`：**0 error / 0 warning**（24 infos，与 2.0 之前持平）
- 数据库迁移用**真 SQLite** 测试覆盖三条路径：全新安装 / 从 v10 升级 / 重复打开幂等

### 已知局限（诚实说明）
1. CEFR 映射与难度阈值是**一阶近似**，还没用真实用户数据校准 —— 上线后会按你的实测回标。
2. 词形归一是启发式（不规则形式 gone/children、派生词 happiness 不还原），所以覆盖率偏保守（宁可高估难度）。
3. 词频数据来自 OpenSubtitles 语料（字幕register），书面语材料的生词判定会略偏严；换成 NGSL 等词表只需替换 `assets/data/` 下的文件（已在 `assets/data/README.md` 写明）。
4. 导师 tab、材料中心尚未实现 —— 本版词频与难度能力先在测试页与模型层落地，等它们接上去。

### 想请你重点验证
1. **速测 5 分钟是否真的能在 5 分钟内做完**、单词显示是否够大够清楚；
2. **测出来的词量是否符合你的自我感觉**（这是校准的起点）；
3. 完整版的语法题解析看得懂吗、阅读篇幅是否合适；
4. 结果页"你在哪一档开始掉"是否直观。
