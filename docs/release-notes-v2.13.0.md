## 二、识图(你第 1 条)

1. **横幅/横置图准确率极低** → 现在本地会**自动判断内容是不是被横放了**:
   用"文字行投影"判断(文字竖排时列方差显著大于行方差),横放就自动转正再送模型。
   局限我写在代码里:分不出 0°/180°(倒置由 EXIF 和模型兜底)。
2. **下划线批注识别率低于圈框** → 两手:
   - 本地加**淡色划线增强**(轻对比度 + gamma,只对"识别标记"生效,不影响翻译的清晰度);
   - 提示词加**下划线专项**:明确告诉模型"线在词正下方 1~6 像素、常只有半截、颜色很淡,
     逐词扫时视线要在每个词下方停一下;一行两个词被划线就输出两个"。

## 四、写译批改(你第 3 条,三个子需求全做)

1. **手写档可以直接批改**了(不再强制转电子档):照片下并列两个入口
   「先转电子档」「直接批改手写图」;直批会选能看图的模型,结果里带回识别原文供你核对;
2. **每条错误都能点开追问**:整条错误卡可点,自动带上"第几条 + 分类 + 原句 + 建议 + 解释"

3. **预设提示词可看可改 + 思考强度可选**:批改按钮上有「批改设置」,

## 五、材料中心(你第 4/6 条:这次是结构重构,不是换皮)

- **需求放在最前面**:首页第一块就是「我的需求」卡(没设过会引导你花 10 秒设),
  所有材料都按它来;「个性化找资源」不再是最下面的第 7 块;
- **首页只留大分区**:我的需求 → 今日精读(大图卡)→ **按分类找材料(2 列分类卡)**→
  今日推荐(横滑)→ 书架(真书架)→ 材料库(横卡)→ 更多找法(低频,收进弹层);
- **子分区全在二级页**:点任意分类进 `分类页` —— 题材说明 + 内容源筛选 + 材料列表 +
  "用中文说需求让 AI 去找";首页不再堆内容。
