## v2.2.0 — 听说练起来,数据带得走,晚上看得清

这一版是 2.0 的第三阶段(**听说与生产力**)。三件事:**能听能写**(听力播放 + 听写练习)、**进得去出得来**(阅读包导出)、**看着舒服**(深色模式)。

> v2.1.0 的复习 FSRS / 错误档案 / 周报 / 导出备份都还在,本版是在它们之上继续长。

### 🎧 一、听力播放(边听边看稿)

播客 / TED 材料打开后,顶部出现播放条:

- 播放/暂停、**±15 秒**、**倍速 0.75 / 1 / 1.25 / 1.5**
- **边听边看稿**:音频在放,文字在下面,点词照样能查
- 音频下架 / 连不上会分别给可读的中文原因 + 重试按钮,不静默失败
- 全 App **共用一个播放器**(不会和单词发音打架),来电时正确让路,离开页面自动暂停

技术说明:为了让"听"和"读"对齐,本 App 用系统 TTS 与材料音频两条线 —— TTS 那条线文字与音频天然对齐,所以能客观判分(见下)。

### ✍️ 二、听写练习(有判分依据的那种)

材料页右上角耳机图标 → **从正文里抽 5 句**,系统朗读(可**慢速 0.35**),你打字,交卷后**逐词判分**:

- 用 LCS 逐词比对你的输入与原文 → **正确率 + 漏了哪些词 + 语序提示**
- 每句给分 + 一轮总评;没听出的词可以**一键收进生词本**(入库即进复习队列)
- **诚实边界(写在页面上)**:只判**文字**,**不评发音** —— 没有语音识别就不编造发音分

### 📚 三、阅读包导出(Markdown,带来源与生词表)

材料库现在**不只是进得去**:

- **单篇导出**:阅读器右上角下载图标 → 一个 `.md`(元信息[来源/原文链接/版权许可/难度/覆盖率/预计时长] + 正文分段 + 这篇的**生词表**)
- **整库导出**:「我的 → 备份与导出 → 阅读包(全部材料)」→ `exports/阅读包-<时间戳>/` 里一篇一个文件,可直接丢进网盘或笔记软件按篇管理
- 文件名做了安全化(去掉 `/`、`:` 等路径字符并限长),导出失败给中文原因 —— **不会悄悄写个空文件**

### 🌙 四、深色模式

「我的 → 外观」:**跟随系统 / 浅色 / 深色**,页面里带实时预览,选完立刻生效(不用重启)。

深色不是"把浅色反过来",这次按三条原则重做了一套配色:

1. **底色不用纯黑**(#12141A):纯黑上放白字会发光晕,长时间读更累;正文用 #E6E8EC 而不是纯白;
2. **层次靠亮度差**:深色下阴影几乎看不见,所以卡片(#1B1F27)和输入框(#262B35)都比页面**亮**一档,层级关系和浅色版一致;
3. **主色换成亮蓝**:浅色的主色是近黑,放深底上等于隐形;深色下实心按钮是"亮底深字"(Material 3 规则),保证对比度。

配套做了一件容易被忽略但很关键的事:**把全库 35 个文件里约 170 处"浅色专用硬编码颜色"清干净了**。

- 次要文字 / 标签 / 音标 → 主题的次要文字色;**正文、单词、释义 → 高对比正文色**;边框 → 主题描边色;浅底块 → 主题填充色
- 淡彩色面板(比如 `blue[50]`、`amber[50]`)改成**半透明色相**:浅色下观感几乎不变,深色下不会变成一块近白亮斑
- 只保留三类写死的颜色:图片上的叠加角标(黑白是刻意的)、全屏预览遮罩、成绩/词型/掌握度等**语义色**

并加了一道**闸门测试**:扫全库源码,禁止灰阶极端档位与淡彩色阶再次出现 —— 以后新增页面不会再"浅色下好看、深色下一块白"。

### ⚠️ 已知限制(诚实说明)

1. **桌面小组件未做**:需要写原生 AppWidget + 插件 + 真机反复验证,我这边看不到你的桌面效果,想单独一版和你配合做(先把内容定下来:今日任务 + 待复习数?);
2. **跟读未做**:没有录音 + 语音识别就没有可信的发音评分,不做假分数;
3. **每日提醒未做**:需要引入通知包 + Android 13 通知权限引导(你上轮未选);
4. 深色模式下**启动闪屏**跟随的是**系统**深浅色(Android 窗口主题只能在"系统夜间模式"里切):如果你把 App 固定为深色、而系统是浅色,启动瞬间会看到一帧白底 —— 这是系统层面的限制,不是 App 内配色问题;
5. bbc_le / voa_le / ted / wikipedia 四个源在中国大陆网络下可能连不上(NPR / Gutenberg / arXiv 实测直连正常)。
