# ReadFlow v4 · 视觉重做计划（用户 2026-11-02 22:3x 定案）

> 用户原话：「现在这个前端都烂得我毫无使用后端的欲望」——前端体验是**使用欲望**的前提，
> 不是"最后美化"。本计划放弃"缝补式发版"，改为**先换共享组件、再逐屏重排**，
> 每组的成果先渲成 PNG 给用户过目，四组全过才出 APK（v2.25.0）。

## 一、用户明确的需求（最终版，勿再自行解读）

1. **软件必须有大变化**：一眼能看出与旧版不同；不接受"多了个按钮"式的版本。
2. **不止主屏**：点进每一个功能都不能是旧样式；内页同样要重排。
3. **前端要"史诗级"**：有色彩、有层次、有设计感；具体可验收：
   - 有彩色头图/主题色，不是白底 + 大黑字；
   - 主次分明，一眼知道点哪；
   - 每屏加载态/空态/错误态齐全且统一；
   - 全 App 同一套颜色/圆角/字号，不出现"这屏一个样"。
4. **材料中心必须显眼**：任何状态下输入页第一眼可见（上版把它藏进"换一份"，是事故）。
5. **封面不能丑**：小封面不再放截断短语（「随着疫」），改单字标/图形。
6. **不再按功能清单交差**：功能已足够，后续只做视觉与体验，不再"补数据层"。
7. **听力不做**（用户明确）。
8. **交付方式**：先看图（PNG），认可再打包；不让用户装盲盒。

## 二、现状（2026-11-02 夜）

- 已发 10 版（v2.14 → v2.23）：功能/数据闭环基本完整（1577 测试通过）。
- v2.24.0 代码（未打包）：输入页头部/题材横滑/继续读海报/拍照·链接动作砖/小封面单字标/写篇设置页引导卡/输出页同款标题。
- **病灶**：视觉语言未变（白卡 + 黑标题 + 蓝按钮）；内页未动；材料中心入口曾不可见。
- 已有可复用资产：`design_tokens`（圆角/字阶/阴影/间距）、`app_ui`（AppCard/AppStagger/AppEmpty/Skeleton）、
  `design_kit`（AppTag/AppHeroCard/AppWideCard/AppStat/AppProgressRing/AppSectionHeader/AppContentTabs/AppEmptyState）、
  `graphics/`（13 域图形、7 类封面、空态插画、数据图形、域色 `GraphicDomain`）。

## 三、方向：两层施工

### 第一层：共享组件 v4（改一处，全 App 变）
新增 `lib/widgets/v4/v4_kit.dart`（不破坏旧组件，逐屏迁移）：
- `V4HeroHeader`：渐变头图（域色/主色），眉标 + 大标题 + 副标题 + 右侧主行动；
- `V4StageCard`：四阶阶段卡（阶位色渐变 + 进度环 + 直接开始）；
- `V4ActionTile`：彩色动作砖（图标 + 标题 + 说明，主/次两态）；
- `V4TopicTabs`：题材 tabs（彩色图标胶囊，选中实心）；
- `V4StatBlock`：统计数字块（域色数字 + 标签 + 可选趋势）；
- `V4ListCard`：内容列表卡（封面/图标 + 两行 + 尾随）；
- `V4SectionTitle`：区块标题（编号 + 标题 + 右侧动作）；
- `V4Empty` / `V4Skeleton` / `V4Error`：状态三件套。
其余：`AppCard` 默认外观微调（描边 + 表面层级）作为过渡；全部迁移完后旧组件只留兼容。

### 第二层：分四组逐屏重排（每组出 PNG → 用户过目 → 下一组）

**第 1 组 · 输入链路**
输入首页、材料中心、题材分类页、书架、收藏、今日精读、阅读器（正文/翻译/目录/字号行距/查词卡/追问）、
拍照/相册导入流程、链接导入、识图结果、材料分组、词汇本列表/词卡/复习。

**第 2 组 · 输出链路**
输出首页（四阶阶段卡）、四阶设置页、答题页、批改结果页（rubric + 折算档）、写译批改工作台、
题库、练习中心弹层、真题抓取、旧计划页（保留但同皮肤）。

**第 3 组 · 助理链路**
助理首页（能力趋势 + 结论卡）、现状分析、任务列表/详情/编辑、复盘、聊天、水平测试（入口/答题/结果）。

**第 4 组 · 我的链路**
我的首页、统计、周报、学习偏好、API 设置、错误档案、写译记录、备份与恢复、关于/更新/反馈。

## 四、验收标准（每屏都要过）

1. 有主题色/彩色头图或色块，不是白底一片；
2. 主次分明（标题 > 内容 > 元信息），一眼知道点哪；
3. 加载态/空态/错误态齐全、风格统一；
4. 全 App 同一套颜色/圆角/字号/间距（走 `design_tokens` + `v4_kit`）；
5. 内页与主屏同一视觉语言；
6. 深色模式可用、对比度达标；系统"减少动态"生效。

## 五、交付流程

1. 每组的界面用假数据渲成 PNG（`test/ui_v4_preview_test.dart` → `build/ui_preview/`）；
2. 在对话里直接发图，用户逐组确认/骂；
3. 四组过完 → 全量 analyze/test → 打包 v2.25.0 → 桌面 + GitHub Release；
4. 装机后仍有图不对，按屏继续改并重渲，不打包盲盒。

## 六、明确不做

- 听力入口（用户不做）；
- 新增功能（除非视觉重做必须）；
- 改数据库结构（dbVersion 保持 22）；
- 后台/数据层大改（备份、能力快照等已闭环）。
