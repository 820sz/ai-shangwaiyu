# ReadFlow v2.20.0 · 输出练习可以「按自己的目标」选素材了；其余屏统一

> 批 5 + 输出练习来源扩展（2026-11-02）。这一版解决两件事：
> ① 输出练习不再只能从"读过的材料"出题；② 我的/统计/设置/书架/收藏/错误档案/写译记录全部换到 v3 视觉。

## 更新内容

1. 写词阶新增「按你的目标练」：不读材料也能练内置考纲词（四六级高频 / 外刊高频），中译英拼写，答错自动记进错误档案。
2. 写句阶新增「作文范文句」：给中文译文写英文原句（英中对照、离线可用），练完按回译 rubric 批改。
3. 写段阶新增「范文段落」：模仿结构与句式写段落，按评分标准批改。
4. 写篇阶新增「四六级作文题」：内置真题风格题目 + 参考要点 + 字数要求，按写作 rubric 评分。
5. 练习来源会按你自己的目标排序：选四六级就先看到四六级词/范文/作文题，选外刊就先看到外刊高频词；没有设目标也能练（全部来源可选）。
6. 写词阶同时保留「复习我的生词本」入口，两条路并存，不强迫走哪条。
7. 我的页重做：学习概览大卡 + 活跃率环形 + 近 7 天柱状图，学习曲线单独成卡。
8. 统计页重做：趋势线 / 柱状 / 热力日历 / 环形进度统一换新版图形，标注统计口径，无数据给空态。
9. 学习偏好页重做：学习目标改为多选，保存后真的写进画像；难度档与材料中心同一份数据。
10. API 设置重做：主/副槽位统一形态，并逐项说明"没配 Key 时哪些 AI 功能不可用"。
11. 书架 / 收藏夹 / 错误档案 / 写译记录统一卡片与信息层级，空态换成插画并给下一步动作；删除类操作统一二次确认。

## 技术细节

- 新增 `lib/services/output_bank.dart`：内置素材库（四六级高频词 ~200、外刊高频词 ~70、作文范文句 12、范文段落 6、作文题 10）+ 纯选择逻辑（按目标排序 / 可复现抽词 / 题组构造），离线可用、不花钱、不依赖模型。
- 新增 `lib/screens/output/word_bank_drill_screen.dart`：写词拼写练习器（首字母+长度提示、结果页正确率与错词清单、可再来一轮）；答错写 `output_attempts` 并记「词汇」错误标签。
- `practice_setup_screen` 增加「按你的目标练（内置素材）」区块；写词卡从"直接进复习"改为"进练习来源选择页"（复习入口保留在页内）。
- 其余屏统一只改 UI 层，不动数据层与数据库结构；使用设计 tokens/组件，`theme_test` / `ui_copy_lint_test` 双闸门通过。
- 验证：`flutter analyze` 0 error / 0 warning；全量测试见随包报告。
