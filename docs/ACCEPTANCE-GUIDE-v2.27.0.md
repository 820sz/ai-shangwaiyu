## 0. 安装 / 首次打开

- [ ] 覆盖安装成功，打开 App 不闪退
- [ ] 输入首页：顶部「找材料」动作砖（原来叫「AI 找材料」）——**点它应进新的「找材料」页**（两张并列大卡），不是旧的 AI 找材料页

## 1. 阅读器（本轮重点，选型 C + 纸张三色 + 真实进度%）

- [ ] 从书架/材料中心/找材料任选一篇开始读：**没有顶部 AppBar、没有底部图标栏**；顶部只有返回圆钮 + 刊头（READING · 栏目 / 28px 大标题 / 署名行 / 双线）；底部只有「% 已读 + 抓手 + 上滑工具」
- [ ] **上滑**底部把手（或点「上滑工具」）：弹出「阅读控制台」4 组——进度卡（已读 % / 第 N 段共 M 段 / 继续阅读）、学习（翻译/追问/收词）、目录（3 行 + 本节 %）、材料（字号行距 / 模型思考档 / 导出·听写·读完）
- [ ] 控制台「材料 → 字号与行距」或阅读设置：能看到 **5 档字号 / 3 档行距 / 纸白·米黄·墨夜 三个色卡 + 实时预览**；点米黄/墨夜 → **整页立刻换纸**；
- [ ] 退出阅读器重进：**纸色保留**
- [ ] 上下滑动：**右上角 % 与右侧竖轨、底部细线连续变化**；退出重进 -> 续读弹层显示上次百分比，确认后回到相应位置
- [ ] 翻到文末：进度接近 99%，不会假 100%
- [ ] 长按选词 / 点译文 / 查词弹层：颜色是砖红/纸色体系（无旧蓝色大按钮）
- [ ] 阅读器内不出现「满屏下划线」：只有生词有砖红下划线

## 2. 找材料（本轮重点，选型 A）

- [ ] 输入首页点「找材料」（或材料中心「找材料」卡）→ 首屏：34px「找材料」标题 + **两张等宽大卡**（自由搜 / 按我的情况找）+ 最近搜过 chips + 上次结果卡 + 右上「历史」
- [ ] **自由搜**：进页 → 输入关键词回车 → 出现搜索过程（可折叠）→ 结果按类型分组、**每页 10 条**、底部页码「上一页 / 第 X/Y 页 / 下一页」、滚到底有「继续找更多」
- [ ] 筛选项：来源（9 个，5 个标"实测可用"）/ 类型 5 类（书籍·论文·外刊新闻·播客·百科）/ 难度 4 档（标注"按来源预估"）/ 场景 4 个 —— **都能点、都有反应**
- [ ] 结果卡：有真封面才显示图；没有封面是「标题+来源/类型/难度」文字卡；「开始读 / 保存到我的 / 打开原文」三个都可用
- [ ] **按我的情况找**：进页看 4 行依据（难度档 / 学习目标 / 弱项 / 最近阅读）；没数据的地方显示「待测」**不显示数字**；点「按这些条件找材料」→ 结果页；每张卡若有「为什么推:难度 xx%…」说明是补抓过正文算过覆盖率的
- [ ] 「历史」：能看搜索历史、点一条回填、清空

## 3. 助理 / 我的（B 每日简报 + A 诊断台）

- [ ] 我的首页：日期刊头 + 名片（暖纸白卡：眉标/砖红铅笔/三栏）+ 本周柱状 + 本周报告入口
- [ ] 点进：统计 / 本周报告 / 错误档案 / 任务详情 / 复盘 / 写译记录 / API 设置 / 备份 / 关于 —— **每个内页顶部都是果冻圆角 AppBar**（不再有黑色直角默认 AppBar），无空白屏、无骨架屏卡住
- [ ] 任务详情：开始/完成/跳过/撤销/编辑 能点、状态会变（真写库）
