## 更新内容

1. 写词阶新增「从读过的材料练词（语境填空）」：在你读过的句子里挖掉生词，四选一补回来；目标词来自你的生词本，干扰项来自同一篇文章里的真实词。
2. 难度档有了软件辅助调整：读完率/查词密度/读后测验正确率两两印证后，输入首页与材料中心会给出「建议调到 i+X」并附真实依据，你点一下才生效，不想改就不改。
3. 考纲词表上线：四六级/考研/雅思/托福词表已内置（859 词精选），写词阶会按你的目标出现「按四级/考研/雅思词表练」；助理「词汇量」维度会显示距目标词表还差多少词。
4. 写译批改接入统一评分标准：新增「写作 / 翻译」类型选择，结果页给出维度分（每维带依据）与折算四六级官方档位；旧评语、逐条点评、收藏、追问全部保留。
5. 写译批改记录同时进入输出统计，与输出练习同一套口径（可在统计/周报里看到写译产出）。
6. 修复助理「开始」按钮会先把任务标成完成的问题（上一补丁版已修，本版一并纳入）。

- 难度辅助调整：`input_prefs.dart` 新增 `BandSignals/BandAdvice/loadBandSignals/loadBandAdvice/applyBandSuggestion`（只读展示层，算法阈值未动）；`BandAdviceBanner` 两屏共用，条件不满足时零高度；新增 15 条测试（含真 SQLite 口径）。

- 写译批改：`write_review_screen.dart` 接入 `buildScoringPrompt`（先依据后分数）+ `parseScoringResult`；写作→cet4_writing、翻译→cet4_translation；维度分 + 折算档位展示；解析失败回退旧解析，不白屏；rubric 明细并入 `output_attempts.score_json`。
