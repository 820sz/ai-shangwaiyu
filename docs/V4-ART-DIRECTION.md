# v4 美术方向（Art Direction）：一本会动的杂志

> 用户 2026-11-03 的要求：前端「既高级、精美，又不喧宾夺主、有逼格」；
> 可以炫技，但技术要为内容服务；内容呈现要舒服，同时不失丰富性。
> 这份文件回答"我想做怎样的前端"。

## 一、一句话主张

**静态时像一本干净的杂志，操作时有细微的物理感，色彩只交代身份与行动。**

- 内容第一：界面是舞台，不是海报墙。视觉重音只给三件事——**身份（在哪个域）、行动（该点哪）、状态（进展/结果）**。
- 高级感来自**秩序**：网格、字阶、留白、对齐、克制的阴影；不是堆装饰。
- 炫技藏在细节里：转场、滚动、材质、触觉。用户第一眼看到的是"舒服"，第二眼才察觉"讲究"。

## 二、三条设计原则

### 原则 1 · 内容永远比装饰大
- 头图渐变**只出现在页面顶部**，正文区回归中性底，绝不让彩色背景压住文字；
- 每屏最多 **1 处渐变/1 个主行动按钮/2 个强调色**，其余用中性层级；
- 数据必须真实可读：数字优先、单位次要、说明最小；不拿渐变和光效盖数据。

### 原则 2 · 秩序产生高级感
- 8pt 网格：页面左右 20、卡间距 12、区块间距 24-32；
- 字阶 7 档（11 / 12 / 14.5 / 16 / 18 / 22 / 30），大标题负字距、正文行高 1.5-1.6；
- 卡片语言统一：`surface + 8~12% 域色 + 0.9px 域色描边 + 柔和双层阴影`；
- 圆角三档：卡片 20 / Hero 24 / 控件 12；胶囊 999；
- 数字用等宽数字（tabular figures），避免跳动。

### 原则 3 · 炫技但不喧宾夺主
- 只在**层级变化/状态变化/引导注意**时动；不做无意义循环动画；
- 动画 120ms（反馈）/ 240ms（过渡）/ 420ms（入场）三档，曲线 easeOutCubic/Quart；
- 尊重系统「减少动态效果」；
- 性能优先：模糊/噪点/视差只用在**一屏一两处**，低端机不闪、不卡。

## 三、视觉语言

| 维度 | 规范 |
|---|---|
| 底色 | 浅色暖灰白；深色近黑但不纯黑；正文区永远中性 |
| 域色 | 13 域身份色（科技/商业/健康/文化/旅行/语言/备考/学术/外刊/公版书/听力/笔记/其他），只用于头图、标签、图标、描边、强调数字 |
| 主色 | 只用于主行动（主按钮、选中态、链接） |
| 材质 | 卡片=浅染色+细描边；Hero=渐变+底部压暗+2% 噪点；玻璃=仅浮层/底栏（模糊 12-18） |
| 图形 | 13 域自绘图形作身份纹理；头图右下低透明度大图形；空态用大图形+一句可执行提示 |
| 排版 | 中文优先字号 15；标题 w800；正文 w400-500；元信息 12；标签 11 |
| 布局节奏 | 「一大两小」：大 Hero + 两列小卡；横向卡流替代长纵列；每屏留一处呼吸空白 |

## 四、"炫技清单"（按性价比排序，逐条落地）

| # | 技术 | 用在哪 | 为什么不算喧宾夺主 |
|---|---|---|---|
| 1 | **滚动收束头部**（大标题→小标题，头图渐变淡出） | 输入/输出/材料中心 | 只发生在滚动时，静止时是干净标题 |
| 2 | **共享元素转场**（材料卡封面 → 阅读器头图；阶段卡 → 练习页） | 阅读器、练习流 | 只是"同一物体继续存在"，不增加视觉元素 |
| 3 | **封面取色**：从真实封面图提主色生成头图（无图用域色） | 阅读器/材料详情 | 色彩来自内容本身 |
| 4 | **骨架与真实布局同构**，加载完成交叉淡入 | 所有列表 | 消除跳动比任何动效都高级 |
| 5 | **进度环生长 + 数字滚动**（一次 600ms，之后静止） | 四阶卡、统计 | 只播放一次，不循环 |
| 6 | **微噪点/纸感材质**（自制纹理，2-3% 透明度） | 头图、空态插图 | 提升质感但不抢文字 |
| 7 | **玻璃底栏/浮层**（BackdropFilter 模糊 12-18） | 底部导航、弹层 | 只在内容滚动到其下方时可见 |
| 8 | **按压缩放 0.98 + 轻触觉** | 所有可点卡片 | 反馈更"实"，没有视觉噪声 |
| 9 | **空态/引导的手绘涂鸦点缀**（沿用图形系统） | 空态、首次引导 | 只在没有内容时出现 |
| 10 | **细节图标动画**（成功打勾描边、任务完成反馈） | 保存/完成/评分 | 只在动作后 400ms 内 |

## 五、对比旧版要改的东西（用户骂过的点）

| 旧问题 | v4 处理 |
|---|---|
| 白底 + 大黑标题 + 蓝按钮 | 头图渐变 + 域色卡片 + 中性正文区 |
| 材料中心找不到 | 头图右上主按钮 + 题材 tabs 首屏可见 |
| 小封面塞「随着疫」截断字 | 单字标/纯图形封面，标题交给卡外 |
| 内页还是白卡 | 四组逐屏迁移，统一 v4 组件 |
| 卡通/低幼感或过度花哨 | 域色克制、图形做纹理、动效只服务层级 |

## 六、为什么这套适合"英语学习"这个产品

- 阅读/写作需要**低干扰**：花的界面会抢走注意力；
- 学习反馈需要**明确的状态表达**：进度环、档位、标签、颜色=域身份，一眼读懂；
- 长期使用需要**耐看**：中性底 + 少量高饱和强调，比大面积渐变更耐看；
- 用户是成年人/学生，不是儿童：要"有品"，不要"卡通"。

## 七、落地方式

1. 先渲"风格板"（组件组合图）确认材质与配色；
2. 每组屏迁移 → 每屏出 PNG → 用户过目；
3. 动效按清单逐条实现，每条都有"关闭减少动态"的降级；
4. 所有颜色/圆角/字号走 `design_tokens` + `v4_kit`，禁止页面裸写。
