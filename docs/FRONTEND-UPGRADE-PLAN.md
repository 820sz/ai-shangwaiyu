## 一、样图给了什么(用户 2026-10-23 提供 5 张,只学本质)

| 样图 | 提取出的设计要素 | 我们不照搬的部分 |
|---|---|---|
| **扇贝阅读 · 每日精读** | ①大标题+日期;②**大图卡**(水彩插画,通栏);③两个圆角标签(内容领域 + Lv8);④英文大标题 → 中文副标题;⑤元信息行(60 句 / 12 分钟 / 美音);⑥**整宽主按钮**「开始阅读」;⑦卡片**层叠**(后面垫两层,暗示还能滑) | 插画我们自绘不了,用真图/程序化图 + 几何图形替代 |
| **扇贝阅读 · 发现更多** | ①**内容领域 tab**(科学与技术 / 商业与政治 / 旅行与体育)+ 选中下划线;②横卡:左文右图(三行标题、日期、分类标签、**竖排 Lv 徽标**、方形缩略图);③留白分组,不套卡片 | 不抄它的配色;领域名要贴合我们内容源 |
| **训记**(商店页) | 「记录 / 精讲 / 规划」**三种功能三种形态**:记录=表单格、精讲=图文、规划=时间块。**同一个 App 里,功能不同,长得就该不同** | 高密度表单不适合阅读场景 |
| **轻小说文库** ×2 | ①**3D 透视书架**(书脊立体、可转动);②**奶白/米色材质**;③杂志化编号排版(`01 / CATALOG`)、英文小标;④极简图标 | 3D 转动的成本高,先做**静态 3D 透视**(书脊带厚度 + 光照) |

**提炼成一句话**:用户要的"丰富",是**不同功能有不同的呈现形态 + 同一形态里有图文和层级**;
不是"再加一个卡片墙"。用户要的"高级",是**安静的颜色 + 克制的层次 + 细致的间距与动效**。

## 三、设计方向(定稿,不再摇摆)

### 3.1 色板
- **浅色**:暖白底 `#FDFCF9` + 纯白卡 `#FFFFFF`;**墨黑**文字 `#14161A`(层级靠它拉);
  **主色蓝** `#2F6BFF`(主按钮/选中/数据),**不再用近黑当主色**(截图里主按钮是明确的蓝);
  浅暖灰 `#F5F2EC` 作次级面板。语义色沿用现有(已过 WCAG 闸门)。
- **深色**:`#0F1115` 底 / `#171A20` 卡 / `#1F232B` 输入;主色 `#7FA8FF`;文字 `#ECEEF2`。
  深色**不用阴影表达层级**(靠亮度差),与现有原则一致。

### 3.2 字阶（7 档，只增语义不增数值）
| 档 | 值 | 用在哪 |
|---|---|---|
| display | 28 / w800 / -0.5 | 页面主标题(「每日精读」) |
| title | 22 / w700 | 大卡标题 |
| heading | 18 / w700 | 区块标题 |
| subhead | 16 / w600 | 卡片标题 |
| body | 14.5 / w400 / 1.45 | 正文 |
| meta | 12 / w500 | 元信息、日期、句数 |
| tag | 11 / w600 / +0.3 | 标签、徽标 |

### 3.3 几何与光影
- 圆角:**卡 20 / 大卡 24 / 控件 12 / 胶囊 999**(不再是全场 16);
- 阴影:**只 2 档**(浅色用):`sm` 静置、`md` 浮起;深色档返回透明(靠亮度差);
- 间距:沿用 4 的倍数,但**区块之间用 24,组内 8/12**(用留白分组,少套卡片)。

### 3.4 形态映射(这次的核心)
| 内容 | 形态 | 为什么 |
|---|---|---|
| 今日精读 / 推荐文章 | **Hero 大图卡**:通栏图(16:9)→ 标签行(领域 + Lv)→ 标题 → 中文副标题 → 元信息行 → 整宽主按钮 → 层叠底 | 一眼看到"读什么、多难、多久" |
| 材料列表 | **横卡**:左文(标题/日期/标签/竖排 Lv)右图(方形缩略图) | 高密度扫描 |
| 书架 | **3D 透视书架**:书脊有厚度与光照、进度书签带 | 物理隐喻,"放满"的欲望 |
| 复习 | **大翻卡 + 环形进度 + 大评分按钮** | 单任务专注 |
| 统计 | **大数字 + 趋势图** | 一眼看懂 |
| 对话 | 气泡 + 头像 | 对话心智 |
| 词条 | 单词卡(词/音标/释义/例句) | 学习单元 |
| 设置 | **分组列表(不套卡片)** | 精简 |
| 空态 | 自绘小图形 + 一句话 + 主按钮 | 首印象 |

### 3.5 动效（只用 transform / opacity，120–420ms）
- 卡片按压:`scale 0.98` + 120ms;
- 列表入场:错峰 40ms,淡入 + 上移 8px;
- 页面转场:共享元素(Hero 封面 → 阅读器大图);
- 分类 tab 切换:方向性滑动;
- 进度数字:变化时补间滚动(400ms);
- 里程碑(读完一本书/连续 7 天):低频,做一次庆祝动效。

### 3.6 分类逻辑（用户点名"一坨屎"）
- 材料中心按**用户任务**分层:「今日」(精读+推荐)/「找材料」(领域 tab:科技 / 商业 / 人文 / 生活 / 学术)/「我的」(书架/材料库);
- 分类 tab 用**内容领域**(不是"发现更多"这类系统词);
- 底栏文案改用户语言(见第 8 批)。

## 五、验收标准（每批自检,也是给用户的口径）

- [ ] 每屏**只有一个主行动**,其余动作降级;
- [ ] 第一眼能回答「这一屏让我选什么」;
- [ ] 层级≥3 档(标题/正文/元信息),字号差≥4;
- [ ] 一屏最多 1 主色 + 2 语义色,没有第三种装饰色;
- [ ] 阴影只用 2 档;深色下不用阴影;
- [ ] 动效只动 transform/opacity,时长 120–420ms,可关闭(系统减少动态);
- [ ] 窄屏(320dp)/ 2× 系统字号不溢出;
- [ ] 无裸 `CircularProgressIndicator`;
- [ ] 相关测试文件通过 + `flutter analyze` 0 error。
