## 5. 病根诊断(我复盘出来的,你可以再验证)

**核心结论:这不是"设计 token 不够细"的问题,是"没有视觉素材"的问题。**

用户说"你没有生图,但是有建模、代码的能力" —— 意思是:
**你该用 CustomPainter / Canvas / 几何构造,自己画图形资产**。我一条都没画(除了鲸鱼尾),
所以界面只能靠"色块 + 文字 + 圆角"撑,怎么改都是简陋。

具体表现:
1. **分类没有图形身份** → 12 个内容领域只有 12 个 Material 图标,没有视觉差异;
2. **材料没有封面身份** → 真实图缺失时只有色块;而用户对"真实图/好看封面"非常敏感;
3. **空态没有插画** → 灰图标 + 一行字,廉价感的主要来源;
4. **数据没有图形** → 统计/进度/难度全是文字与进度条,没有环、柱、热力、趋势;
5. **动效只有"出现"** → 没有按压、切换、数字滚动、图形生长;
6. **形态只有一种卡** → 内容类型不区分,导致"清一色"。

## 6. 计划方向(我的主张,等用户批注)

### 6.1 第 1 层:视觉语言 / 图形资产系统(地基,最优先)

**A. 12 套分类图形(CustomPainter,自绘,双色渐变底)**
每个内容领域一个抽象几何图形(不是 Material 图标):
- 科学与技术 = 同心轨道 + 粒子点
- 商业与政治 = 峰线 + 柱状
- 健康与生活 = 脉搏波 + 圆环
- 文化与艺术 = 拱门 + 圆形色块
- 旅行与体验 = 航线弧 + 地平线
- 语言与学习 = 字母解构 + 网格
- 备考 = 考卷格 + 勾
- 学术论文 = 公式符号 + 点阵
(其余按同样逻辑补;每个图形 96~160px,可在分类卡/二级页头图/空态复用)

**B. 材料封面体系(彻底废掉"色块+文字")**
优先级:①真实图(og:image / 书籍封面 API / arXiv 缩略图)→ ②**按类型自绘封面**:
- 书 = 书脊 + 书皮 + 几何装饰
- 论文 = 网格 + 公式符号 + 页码
- 新闻 = 头条排版 + 栏线
- 真题 = 考卷格子 + 题号
- 笔记/碎片 = 便签 + 折角
(自绘封面 = 类型色 + 图形 + 极简标题排版,不是纯色块)

**C. 空态插画**:每个空态一套自绘插画(漂浮书页 / 纸飞机 / 散落字母 / 放大镜)
**D. 数据图形**:环形进度、柱状对比、热力日历、趋势线(用 CustomPainter,不引依赖)
**E. 色彩语义**:文章=蓝 / 图书=紫 / 论文=青 / 真题=琥珀 / 生词=绿,全 App 统一
**F. 形态库 6 种**:大图 hero 卡 / 横卡(左文右图) / 竖卡封面(3:4) / 网格块 / 列表行 / 图表卡 —— 按内容类型选用

### 6.2 第 2 层:页面结构(每屏重排)

**材料中心(主战场)**
1. 首屏 =「**你要读什么?**」选择器:目的(备考/工作/兴趣/学术)× 难度(i+1/i+10/不限)× 题材,
   **卡片式多选 + 图形**,选完直接出推荐流;偏好不再是"顶部一张卡",而是**流程第一步**;
2. 已设置时:顶部"我的偏好"条(可改) + **分类大卡网格**(2 列,每张 160 高,图形占 60%);
3. 点分类 → 二级页:子类 chips + 排序 + 材料列表(按类型不同形态);
4. 首页另留:今日精读(大图卡)+ 你的书架 + 为你推荐。

**写译批改**
1. 首屏 =「**三步工作台**」:① 拍/写 → ② 批改 → ③ 复盘,带步骤指示;
2. 手写档:示例图 + 大拍照按钮 + "批改后你会看到:分数环 / 四类错误 / 逐条改写";
3. 电子档:写作区 + 字数 + 计时 + 可选题目模板;
4. 结果页:分数环 + 错误分类图(环/柱)+ 逐条错误卡(图标 + 色标 + 原句→建议 + 追问）。

**阅读器**:目录抽屉、字号/行距图形化面板、翻译控制条(已有)视觉统一、进度可视化。
**练习 / 我的 / 助理 / 书架 / 收藏 / 统计**:同样按"主行动 → 内容 → 元信息"三层重排,数据图表化。

### 6.3 第 3 层:功能键 / 标签语义化

- 功能键 = **图标 + 动词**(「拍照识词」「直接批改」「换个说法找」),主/次/危险三级,尺寸统一;
- 类型标签 = **色块 + 图形符号**(文章/图书/论文/真题),不再黑底小贴片;
- Lv 徽标改**横排** + 色阶;

## 9. 血的教训(我都踩过,你别再踩)

### 9.1 用户说"没变化"时,先查**主体结构**是否真的变了
v2.12.0 我改了配色/卡片/圆角,还加了顶部 tab,用户一看"还是老样子" —— 因为
材料中心主体仍是 7 个 `CollapsibleSection`。**换配色/换卡片不算升级**。
判断标准:**把新旧截图并排,能不能一眼看出不同的"形态"**。

### 9.2 "丰富"≠"换排列"
加网格/横滑/分段只是排列;真丰富 = **形态差异 + 图形资产 + 类型区分**。

### 9.3 禁用 PowerShell 改源码(我犯了 3 次)
`Set-Content`/`-replace` 会给文件加 UTF-8 BOM、可能改换行。
**只用 read / write / edit 工具**。写大文件用 `write` 整个重写,不要跟 `edit` 较劲。

### 9.4 改嵌套结构(加 SafeArea / 包一层)时括号极易错位
我因此编译失败 3 次。**改完立刻单独 `flutter analyze` 该文件**,别等最后。

### 9.5 不要把半成品 3D 当亮点
v2.12 给书架加 `Transform..rotateX` 透视,没裁剪 → 书脊文字溢出到统计条下面(用户截图可见)。
3D 要做对 = 裁剪 + 透视阴影重建。

### 9.6 已知测试假失败(别浪费时间)
`test/profile_card_test.dart` 的界面用例会因 Hive 真实写盘悬在假时钟上,偶发失败。
**这是测试环境问题,与 App 无关**,已加 3 秒上界;根治需要把名片存储抽成可注入接口。

### 9.7 硬编码颜色会被测试抓
`test/theme_test.dart` 有闸门扫描 `lib/` 里的浅色硬编码(排除 theme.dart)。
淡色文字用 `AppTheme.faintText(context)`,不要 `onSurfaceVariant.withAlpha(...)`。

### 9.8 新文件用 ASCII 文件名
同步远端的脚本 `tool/push_via_api.ps1` 对中文文件名不友好。

### 9.9 发版必须核对 digest
`gh api .../releases/tags/vX.Y.Z --jq '.assets[0].digest'` 与本地 sha256 逐字比对;
并确认远端 tree 与本地一致(`tool/push_via_api.ps1` 会打印)。
