## 更新内容

1. 输出页改成四阶并行工作台：写词 / 写句 / 写段 / 写篇，四张卡平级并列，从哪一阶开始都行。
2. 新增「今日建议」：按你的到期复习词数和最近 7 天写译篇数，给两条能直接点进去的建议（数据不足就不显示）。
3. 写句 / 写段 / 写篇都有新练习器：先选"从哪出题"，题目来自你读过的材料；写完当场批改。
4. 写篇可以按目标考试抓公开真题页面出题（写作 / 翻译），每道题标注真实来源；抓不到就不生成，不编题源。
5. 批改结果页按"维度分 + 依据 + 客观档位"展示：分数环、每个维度的分数与引用原文的依据、逐条错误与改法、参考改写。
6. 练习记录与作答落库，后续用于复盘与统计。
