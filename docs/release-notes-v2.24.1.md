# ReadFlow v2.24.1 · 真机对版修复（v4 视觉第一批补漏）

> 起因：用户 11/04 凌晨真机截图指出「很多地方和渲染图不一样，有些还是老版」。
> 核查结论：v2.24.0 只把"外壳/头图"换成了果冻，**内页 body 与全局区块组件仍是旧样式**，
> 且此前多数页面预览图是"手搭示意图"，不是生产屏幕渲染。本版按真机截图逐项对版修复。

## 本版修复

1. **全局区块标题重做**（影响最大）：材料中心「01 今日精读 / 02 按分类找材料 /
   03 今日推荐 / 04 书架」、我的、学习助理、输出等所有使用区块头的页面 ——
   从"两行大黑编号 + 大标题"改成 **主色编号胶囊 + 一行大标题 + 右侧淡底胶囊动作**。
2. **全局 AppBar 果冻化**：所有还没逐页迁移的内页（统计、周报、备份、学习偏好、
   API 设置、写译记录、助理内页等）从"白底工具条"改成 **淡粉紫底 + 26 圆角 +
   深墨标题 + 深墨图标**，与主屏语言一致。
3. **识图结果页对版**：详细词卡改 **白卡果冻 + 柔影 + 18 圆角**、序号变主色胶囊、
   释义/例句块分层；底栏改 **白玻璃条 + 胶囊（模型/追问）**；头图动作全部改玻璃圆键，
   标题不再被挤成"识别结果…"。
4. **书架去"木头"**：书架从浅橡木/深胡桃木配色改成 **果冻淡紫书架 + 白色搁板 +
   主色光晕/虚线书位**，与周围卡片同一套语言。
5. **生词本词卡**：M3 默认 Card → **白卡果冻 + 18 圆角 + 柔影**（选中态主色描边）。

## 内部改进（不改变功能）

- 建立 **真实屏幕渲染** 验收通道：测试里直接 pump 生产屏幕 widget（恢复会话/真实 DB 假数据）
  出图，不再用手搭示意图当验收（`test/ui_real_screens_test.dart`）。
- 差异审计清单归档：`docs/V4-MISMATCH-AUDIT.md`（哪一屏、之前声称、真机实际、处理）。
