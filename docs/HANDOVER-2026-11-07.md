## 3. 工程经验（本轮踩过，别再踩）

1. **多 agent 并发调 flutter 会抢 `build/native_assets` 与 `.buildlock`**：一律 `bash tool/lockrun.sh ... --no-pub`；锁卡住时先看 `Get-CimInstance Win32_Process` 有没有僵死 `flutter test`，必要时杀测试进程再清锁。
2. **渲染测试字体**：开屏/预览没有 Scaffold 时，必须自己包 `Material + DefaultTextStyle(fontFamily)`，否则中文落成 Ahem 方块；字体要显式 load `NotoSansSC-VF.ttf`。
3. **fake-async 里 await 真实 I/O 会永久挂起**：Hive 写库/`image.toByteData`/`SplashSettings.setTagline` 都要放 `tester.runAsync`；否则测试挂 10 分钟超时。
4. **全量测试串行跑**：多个测试文件共用同一 sqflite 磁盘库，并行会偶发 `database is locked`；`final_gate.sh` 已固定 `test -j 1`。
5. **删/加数据库列要用户批准**：本轮 rubric 六级用开库自检 `INSERT OR IGNORE` 幂等补种，零迁移；草稿用 Hive 单行 JSON，不改表。
6. **图标生成**：`test/gen_icons_test.dart` 用 PictureRecorder 按密度原生渲染 PNG（不缩放、不引依赖），输出 `build/gen_icons/`，再由 Lead 拷进 `android/app/src/main/res/`。

## 5. 发版流程（复用）

1) 改版本（pubspec `x.y.z+n`）→ 2) `bash tool/final_gate.sh` → 3) `bash tool/lockrun.sh build apk --release --target-platform android-arm64 --no-pub`
→ 4) `aapt dump badging` 核 versionCode/versionName → 5) `sha256sum` + 桌面副本 + `tool/symbols/<ver>/`（mapping + sha256）
→ 6) `git add -A && git commit` → 7) `git push origin master` + `git tag v<ver> && git push origin v<ver>`
→ 8) `gh release create v<ver> build/app/outputs/flutter-apk/app-release.apk --title ... --notes-file docs/release-notes-v<ver>.md`
→ 9) `gh release view v<ver> --json assets` 核对 digest；10) 让用户用应用内「检查更新」验收（`update_service` 走 GitHub releases/latest）。
