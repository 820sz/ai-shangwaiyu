## 4. 工程经验（本轮踩过、下一轮别再踩）

1. **多 agent 并发跑 flutter 会互相抢 `build/native_assets/windows/sqlite3.dll`**（后到的静默失败）——已做 `tool/lockrun.sh`（mkdir 原子锁），所有 flutter 命令必须走它。
2. **渲染测试两个坑**：
   - 预览屏根节点不是 Scaffold/Material 时，`MaterialApp` 会把默认文字样式设成内部 `_errorTextStyle`（红字+**纯黄双下划线**，Flutter `app.dart:45-54`）——预览图黄线就是它；解法：`DefaultTextStyle(decoration: TextDecoration.none)` + 显式字体。
   - 测试体内真实 I/O（Hive/SQLite）在 fake-async zone 里 `await` **永不返回**（`--timeout` 也不触发）——seed 必须包 `tester.runAsync`；渲染用有界 `pump`，别 `pumpAndSettle`。
3. **字体**：`ThemeData(fontFamily:)` / `textTheme.apply` 只覆盖一部分；按钮/chip/下拉/裸 TextStyle 会落回 Ahem 方块——要么显式给组件主题设字体，要么把字体注册成多个族名 + fallback（见 `test/assistant_mine_preview_test.dart`）。
4. **多 agent 文件所有权**：写作用域分好、跨作用域先问 Lead；本轮唯一跨作用域例外是 `lib/widgets/word_action_sheet.dart` 加 `@visibleForTesting previewWordInfo`（已批准、生产零影响）。
5. **QA 角色价值**：独立只读 QA 抓出了大量"图不能骗人"的问题（Ahem 方块字、周报假 0、首页骨架屏、空白带、残留 ListTile、P2-1 材料出题不吃等级筛选），**验收要逐张 read_image + 追代码到真实调用，不能只看测试绿**。
