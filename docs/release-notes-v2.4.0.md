### 🔎 1. 识图(你说"问题最大、越改越烂、开盲盒")——先给你预设提示词,再说改了什么

**原来的识图提示词(逐字)**:

```
你是英语学习助手。识别照片中"被标注"的英语内容。输出JSON，格式：
{"items":[{"word":"完整原文","translation":"中文释义","word_type":"word|phrase|sentence",
"part_of_speech":"词性(可选)","phonetic_uk":"…","phonetic_us":"…","original_sentence":"…"}]}
标记定义：手写笔迹圈画、下划线、波浪线、荧光笔、方框、星号、书签贴、页边批注对应的英文等读者标注痕迹。
识别纪律(v1.4.4)：
1. 只输出有明确标记痕迹的内容；正文中未作任何标记的文字一律不要输出。
2. 如果不能确定某个内容是否被标记，宁可漏掉，也不要输出。
3. word 必须与照片中的文本完全一致——单词、短语、句子一律完整输出,禁止截断,禁止用省略号(…)代替后半部分。
4. 短语/句子必须在 original_sentence 中给出其所在的完整句子(必填,不可省略)。
5. 单词给词性,并同时给 phonetic_uk(英式)与 phonetic_us(美式)音标;…
6. 先扫一遍找出所有标记位置，再逐个读取，同一处重复标记只输出一次。
无任何标记返回{"items":[]}。只输出JSON。简洁思考。
```
(另有"校准重识别"分支:逐行扫描 + `detail=high` + 输出前自检;它只有在你点"重新识别"时才用。)

**这版改了什么(依据你发的 5 张样本照片)**:

| 改动 | 为什么 |
|---|---|
| **识图固定低思考档** | 你原来开着"高":实测 6 秒 / 6225 字思考、只出 1 条 —— 思考预算挤占正文,还越想越偏 |
| **图片先转正再发** | 你的样本里有横拍/倒置的页面;现在按 EXIF 把像素转正、长边压到 2000px 统一 JPEG,发出去的东西每次都一样 |
| **提示词加了 4 条实战纪律** | ①照片可能是任意方向,先转正再逐行读 ②**一位词就是 word**(直治"整页批注单词全被标成短语")③跨行标记要接完整 ④新增 `line` 字段(照抄该行原文) |
| **本地确定性校验层**(新增) | 模型说的不算算:重复条目、被更长条目包含的碎片、截断碎片(有完整句就替换、没有就丢)、类型本地重判、`line` 里核对不到就标"存疑" |
| **结果头部显示"已校验"** | 例如「已校验:忽略 2 条 · 纠正类型 3 条」,点开能看到**每一条被忽略的原因** —— 把盲盒打开 |
| **页边中文批注保留**(你当场纠正) | 你要拿它补录,所以不再当垃圾丢掉;旁边的英文照常单独出一条 |

⚠️ 诚实说明:准确率最终只有你在真机上能判。我这边能保证的是"能确定性校验的都校验了"、图片不再歪着发、思考不再挤占输出。

### ✨ 2. 「AI 补全」没法用
根因:追问端点未配置时按钮被设成**灰的且没有任何解释**(`onPressed: null`)。现在按钮始终可点:缺配置就说清缺什么 + 一键跳 API 设置;追问端点没配时**自动回落主 API**。

### 🗂 3. 追问抽屉的复制(你说"连个基本的复制逻辑都有问题")
根因:自定义菜单把**系统默认的「复制」换掉了**,所以"选中一段"根本复制不了那一段。现在平台默认项(复制/全选/分享)全部保留 —— 选中哪段复制哪段 —— 再补「复制整条」「取消选择」。

### 🔤 4. 词汇原型备注(`taming(tame)`)
- 规则推导(ing/复数/三单/过去式)+ 不规则表(children/teeth/lives/ate/written…);
- **候选原型必须在内嵌 5 万词频表里是真词才显示** —— 挡住 `bus→bu`、`news→new` 这类笑话;没把握就不写;
- 生词本列表与词条详情都显示。

### 🔁 5. 同一个词反复出现 → 记次数与出处(`apple(×2)`)
- 同词不再"又存一行",而是**合并一次出现**(按 书+页+句 去重);
- 词汇本与词条详情显示 `apple(×2)`;**词条详情新增「出现记录(N 次)」**,逐条列出每处的出处与该处原句(你说的"加强记忆");
- 已有的释义/音标**不会被覆盖**,只在原来为空时补;
- 数据库加了 `occurrences_json`(dbVersion 12,老库自动迁移)。

### 🌐 6. 翻译质量(你说"生硬、不符合原句语境")
识图与 AI 补全两处提示词都加了硬性要求:单词先判**语境词性**再给中文(bank 河岸/银行、issue 问题/发行),不给词典第一个义项;短语/句子给整句通顺中文,不逐词硬译。

### 💬 7. 学习助理对话独立窗口 + 字号外的两个修复
- 新页面「和助理聊聊」:**AI 头像、流式输出、思考过程可折叠、思考强度可选**、读取全部学习数据(证据包不变,禁止编造)、消息落库;
- 学习助理页不再内嵌聊天,只留"今天做什么 + 诊断"和一张入口卡(带最近一条对话摘要);
- **「今天做什么」划掉后可以再点回来**(新增"取消完成",之前按钮是禁用的)。

### 📁 8. 手改归类后仍留在「未归类」
两个根因都修了:①「批量移动」时**取消子分类对话框仍会执行移动**(分类改了、路径没改 → 分组按路径归类,词还挂在未归类),现在取消 = 整件事取消;②材料名留空时旧实现拼出只有一级的伪路径 `书籍`,现在统一落到「未命名材料」分组。顺带:移动时用选中词的共同出处预填对话框。

### 🌤 9. 浅色模式看不清(你点名的《character》泛白)
实测数字:卡片描边对白底 **1.70:1**、输入框描边 **1.61:1**(WCAG 要求 3:1)——M3 用近黑种子生成的浅色描边本来就极淡,而卡片白底和页面 #F8F9FA 几乎同色。修法:主题层把描边加深到 5.2:1 / 3.4:1、输入框改用可见描边、**chip 补描边**;词条卡片里自己调透明度的文字色(3.0~3.9:1)全部改成主题色;并加了**浅色对比度闸门测试**,以后新页面不会再犯。

### 📚 10. 材料中心(两条)
- **(1) AI 二手改写 → 两个方向自选**:「按你的水平找材料」现在进的是方向页,**默认「资料原文」**(Gutendex 公版书 / arXiv 论文 / 外刊最新条目的**真实原文检索**,每条带来源角标、点开即抓正文入库阅读);「AI 整理编写」单独一栏,顶部黄色警示写明"这是 AI 产物、不是出版原文、完整度与出处无法考究",AI 推荐条目也加了**「AI 编写」角标**;
- **(2) 「再多来几条」**:原来只有"重新推荐"(整组覆盖),现在可**追加**(按标题去重;全重复时明确提示,不静默无变化)。
