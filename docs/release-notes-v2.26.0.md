## 一、材料中心频道化（方案 2）

四个大分类（按需求 / 按题材 / 按形式 / 按场景）现在点进去都是**频道页**：

### 发现 Tab（真实检索，不再是历史堆积）
- **快照留存**：搜过的结果按频道存本地；下次进入直接显示「上次结果 · 时间 · N 篇 · 花费」；
- **继续找更多**：让 AI 基于已见结果换检索词，再带着 `excludeUrls` 去搜，不会把旧卡片重复塞回来；
- **分页**：每页最多 10 条，底部「显示更多」，不再一整列无限铺；
- **分组**：教材 / 应试真题 / 书籍 / 论文 / 外刊新闻 / 文章 / 其他，组名带数量；
- **结果卡**：开始读（抓到正文 → 入库 → 阅读器）、保存到我的、打开原文 / 打开 PDF（抓不到正文也能打开真实链接）；
- **搜索过程可折叠**：跑完只剩一行「搜索过程 · N 步」，点开才看时间线。

### 我的 Tab（历史归这里，可管理）
- 只显示「保存到我的」+ 当前子分类匹配到的材料，不再把整库 300 条倒出来；
- 支持：打开阅读、编辑中文标题、**从本频道移除（持久，重进也不再出现）**、删除材料；
- 空态给「去发现里找」。

### 类型与标签修复
- 新推断：标题/URL 命中真题（四六级/CET/雅思/托福/考研/试卷…）→「应试真题」；
  命中教材（课本/新概念/必修/选修/textbook…）→「教材」；
- 材料库/封面/列表同步补上「教材」「应试真题」文案（之前一律回落「文章」）。

## 二、质检发现的 P1 修复（本轮已修）

1. **「继续找更多」的新检索词进不了官方搜索**：官方搜索现在优先用补充词（最多 4 条名额），
   基础词只在还有名额时兜底 —— 否则"继续找更多"等于重跑旧词；
2. **空结果快照不回显时间/花费**：上次跑过但 0 条，也会显示「上次结果 · 时间 · 0 篇 · 花费」
   和空态说明，不再装成"从没找过"；
3. **教材/真题分组无数据来源**：官方搜索结果按标题/URL 推断 kind，分组与标签不再恒空；
4. **快照恢复重复抓正文**：频道页会把快照条目与材料库**全量**按 URL/标题对上号；
   读过的材料再点「开始读」直接打开本地正文，不再重复抓取/计费；
5. **「从频道移除」不持久**：新增频道级持久移除表，重进频道也不会再出现；
6. 频道页顶部「上次结果」行不再塞刷新按钮（刷新统一在 AppBar），小屏不再挤成省略号。
