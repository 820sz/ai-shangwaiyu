# ReadFlow v2.15.0 · 图形资产 + 视觉地基 + 阅读器翻译修复

> 批 1（2026-11-01）：全 App 除鲸鱼尾外第一次有了自绘图形语言；
> 同时把你点名好几轮没修好的「阅读器翻译」修掉了。

## 更新内容

1. 材料中心的大分类变成"图形墙"：科技、商业、健康、文化、旅行、语言各有自己的几何图形，不再是色块加小图标。
2. 材料封面不再是纯色块：书、论文、外刊、播客、百科各有类型身份图，没抓到真实配图时也不再是一块颜色。
3. 空态不再是一个灰色图标：搜不到、没内容、没网、词库空都有对应的小插画。
4. 统计页和周报上了真实图表：近 7 天柱状图、30 天趋势线、打卡热力图、完成度环。
5. 阅读器翻译修好了：文章按真实段落拆成 6~10 段，进度 0/N 会真的往前走，每段原文下面出现中文译文；某段失败有提示和重试，单段 45 秒超时不再干等 3 分钟。
6. 分类二级页头图换成该分类的领域图形，点进去视觉语言不断档。

## 技术细节

- 新增 `lib/widgets/graphics/` 图形资产系统：13 个领域身份图形 / 7 种材料封面 / 5 种空态插画 / 4 个数据图形 / 输出四阶，全部 CustomPainter 自绘、零新依赖、明暗两套自适配（`test/graphics_preview_test.dart` 有渲染与对比度闸门）。
- `MaterialCover` 底座改用 `MaterialCoverArt`：真图优先、类型徽标/难度胶囊/标题沿用原有壳层逻辑，小卡/横卡/大图三种尺寸都验证过（`test/cover_preview_test.dart` 出预览图）。
- 空态三组件（`AppEmptyState` / `AppEmpty` / `EmptyState`）向后兼容接入 `EmptyArt`：新增可选 `art` 参数，22 处调用点一行未改。
- 统计/周报接入 `SparkBars` / `TrendLine` / `HeatmapCalendar` / `RadialGauge`：只用真实字段，空数据显示"暂无数据"，不画假曲线（`test/chart_data_integration_test.dart` 钉住口径）。
- 阅读器翻译（根因：把 2500 词正文块当段落）：
  - 新增 `lib/services/reader_units.dart`：`splitUnits` 按空行拆真段落（超长段二次切、无损、块映射）+ `TranslationRunState` 进度状态机；
  - 阅读器渲染/翻译状态/可见性全部从"块"换到"段"；一次请求只发 1 段（≤600 字符）；完成时先渲染 100% 保留 2 秒再收条；
  - 失败段译文下显示「可能不完整:…」，可单段重试；错误文案改中文人话；
  - `translateParagraphsRich` 单请求超时 45 秒（原来 180 秒干等），`DeepseekApiService` 改为可注入（现有调用零改动）。
- 验证：`flutter analyze` 0 error / 0 warning（9 条存量 info）；全量测试 **1163 passed + 1 skip + 1 已知假失败**（`profile_card_test` 的 Hive 假时钟问题，与 App 无关）。
