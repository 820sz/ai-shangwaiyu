# ReadFlow v2.28.0 · 真机反馈第二轮整改（8 条）

> 本版针对 2026-11-07 用户真机验收反馈的 8 条问题；每条都有真机症状 → 根因 → 修法 → 渲染/测试证据
> （对照表 `docs/ROUND3-PLAN-2026-11-07.md`、QA 报告 `docs/QA-IMPLEMENT-ROUND3.md`）。

## 1. 材料中心找材料质量（第 1 条）

- **检索逻辑纠偏**：材料中心（按题材/形式/场景）现在**只按「你选的难度 + 你选的分类」**去找；
  不再把"学习目标/需求"全局注入到每个频道的检索词里（这正是"四六级 + 商业政治"互相为难、结果又少又怪的原因）。
  需求画像只留给独立「找材料」的「按我的情况找」。
- **结果过滤**：新增非英文内容过滤（如越南语文章不再混进来）、考试报名/公告/招生页过滤（不再把「考试报名网/考试简介」当材料）、弱相关过滤；覆盖率过低的卡片不再显示误导性的"为什么推"文案。
- **真题分级**：应试真题检索按四级/六级拆分，结果卡标明等级。

## 2. 阅读器空间利用率（第 2 条）

- 右侧进度竖轨 + % 胶囊改为**悬浮在页面右侧**，不再挤压正文宽度；页面左右/上下留白收紧。
- 保持 C 方案：零常驻按钮、上滑控制台 4 组、三纸色、真实阅读进度%、只有生词砖红下划线。

## 3. 书架 3D「每次点进去有一本书横档」（第 3 条）

- 初始进入只显示一排书脊；**点书脊后才抽出封面**，再点/点空白收回；封面不再遮挡相邻书脊与底部提示。

## 4. 自由搜（第 4 条）

- 顶部输入框不再裁字；
- 筛选区默认**收起**（顶部一行「筛选(n)」+ 已选条件摘要，点开为可滚动面板，搜索后自动收起），不再悬置挡屏；
- **无原文保底**：搜不到原文/抓不到正文时，明确说明"为什么没找到"，并基于真实搜到的标题/摘要/来源提供**「AI 改写学习版（非原文）」**（标注来源、字数、难度，可阅读/保存）；有真实原文时原文优先，不混淆。

## 5. 材料封面（第 5 条）

- 卡片级**懒加载封面**：能抓到页面 og:image 就显示真实封面（内存缓存），书目用现成公版封面；抓不到或材料本身没图时用文字版式——**不画假封面**。频道页/找材料/「我的」同口径。

## 6. 输出板块（第 6 条）

- 四阶卡片文字不再被裁切；
- **评分标准按考试等级**：CET-6 材料使用六级 rubric（幂等补 seed），界面显示中文标准名，不再显示 `cet4_writing` 这种原始 id；
- **答题可自由跳题**：新增题目导航/答题卡，可任意切题、查看已答/未答状态，不再强制顺序；
- **练习材料留存**：生成的题组落库为草稿，输出首页/练习中心提供「继续上次练习」，退出重进可恢复，不用重新找。

## 7. 我的 · 名片可读性（第 7 条）

- 自定义背景图加统一 scrim/遮罩，名字、签名、三栏数据、按钮在任意背景下清晰可读；无背景图保持纸面卡。

## 8. 我的 · 关于（第 8 条）

- 新增「关于」栏三入口：**软件声明**（著作权/使用范围/免责，署名 xi283、不公开联系方式）、**软件特色**（闭环架构、多维度材料、高可个性化、AI 驱动等技术定位）、**软件思想**（用户原文《谈谈语言学习的本质》+ 学术文献对照与真实参考文献链接）；
- 三者在**首次启动时作为开屏公告**展示一次（可「我已阅读并继续」，之后不再弹，可在关于里重看）；
- 新增「开源许可」入口（Flutter 依赖许可证自动汇总）。

## 9. 开屏动画 + 新 Logo + 桌面图标（本版一并完成）

- 开屏从"素底 + 文字方块"升级为 **琉璃玻璃**：背景三段极光 + 三团柔光斑 + 细噪点；中央 132×132 琉璃块（磨砂→澄澈凝结、1.5px 内高光边、斜向高光扫过、柔影）；
- **动画叙事（AI × 语言）**：方案 A「琉璃凝结」——引号（language）与星芒（AI）两条独立元素相向滑入、靠近、相撞合成，再浮出「AI上外语」字标与可自定义文案；总时长 1.5s，点击任意处可跳过，动画结束 250ms 交叉淡入主界面；
- **新 Logo「引号·星」**：引号=语言，星芒=AI，白色 mark + 投影；同一 mark 生成桌面图标（各密度原生渲染 + Android 12+ adaptive icon + monochrome，不引入依赖）；
