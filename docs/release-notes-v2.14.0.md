## 技术细节

- dbVersion 18 → 19：`vocabulary.material_path` / `materials.group_name` 一次性归一，
  只折"连续重复的前导分类段"（`书籍/书籍/《X》` → `书籍/《X》`），合法多级路径与
  "材料名恰好等于分类名"的两段值不动；单事务 + 幂等 + 启动自检双通道。
  注意：**已升级到 19 的库不能再用 18 的包打开**（会触发 onDowngrade），回退只能前向 hotfix。
- 识图内存：三条入口（首页拍照 / 首页相册 / 结果页追加）压缩参数统一到 1600/q85；
  方向检测复用同一张解码结果（不再每张多解一次整图）；预处理走 `compute` 后台 isolate；
  词汇/全文提取删掉 `Future.wait` 改严格串行；追加/旋转前先取消并等待「高清复查」退出。
- 追问抽屉：滚动监听持续记录 offset + maxScrollExtent，打开后 3 帧重试并按比例换算还原
  （抽屉 0.6↔0.85 高度变化不再错位）。
- 更新说明解析：`UpdateService.parseReleaseNotesForDisplay` 只取「## 更新内容」小节，
  清理 markdown，最多 8 条；发版说明从此按 `docs/RELEASE-NOTES-FORMAT.md` 书写。
- 验证：`flutter analyze` 0 error / 0 warning；全量测试与相关回归见发版记录。
